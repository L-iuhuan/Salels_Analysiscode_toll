# 实验 0.3: 产品生命周期数据提取与对齐

## 元信息
- 日期: 2026-06-12
- 数据版本: gold_product_portrait.csv (946产品×61字段), 原始Excel (922产品→产品线映射)
- 用途: **解释层** (当前2026-05快照, 非point-in-time画像, 不得用于回测建模)
- 前置实验: 0.2 ✅

## 实验假设
从gold_product_portrait.csv可提取的关键生命周期因子(健康扩张占比、衰退占比、风险评分等)覆盖至少14/17产品线，可为后续实验提供解释性特征。

## 实验设计

### 映射链路

```
gold_product_portrait.产品名称 (型号简称, 如'20DB')
        ↓ JOIN via 存货名称
原始Excel.存货名称 → 原始Excel.型号_产品线（新）
        ↓
17条产品线
```

### v1.3修订约束
- 当前画像 = 2026-05快照，**仅用于解释/置信度辅助，不得进入回测选模**
- 回测建模必须使用point-in-time画像 (按每折截点重新生成)
- 若无法生成point-in-time画像 → 生命周期因子仅限于解释层

### 提取因子
- 生命周期阶段分布：健康扩张、衰退期、夕阳产品、新品观察、成长型、现金牛等11种
- 风险等级分布：高风险、极高风险、中风险、低风险
- 连续指标：综合评分、毛利率、毛利率趋势、客户集中度、增长率
- 管理层摘要：投资区、退出区、观察区
- 营收-毛利判断：双增、双降、增收不增利、减收增利
- 6K达成情况

## 执行过程

### 步骤1: 映射建立 (v1/v2失败 → v3成功)
- v1: 直接用所属参照组名匹配产品线 → 仅1/17匹配 (所属参照组≠产品线)
- v2: 从silver层读映射列 → 列名不匹配
- **v3: 从原始Excel读取 存货名称→型号_产品线（新）映射** → 922条唯一映射 ✅

### 步骤2: 画像关联
- gold产品名称 JOIN 存货名称 → 产品线
- 耗时: ~30s
- 结果: 915/946产品映射成功 (96.7%)
- 31个未映射产品: 多为新品/非常见型号 (如EUP3042HFJIR1系列)

### 步骤3: 产品线级聚合
- 耗时: ~5s
- 按产品线汇总: 产品数、销售额、销量及各类占比

- 仅"未分类"无对应产品 (聚合产物, 预期内)
- 其他16条线所有因子均有值，缺失率 < 5%

## 成功标准判定

| 标准 | 预期 | 实际 | 判定 |
|---|---|---|---|
| 覆盖≥14/17产品线 | 14+ | 16/17 (仅未分类缺失) | ✅ |
| 缺失率<30% | <30% | <5% | ✅ |
| 因子值在合理范围 | 风险0-100, 占比0-100% | 全部在合理范围 | ✅ |

## 关键发现

1. **产品池规模与预测精度正相关**: 通用电源管理(495产品, WAPE=5.5%) vs 电源模组(2产品, WAPE=97.7%)
2. **新品占比高不一定不可预测**: POE(57.9%新品, WAPE=14.4%) vs 车规电源(85.7%新品, WAPE=31.7%) — 取决于是否有历史类比产品
3. **衰退期占比高仍可A类**: 硬件锂电保护(23.9%衰退, WAPE=9.2%) — 衰退过程有规律可循
4. **毛利率极低是危险信号**: 新显示MLED(2.3%毛利率, WAPE=51.3%) — 经营基本面差的线预测更困难
5. **健康度指标待Phase 1.3验证**: 与WAPE的Spearman相关性需在实验1.3中量化

## 结论

生命周期因子成功提取并映射到16/17产品线。当前画像为**解释用途**：可用于标注置信度、识别风险信号、辅助人工复核判断。若实验1.3需要回测建模，必须为每个回测截点重新生成point-in-time画像（以当前快照直接做回测特征会引入未来信息泄漏）。
