# 半导体销售数据分析系统 — 验证测试集

## 1. 测试套件概述

### 用途
本测试套件对半导体销售数据分析管道的以下方面进行自动化验证：
- **边界条件**：极端/异常输入下的系统健壮性
- **回归验证**：P0缺陷修复的有效性确认
- **业务规则**：核心业务逻辑的正确性
- **数据完整性**：Silver/Gold层输出的完整性和一致性
- **Schema验证**：各层输出文件的列名、数据类型、约束

### 运行方式

```bash
# 完整运行（推荐）
python test/validation_suite.py

# 仅运行特定章节
python test/validation_suite.py --include boundary,regression

# 仅运行边界测试
python test/validation_suite.py --include boundary

# 跳过需要导入pipeline模块的测试（只运行黑盒文件检查）
python test/validation_suite.py --blackbox-only
```

### 前置条件

| 条件 | 说明 |
|------|------|
| Python ≥ 3.8 | 基础运行环境 |
| pip 依赖 | `pandas`, `numpy`, `openpyxl`, `statsmodels`, `rapidfuzz` |
| 数据文件 | `data/*.xlsx` — 至少一个有效Excel文件 |
| Silver层 | `output/silver/*.csv` — 需先运行 pipeline 生成 |
| Gold层 | `output/gold/*.csv` — 需先运行 pipeline 生成 |

```bash
pip install pandas numpy openpyxl statsmodels rapidfuzz
python run_all.py  # 生成 Silver/Gold 层
```

## 3. 回归测试用例（Regression Test Cases）

### P0缺陷修复验证（5项）

| # | 测试名 | 验证内容 | 运行方式 |
|---|--------|----------|----------|
| P0-01 | **CUSTOMER_ANALYSIS_WINDOW.start_date 过滤** | 修改`start_date`后，分析数据应仅包含该日期之后的记录。验证：设`start_date="2025-01-01"`，数据中不应有2024年的记录参与分析。 | `python test/validation_suite.py --include p0` |
| P0-02 | **风险评分 0-100 封顶** | 所有风险因子（slope, cv, decay, self_health, asp）的输出得分必须在[0,100]闭区间内。验证：传入极端值（如无穷大、极大正数、极小负数），检查返回分。 | `python test/validation_suite.py --include p0` |
| P0-03 | **fillna(0) 在 MinMax 之前不影响评分** | `scoring.py` 中 `_minmax_norm` 的 `fillna(0)` 导致缺失值的客户得到50分而不是被排除。验证：构造一个只有1个活跃客户的数据集，检查该客户的各维度分不为50。 | `python test/validation_suite.py --include p0` |
| P0-04 | **profiling.py 解耦重构输出一致性** | 重构后的`run_profiling`函数与原v2.8版本对同一输入产生相同输出（列名、值、数据类型）。验证：传入固定输入，检查输出DataFrame的列名和关键字段的数值。 | `python test/validation_suite.py --include p0` |
| P0-05 | **RFM-π rank稳定性** | `rank(method='first')` 在并列值上产生行顺序相关的评分。验证：对同一组数据做两次评分（交换行顺序），两次结果应一致（当前可能不一致）。 | `python test/validation_suite.py --include p0` |

## 4. 数据完整性测试（Data Integrity Tests）

| # | 检查项 | SQL/逻辑描述 | 预期结果 |
|---|--------|-------------|----------|
| DI-01 | **Gold产品数 = Silver唯一产品数** | Gold层产品画像的产品数 = Silver产品月表中`产品品种`的unique计数 | 相等 |
| DI-02 | **Gold客户数 = Silver唯一客户数** | Gold层客户全景的客户数 = Silver客户月表中`客户编号`的unique计数 | 相等 |
| DI-03 | **无负评分值** | 评分列（综合价值分/机会评级分/风险评级分）中不应有负数 | min >= 0 |
| DI-04 | **所有评分在0-100范围内** | 所有评分列的最大值不超过100，最小值不低于0 | 0 ≤ score ≤ 100 |
| DI-05 | **产品年龄 = 末月 - 首月** | `calc_age_months`计算的产品上市月龄 = `last_month - first_month`（月数差） | 一致 |
| DI-06 | **产品数 + data_insufficient数 = 唯一产品数** | profiling输出的有效产品数 + 数据不足产品数 = Silver中唯一产品数 | 总和相等 |
| DI-07 | **客户月表中无负销量聚合** | Silver客户月表的`qty_sum`列不应有负值（负数已在清洗层过滤） | min(qty_sum) >= 0 |
| DI-08 | **毛利率无超出[-0.50, 0.75]的值** | Silver层计算后的`毛利率%`应在Winsorization范围内 | 均在[-50%, +75%] |
| DI-09 | **Gold无缺失必填列** | 客户全景表的`客户编号`不应有缺失 | 全部非空 |
| DI-10 | **客户ID一致性** | Gold层所有表中的客户编号均在Silver客户月表中存在 | 全部匹配 |
