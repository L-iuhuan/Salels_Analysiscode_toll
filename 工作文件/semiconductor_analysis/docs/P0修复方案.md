## P0-01: 分析起始日期不一致

### 重新定性

**原诊断**: P0 bug——两个管道使用不同起始日期，导致数据范围不一致。

**经确认**: **这是设计选择，非 bug**。
- 产品分析使用全量数据（`data_start_date="2020-01-01"`）：所用字段不涉及缺失信息
- 客户分析使用 2024+ 数据（`start_date="2024-01-01"`）：2024年之前客户等级/渠道/区域等字段数据不全

### 已实施的修改

    #   产品分析( PRODUCT_LIFECYCLE.data_start_date="2020-01-01" )
    #   使用全量数据因其所用字段不涉及缺失信息。

## P0-02: 衰退画像最低风险分公式错误 ✅ 已修复

### 位置

`product_lifecycle/profiling.py:1037`

### 修改前

```python
total = (exit_min_risk * non_sh_weight + s_sh * w[3]) / sum_w
```

**问题**：`exit_min_risk`（分数阈值=50）与自身健康加权分 `s_sh * w[3]` 混合计算，自身健康分（最低可到0）能将总分拉低到阈值以下，**保护机制完全失效**。

示例：`w_sh=0.35, non_sh=0.65, exit_min_risk=50, s_sh=10`
→ `total = 50×0.65 + 10×0.35 = 32.5 + 3.5 = 36.0`（低于下限50！）

### 修改后

```python
total = max(exit_min_risk, total)
```

### 修改原因

原公式将分数阈值与加权贡献混合计算，数学不一致。简化为 `max(阈值, 原始总分)` 后：
- `total` 是 0-100 的加权分数（权重已归一化 sum_w=1.0）
- `exit_min_risk=50` 是对该总分设定的下限
- 逻辑清晰：衰退期且毛利/销量为零的产品，风险分不低于50

### 结果变化

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 影响产品数量 | 28个产品评分被压低 | 同上28个产品评分被修正 |
| 风险分下限 | 可能低于50（如36分） | 不低于 exit_min_risk（默认50） |
| 风险等级 | 部分为"低风险" | 最低为"中风险" |
| 组合健康度 | "衰退风险品金额占比"偏低 | 更真实反映风险 |

## P0-03: fillna(0) 前置污染归一化 ✅ 已修复

### 位置

`customer_analysis/scoring.py:45-61` (`_minmax_norm` 函数)

### 修改前

```python
def _minmax_norm(s: pd.Series, reverse: bool = False) -> pd.Series:
    s = s.fillna(0)                    # ← 问题：NaN→0 后参与极值计算
    if not pd.api.types.is_numeric_dtype(s):
        s = pd.to_numeric(s, errors="coerce").fillna(0)
    if s.dtype == bool:
        s = s.astype(int)
    if s.max() > s.min():              # ← 0 包含在 min 中
        norm = (s - s.min()) / (s.max() - s.min()) * 100
        return 100 - norm if reverse else norm
    return pd.Series(50.0, index=s.index)
```

**问题**：非活跃客户的NaN被fillna(0)填入0，0成为归一化最小值，压缩了活跃客户的分数分布。

### 修改后

```python
def _minmax_norm(s: pd.Series, reverse: bool = False) -> pd.Series:
    """Min-Max 归一化到 [0, 100]。缺失值不参与极值计算。"""
    if not pd.api.types.is_numeric_dtype(s):
        s = pd.to_numeric(s, errors="coerce")
    if s.dtype == bool:
        s = s.astype(int)
    valid = s.notna()
    if valid.sum() >= 2 and s[valid].max() > s[valid].min():
        norm = (s - s[valid].min()) / (s[valid].max() - s[valid].min()) * 100
        return 100 - norm if reverse else norm
    return pd.Series(50.0, index=s.index)
```

### 修改原因

1. 缺失值（NaN）不参与 min/max 计算 → 归一化范围仅基于真实有效数据
2. 缺失值归一化后保持 NaN → 由调用方 `_score_dimension` 在第94行 `norm.fillna(0) * w` 处理
3. 非活跃客户分数在第91行被 `SCORE_INACTIVE_DEFAULT` 覆盖 → 不受影响
4. 至少需要2个有效值才归一化 → 与调用方 `active_mask.sum() > 1` 语义一致

### 结果变化

| 维度 | 修改前 | 修改后 |
|------|--------|--------|
| 归一化极值 | 含人为插入的0值 | 仅基于活跃客户真实值 |
| 非活跃客户分数 | SCORE_INACTIVE_DEFAULT | 不变 |
| 活跃客户分数 | 略被压缩 | 分布展宽，更真实 |
| 整体影响 | 偏移1-5分 | 基本无感（净影响极小） |
