## 1. 客户分析规划

### 1.1 回款信用评分 (G3)

- **来源**: 客户销售数据分析方案 · 维度10
- **数据依赖**: 对账回款表（对账月度、应收金额、回款日期、回款金额）
- **原设计**:
  - DSO计算：月末应收余额 / 近3月日均销售额
  - 信用等级A/B/C/D
  - 回款模式聚类
- **当前状态**: ❌ 已废弃（客户整体回款状况好，不分层无实际意义）

### 1.2 销售人员归因 (G7)

- **来源**: 客户销售数据分析方案 · 维度07
- **数据依赖**: 业务负责人字段完整准确
- **原设计**:
  - 销售人员月度收入/毛利/活跃客户数/活跃品种数
  - 销售人效 = 毛利 / 活跃客户数
- **当前状态**: `客户全景.csv` 保留字段，归因分析未实施

### 1.3 渠道路径穿透 (G8)

- **来源**: 客户销售数据分析方案 · 维度08
- **数据依赖**: 客户信息表含代理商名称和终端客户名称
- **原设计**:
  - 三级交易网络（客户→终端客户→代理商）
  - 同一终端通过不同代理的路径价差比较
  - 渠道集中度监控
- **当前状态**: 代理商字段已预留(`COL_MAP`)但未启用

### 1.4 购物篮与交叉销售

- **来源**: 方案1.md · 3.4节
- **原设计**:
  - 订单篮子/时间篮子/项目篮子的融合购物篮分析
  - 频繁项集与关联规则挖掘
  - 互补品综合评分（6因子加权）
  - 交叉销售推荐、套餐捆绑、新品加速、流失防御
- **当前状态**: `shared/customer_analysis.py` 含基础的产品关联分析，完整体系未实现

### 1.5 工作日调整

- **来源**: 方案1.md · 2.2节
- **原设计**:
  - 维护节假日日历，计算月工作日系数
  - 调整月销量 = 原始值 ÷ (工作日/21)
  - 工作日 < 标准70%的月不计入"零采购"
- **当前状态**: 未实现（数据以月聚合形式进入分析）

### 1.6 库存联动

- **原设计**:
  - 产品四分类：畅销品/呆滞可激活/呆滞风险/成长储备
  - 库存周转天数计算
  - 阶梯折扣+互补品打包
- **当前状态**: 未实现（库存数据未纳入源数据）

### 1.7 产品结构迁移分析 (G4深度)

- **原设计**:
  - 各产品线收入/毛利占比月度变化图
  - 结构贡献度分析 = Δ占比 × 毛利率差异
  - 月度热力图标记突然新增/消失的产品线
- **当前状态**: 基础品种集中度已实现，迁移分析依赖BI工具配置

### 1.8 毛利率三因子拆解

- **原设计**:
  - Δ毛利 ≈ Δ数量×期初单位毛利 + Δ单价×期末数量 - Δ成本×期末数量
  - 三因子瀑布图（数量/价格/成本）
- **当前状态**: 未实现（依赖成本字段细粒度可用性）
