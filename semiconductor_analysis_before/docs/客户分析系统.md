## 1. 系统概述

客户分析系统从共享Silver层读取数据，输出客户全景画像、RFM-π评分、机会/风险评分、定价建议、行动建议等。

### 运行流

```
Silver层(3张聚合表)
  ↓ calc_customer_portrait()
客户全景(60+指标/每客户)
  ↓ score_rfm_pi()          → RFM-π综合分 + S/A/B/C分层
  ↓ score_opportunity()      → 机会分(0-100) + 极高/高/中/低
  ↓ score_risk()             → 风险分(0-100) + 极高/高/中/低
  ↓ generate_action_suggestions() → 行动建议(规则引擎)
  ↓ classify_customer_journey_stage() → 客户旅程阶段 (7阶段)
  ↓ batch_calc_volatility()  → 采购波动性指标 (CV/跌幅/等级)
  ↓ batch_estimate_true_profit() → 估算真实利润 (扣除服务成本)
  ↓ generate_gold_tables()
8+张Gold层CSV + Excel报告
```

### 入口

```bash
python run_customer.py     # 单独运行
python run_all.py           # 全部运行
```

## 4. RFM-π评分

### 4.1 评分维度

| 维度 | 列名 | 方向 | 权重(默认) |
|------|------|------|-----------|
| R(近度) | 距上次采购天数 | 越小越好 | 30% |
| F(频次) | 常规平均采购间隔 | 越小越好 | 20% |
| M(金额) | 近12月毛利 | 越大越好 | 30% |
| π(新品) | 新品采购占比 | 越大越好 | 20% |

### 4.2 评分方法

每个维度使用 `pd.qcut` 五分位法打分1-5分：

| 方向 | 5分 | 4分 | 3分 | 2分 | 1分 |
|------|-----|-----|-----|-----|-----|
| 反向(R/F) | 最短20% | 次短20% | 中间20% | 次长20% | 最长20% |
| 正向(M/π) | 最高20% | 次高20% | 中间20% | 次低20% | 最低20% |

### 4.3 综合分层

```python
RFMπ_综合分 = R_得分×0.30 + F_得分×0.20 + M_得分×0.30 + P_得分×0.20
```

| 综合分 | 层级 |
|--------|------|
| ≥ 4.0 | S级 |
| 3.5 ~ 4.0 | A级 |
| 2.5 ~ 3.5 | B级 |
| < 2.5 | C级 |

### 4.4 渠道隔离评分（v1.1新增）

直销客户（终端厂商）和代理客户（渠道分销商）的采购行为本质不同——直销客户单量大、毛利高，代理客户品种分散、毛利低。
混合评分时代理客户在R/F/M维度全面偏低，分层失去意义。

**渠道隔离评分** = 按 `渠道类型`（直销/代理）分组后分别做 `pd.qcut` 五分位排名 + 使用渠道特定权重：

| 渠道 | R权重 | F权重 | M权重 | P权重 |
|------|-------|-------|-------|-------|
| 直销(direct) | 30% | 20% | 30% | 20% |
| 代理(agent) | 25% | 25% | 25% | 25% |

```python
# 启用渠道隔离
df = score_rfm_pi(df, channel_col="渠道类型", weights_by_channel=RFM_PI_WEIGHTS)
```

> 当某渠道客户数 < 5 时无统计意义，自动回落为统一评分（默认权重）。
> 配置位置：`config/settings.py` → `RFM_PI_WEIGHTS`

## 7. 价格治理体系

### 7.1 价格偏离度

`calc_price_deviation()` — 所有函数在 `shared/pricing.py`。

```
偏离度 = (客户平均价 - 全市场中位价) / 全市场中位价
正 = 买得贵, 负 = 买得便宜
最低月数要求: CUSTOMER_THRESHOLDS.price_deviation_min_months (默认3)
```

### 7.2 价格带分布

`calc_price_band_distribution()` — 按P25/P75分界，将价格分为低价/中价/高价带。

### 7.3 跨客户价格离散度

`calc_cross_customer_price_dispersion()` — 变异系数(CV)法

| 条件 | 结论 |
|------|------|
| CV > 0.30 | 标记"价格混乱" |

## 9. 生命周期阶段

### 9.1 客户生命周期

`calc_customer_lifecycle_stage()` — 6阶段判定：

| 阶段 | 判定条件 |
|------|---------|
| 导入期 | 首次采购距今 ≤ 12月 |
| 爬坡期 | 近N月环比 ≥ 阈值(默认0.05/3月) |
| 成熟期 | 月收入在均线±Nσ内稳定 |
| 衰退期 | 连续3月低于均线15% |
| 休眠期 | 180~360天无采购 |
| 流失期 | ≥ 360天无采购 |

> 爬坡期参数由 `CUSTOMER_THRESHOLDS` 配置（批次A新增）。

### 9.2 SKU生命周期

`calc_sku_lifecycle_stage()` — 5阶段状态机：

| 阶段 | 条件 |
|------|------|
| 导入试销 | 在售<3月+低量 |
| 成长爬坡 | 近3月环比>增速阈值 |
| 平稳成熟 | 持续>6月 |
| 隐性衰退 | 连续下滑但总量可观 |
| 衰退出清 | 连续下滑+低于峰值30% |

## 13. B2B客户评分系统 v2

> 新增模块位于 `src/` 目录下，Task 1/5/6 实现。

### 13.1 客户旅程阶段 (Task 1)

`src/journey/stage_classifier.py` — 7阶段分类器，优先级顺序：

| 优先级 | 阶段 | 判定条件 |
|--------|------|---------|
| 1 | 激活期 | 历史有 >180天间断后重新交易 |
| 2 | 导入期 | 首次交易 ≤6月 且 总订单 ≤3 |
| 3 | 流失期 | 距上次 >90天 且 近6月无交易 |
| 4 | 衰退期 | 近6月环比跌幅 ≥20% 且 连续下滑 ≥2月 |
| 5 | 成长期 | 近6月环比增长 ≥30% 或 频次激增 ≥2倍 |
| 6 | 成熟期 | 近12月CV <0.3 且 金额排名前30% |
| 7 | 稳定期 | 默认兜底，不符合以上任何条件 |

> 成熟期金额排名在 `classify_customer_journey_stage()` 中修正。如传入 `channel_map`（{客户编号: 渠道类型}），则按渠道分组 percentile 排名；否则全局排名。不满足排名则降级为稳定期。
> 配置位置：`config/settings.py` → `CUSTOMER_JOURNEY_THRESHOLDS`

**输出字段**（合并入`客户全景.csv`）：客户旅程阶段、阶段持续月数、阶段转换次数、首次交易日期、距上次采购天数、近6月交易额环比增长率、近12月交易额CV

### 13.2 采购波动性指标 (Task 5)

`src/behavior/volatility.py` — 4项指标 + 稳定性分级：

| 指标 | 计算方式 |
|------|---------|
| 收入CV | 月度金额标准差 / 均值 |
| 最大单月跌幅 | max(月环比下跌比例) |
| 零采购月占比 | 零金额月数 / 总月数 |
| 趋势R² | 线性回归拟合优度 (≥3点) |

**稳定性等级**：

| 等级 | 条件 |
|------|------|
| 高稳定 | CV <0.3 且 零月占比 <10% |
| 中等稳定 | CV <0.6 且 零月占比 <20% |
| 高波动 | 其他（含数据不足） |

> 配置位置：`config/settings.py` → `VOLATILITY_METRICS`

**输出字段**（合并入`客户全景.csv`）：收入CV、最大单月跌幅、零采购月占比、趋势R²、稳定性等级

### 13.3 估算真实利润 (Task 6)

`src/profitability/true_profit_estimator.py` — 在毛利率基础上扣除服务成本：

```
真实利润 = 近12月毛利 - 订单处理成本 - 物流成本 - 售后成本 - 资金占用成本
```

| 成本项 | 默认参数 | 计算依据 |
|--------|---------|---------|
| 订单处理成本 | 50元/单 | `订单数` × 单价 |
| 物流成本 | 营收2% | 营收 × `logistics_cost_rate`（半导体行业量级大，不宜按件计费） |
| 售后成本 | 退货金额×30% | 无退货金额时按营收×2%×30%估算 |
| 资金占用成本 | 年利率6% | 应收账款 × 利率 × DSO/365 |

> DSO按客户等级（来自 `config/settings.py` → `CREDIT_THRESHOLDS`）：A=45天, B=60天, C=90天
> 配置位置：`config/settings.py` → `ESTIMATED_COST`

**利润等级**：真实利润率 >15% = 高利润, >0% = 微利, ≤0% = 亏损

**输出字段**（合并入`客户全景.csv`）：估算真实利润、估算真实利润率、利润等级、订单处理成本、物流成本、售后成本、资金占用成本
