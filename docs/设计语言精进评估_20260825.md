# 设计语言精进评估（参照 tabler/tabler）

> 日期：2026-08-25 | 触发：用户反馈"现在的看板看起来比较土，元素/组件比较凌乱"，并提供 https://github.com/tabler/tabler 作为参考
> 约束：单文件 HTML + 内嵌 ~30MB JSON + ECharts 主导 + 无构建工具链——**只能借鉴 tabler 的视觉规范（token/组件），不能整包引入**

## 一、tabler 是什么（调研结论）

tabler/tabler = 基于 Bootstrap 5 的开源设计系统：Geist 字体族、干净的卡片/表格/标签/徽章/按钮组件规范、`preview/` 下有完整 dashboard 示例（index/cards/tables/datatables 等页）。它的"高级感"来源不是组件多，而是**规范严**：统一的间距阶梯、字重阶梯、色彩语义、阴影层级、空状态。

## 二、现状评估（template.html 当前版）

我们的模板其实已有一套设计令牌（`--primary` 蓝色系、阴影/圆角 token、`.kc` 卡片、`.data-table`），方向与 tabler 同属 Bootstrap 式浅色系——**底子不差，输在一致性**：

| 现状问题 | 具体表现 |
|---|---|
| 组件体系并存 | `.cb`/`.kc`/`.bs`/`.ig`/`.rg` 多套卡片样式并存，padding/阴影不统一 |
| 字体层级混乱 | 系统字体 + 图表内字体各自为政，字重阶梯不明确 |
| 表格规范不一 | `.data-table`/`.esr-tbl`/`.crow`/`.brow`/`.d-row` 五种表格各行其是（密度、斑马纹、表头粘性不一致） |
| 色彩语义漂移 | 红/黄/绿的使用场景没有统一规则（有时红=坏，有时红=重点） |
| 空状态/加载态缺失规范 | 有无数据的呈现各面不同 |

## 三、最值得改的 8 个点（不动技术栈，只收规范）

| # | 改进点 | 做法 | 收益 |
|---|---|---|---|
| 1 | **卡片体系统一** | 收敛 `.cb`/`.kc`/`.bs`/`.ig` 为两级（KPI 卡 / 内容卡），统一 padding 16px、圆角 12px、阴影一档 | 视觉立刻整齐 |
| 2 | **字体与字重阶梯** | 定三级：标题 600/正文 400/辅助 400-muted；图表字体随页面 | 高级感最大来源 |
| 3 | **表格规范收敛** | 五种表格合并为 `.data-table` 一种：紧凑行高、细线分隔、表头 sticky、斑马纹可选 | 凌乱感主因 |
| 4 | **色彩语义规则** | 红=负向/风险、黄=关注、绿=正向、蓝=主交互——写进设计令牌注释，全模板扫一遍 | 语义不再漂移 |
| 5 | **tab 栏选中态** | 参考 tabler：选中 tab 下划线加粗+主色，未选中弱化；当前已有雏形，微调间距与字重 | 导航清晰 |
| 6 | **KPI 卡片规范** | 标签小字 muted、数值大字 tabular-nums、副标题一行截断、图标统一右上角淡色底 | 首屏档次 |
| 7 | **空状态统一** | 统一的空状态组件（淡图标+一句话），替换各面的零散空态 | 细节完整度 |
| 8 | **间距阶梯** | 页面级 20px、卡间 14px、卡内 10px 固定阶梯，清理各处手写 margin | 呼吸感 |

## 四、建议路径

1. **本期（推荐）**：做"token 统一 + 组件收敛"设计债清理——只动 CSS 令牌与组件类，不动 HTML 结构、不动 JS、不动数据。风险最低，视觉收益最大。可由设计师配额恢复后实施，验收走 golden_diff 零漂移 + 结构探针。
2. **远期**：若哪天重写前端（如拆多页/引入构建链），再评估整包引入 tabler 或同类（也看过有 geeky 的 dashboard kit，但都要求构建链，与当前单文件架构不兼容）。

## 五、不做什么

- 不引入 Bootstrap/tabler 的 CSS 包（文件体积 + 与现有令牌冲突 + 构建链不兼容）
- 不改 ECharts 配置体系（图表库自身的视觉规范另行统一即可）
- 不改任何数据与口径
