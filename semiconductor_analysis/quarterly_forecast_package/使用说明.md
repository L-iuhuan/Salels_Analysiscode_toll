# 产品线季度预测工具使用说明

本文档说明 `analysis/quarterly_forecast/` 下产品线季度预测工具的完整使用方式，包括：

- 全量回测模式
- 锁定方法模式
- 数据源/工作表/字段名配置
- 输出文件说明
- HTML图表说明
- 数据更新后的操作流程
- 拷贝到其他电脑运行的注意事项

---

## 1. 工具目标

该工具用于从原始出货明细 Excel 中直接生成产品线级季度分析与预测结果。

核心输出是一张可以直接用于图表和经营分析的合并表：

```text
产品线 × 历史12个滚动3个月桶 + 未来4个预测桶
```

历史和预测不分开输出，而是在同一张表中通过 `数据类型` 字段区分：

```text
历史 / 预测
```

## 6. 运行模式

工具支持两种主要模式：

1. 全量回测模式
2. 锁定方法模式

---

## 7. 全量回测模式

### 7.1 使用场景

全量回测模式适合：

- 第一次建模。
- 数据结构或业务结构发生明显变化。
- 新增很多产品线或客户。
- 想重新评估所有候选方法的准确度。
- 想生成完整的回测明细。

### 7.2 运行命令

使用默认数据和默认输出目录：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py
```

使用配置文件：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py \
  --config analysis/quarterly_forecast/forecast_config.default.json
```

指定数据文件：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py \
  --data data/新的出货明细.xlsx
```

指定工作表：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py \
  --data data/新的出货明细.xlsx \
  --sheet 出货明细
```

指定输出目录：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py \
  --output output/quarterly_forecast_202606
```

### 7.3 快速测试模式

快速测试模式只跑前120个候选方法，用于检查流程是否能跑通：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py --fast
```

注意：

- `--fast` 不建议作为正式结果。
- 正式结果建议使用全量模式或锁定模式。

### 7.4 全量模式输出特点

全量模式会：

1. 读取原始Excel。
2. 清洗数据。
3. 回填缺失产品线。
4. 生成历史12个滚动3个月桶。
5. 生成产品线、产品、产品×客户聚合。
6. 生成552种候选预测方法。
7. 对每条产品线、每种方法做6折滚动回测。
8. 生成完整回测明细。
9. 为每条产品线选择综合评分最优的方法。
10. 预测未来4个桶。
11. 生成CSV、Excel、HTML图表。

## 8. 锁定方法模式

### 8.1 使用场景

锁定方法模式适合：

- 已经做过一次全量回测。
- 已经认可某次排行榜中的最优方法。
- 后续只是更新数据，快速生成新报表。
- 希望每次刷新预测口径稳定。
- 不想每次都花时间跑完整回测。

### 8.2 前提条件

必须先有一个全量模式生成的排行榜文件，例如：

```text
output/quarterly_forecast/预测方法排行榜.csv
```

排行榜中每个产品线应有：

```text
是否最终选中 = 是
```

或：

```text
排名 = 1
```

### 8.3 运行命令

使用默认配置 + 锁定方法：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py \
  --config analysis/quarterly_forecast/forecast_config.default.json \
  --method-lock output/quarterly_forecast/预测方法排行榜.csv \
  --output output/quarterly_forecast_locked
```

指定新数据文件 + 锁定方法：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py \
  --data data/新的出货明细.xlsx \
  --method-lock output/quarterly_forecast/预测方法排行榜.csv \
  --output output/quarterly_forecast_new
```

指定新配置 + 锁定方法：

```bash
python analysis/quarterly_forecast/run_quarterly_forecast.py \
  --config analysis/quarterly_forecast/你的配置.json \
  --method-lock output/quarterly_forecast/预测方法排行榜.csv
```

### 8.4 锁定模式输出特点

锁定模式会：

1. 读取新数据。
2. 重新生成历史12桶。
3. 读取旧排行榜中的选中方法。
4. 跳过全量回测。
5. 直接按锁定方法生成未来4桶预测。
6. 输出CSV、Excel、HTML图表。

### 8.5 锁定模式注意事项

锁定模式的 `预测方法回测明细.csv` 是空表或仅有表头，因为它不重新回测。

如果需要重新评估方法准确度，请使用全量回测模式。

## 12. 预测上下限说明

预测上下限基于回测误差生成。

以销售额为例：

```text
销售额预测下限 = 预测销售额 × (1 - 销售额WAPE)
销售额预测上限 = 预测销售额 × (1 + 销售额WAPE)
```

为了避免区间过窄或过宽，程序做了保护：

```text
误差带最低 5%
误差带最高 80%
```

因此图表中的预测上下限是“基于历史回测误差的经验区间”，不是严格统计置信区间。

---

## 13. WAPE说明

WAPE 是 Weighted Absolute Percentage Error，即加权绝对百分比误差。

公式：

```text
WAPE = sum(abs(预测值 - 实际值)) / sum(abs(实际值))
```

例如销售额WAPE = 0.10，表示：

```text
历史回测中，该方法的整体销售额预测误差约为10%。
```

WAPE比MAPE更适合经营预测，因为它按金额加权，不会被极小销售额样本过度放大。

## 14. 数据清洗规则

程序默认做以下处理：

1. 发货日期转为日期格式。
2. 数值字段转为数字。
3. 剔除 `发货数量 <= 0` 的记录。
4. 剔除发货日期缺失的记录。
5. 剔除存货名称缺失的记录。
6. 产品线缺失时，优先按 `存货名称` 的历史最常见产品线回填。
7. 仍无法回填的产品线标记为 `未分类`。

历史毛利额直接使用原始 `利润` 字段汇总。

## 15. 方法选择逻辑

全量回测模式下，程序会生成552种候选方法。

方法层级包括：

- 产品线级销量 × 产品组合ASP
- 产品级销量 × SKU最近ASP
- 产品×客户级销量 × SKU最近ASP
- 产品线销售额直接预测
- 产品级销售额直接预测
- 产品客户级销售额直接预测

基础算法包括：

- 最近值
- 均值
- 中位数
- 线性加权均值
- 指数加权均值
- 线性趋势
- 对数线性趋势
- 漂移
- 同比季节
- 衰减趋势
- 保守增长
- 保守衰减

每个产品线独立选择综合评分最低的方法。

综合评分以销售额WAPE为主，同时考虑：

- 销售额MAPE
- 销售额偏差率
- 销量WAPE
- 毛利额WAPE
- 毛利率MAE

## 17. 常见问题

### Q1：为什么锁定模式下回测明细为空？

因为锁定模式跳过了全量回测，只使用已有排行榜中的选中方法。

如果需要回测明细，请跑全量模式。

### Q2：为什么HTML打开没有图？

当前版本已经不依赖外部库。如果仍看不到，请检查：

1. 浏览器是否过旧。
2. 文件是否完整复制。
3. 是否打开的是旧版本HTML。
4. 是否有浏览器安全策略禁用本地JS。

建议使用 Chrome 或 Edge 打开最新生成的：

```text
output/quarterly_forecast_locked/产品线季度预测图表.html
```

### Q3：新Excel字段名不同怎么办？

修改配置文件中的 `field_map`。

左边保持标准字段不变，右边改成新Excel里的真实字段名。

### Q4：工作表名不同怎么办？

修改配置文件中的：

```json
"sheet_name": "你的工作表名"
```

或命令行指定：

```bash
--sheet 你的工作表名
```

### Q5：能不能只生成图表不重新预测？

当前主程序会重新读取数据并生成结果。若后续需要，可以增加一个单独的 `--chart-only` 模式，从已有CSV生成HTML。

### Q6：预测上下限是不是严格置信区间？

不是。当前上下限是基于历史回测WAPE的经验区间，适合经营展示和风险提示，不是严格统计置信区间。
