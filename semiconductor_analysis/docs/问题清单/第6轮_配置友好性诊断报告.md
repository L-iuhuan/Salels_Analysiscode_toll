## 详细发现

### P0-6-1: 无双击运行能力（无.bat/.exe）

- **表现**: 项目没有任何 `.bat` 文件或可执行文件包装
- **测试**: 双击 `run_all.py` — 控制台窗口一闪而过（即使程序正常运行，用户也看不到输出）
- **影响**: 业务用户小明不知道 `python run_all.py` 是什么意思，也无法从双击得到任何反馈
- **归因**: C（体验缺失）

### P0-6-2: 无依赖检查和安装引导

- **表现**: 三个入口脚本（`run_all.py:21-22`、`run_product.py`、`run_customer.py`）顶部直接 `import pandas` 等，不检查是否已安装
- **报错**: 未安装 pandas 时显示英文回溯: `ModuleNotFoundError: No module named 'pandas'`
- **影响**: 用户看到满屏英文错误代码，不知道如何修复
- **有对比**: `shared/forecasting.py` 中有条件 import 的降级 (`print("...ETS未安装...")`)，但入口脚本没有
- **归因**: C（体验缺失）— 应有醒目的中文引导，告诉用户运行 `pip install ...` 或执行某个安装脚本

### P1-6-1: 全项目无日志系统 (logging=0)

- **表现**: 70+ Python 文件中 `import logging` 次数为 **0**
- **问题**: 所有输出使用 `print()` 混入 stdout，无 INFO/WARN/ERROR/DEBUG 分层
  - 进度消息 `[时间] 客户分析总计: ...s`
  - 警告 `[警告] 产品 XXX ETS预测失败`
  - 错误 `[致命] Silver层构建失败`
  - 性能计时 `[时间] 产品生命周期总计: ...s`
  - 全部混合在一起，无法过滤
- **影响**: 
  - 无法实现静默/详细模式切换
  - 生产环境中日志无法路由到文件
  - 调试时需要从进度输出中人工筛选错误信息
- **归因**: C（架构债）— 属于已识别的工程债务

### P1-6-2: `config/settings.py`内含Python代码

- **细节**: 配置文件是 `.py` 文件而非 `.json`/`.yaml`/`.toml`
- **关键障碍点（对小明来说）**:
  - 第14行 `import os` — 纯编程语句
  - 第21行 `PROJECT_ROOT = os.path.abspath(os.path.join(...))` — 嵌套函数调用
  - 第924行 `ref_priority` 使用 Python 元组语法 `("型号_产品品类", 3)`
  - `True`/`1` 混用（第667行 `"enabled": True` vs 第906行 `"hist_portrait_enabled": 1`）
- **影响**: 小明打开"配置文件"，看到的是Python代码，不是表格或键值对
- **归因**: C（架构债）

### P1-6-3: `PRODUCT_LIFECYCLE` 80+配置项零注释

- **文件**: `config/settings.py:771-938`（168行）
- **表现**: 80+个配置键，**零个**有行内注释说明用途、取值含义或示例
- **例子**:
  - `"growth_accelerate": 0.15` — 0.15是什么意思？增长加速阈值？加速多少？范围是多少？
  - `"cv_low": 0.5` — CV是什么？0.5是高还是低？
  - `"pareto_key_revenue": 100` — 单位是万？元？100什么？
- **对比**: `CUSTOMER_THRESHOLDS` 段（第147-204行）有详细的中文注释和回退方案说明
- **影响**: 小明想调整参数但无从下手
- **归因**: C（体验缺失）

### P1-6-4: 报错信息缺少修复引导

- **表现**: 虽然有中文报错，但大多只描述问题，不告诉用户"怎么做"
- **例子**:
  - `[致命] Silver层构建失败` → 没有说"请检查 data/ 目录是否有可读的Excel文件"
  - `[错误] 未找到源数据文件` → 没有说"请将Excel文件放入 data/ 目录，或使用 --data 参数指定路径"
  - `ModuleNotFoundError: No module named 'pandas'` → 英文回溯，没有"请运行 pip install pandas"提示
- **有对比**: 第111-114行的列缺失检查提供了"请检查：1) ERP_COL_MAP... 2) 数据文件列名..."的指导——这是正确的做法，但其他错误消息未采用此格式
- **归因**: C（体验缺失）

### P2-6-1: 入口脚本缺少 `if __name__` 守卫

- **文件**: `run_product.py`、`run_customer.py`
- **表现**: 两个脚本都是5行，顶级代码直接执行，无 `if __name__ == "__main__":` 保护
- **风险**: 如果从其他地方 `import run_product`，会意外启动完整分析流程
- **归因**: B（代码质量）

### P2-6-2: 内部术语未对用户解释

- **表现**: 所有文档和帮助信息使用内部术语而不加解释
  - "Silver层" — 为什么叫Silver？不是清洗后的数据吗？
  - "Gold层" — 分析结果为什么叫Gold？
  - "KPI通道" — 通道是什么？准实时又是什么？
  - "交叉关联" — 谁和谁关联？
- **影响**: 小明在argparse帮助中看到 `--stage silver,customer` 时不知道应该选哪个
- **归因**: C（体验缺失）

### P2-6-3: 运行结束后无输出告知

- **表现**: 管道运行完成后，没有自动打开输出目录或报告文件的引导
- **对比**: Windows应用通常运行结束后会"打开文件所在位置"或直接打开生成的报告Excel
- **影响**: 小明运行完不知道结果在哪里
- **归因**: C（体验缺失）

### P3-6-1: 全文件缺少举例值

- **表现**: 1087行的 settings.py 中没有任何 `例如:` 或 `e.g.:` 示例值
- **例子补充**（需要添加的）:
  - `"churn_multiplier": 1.5` → `# 例如: 平均采购间隔30天×1.5=45天预警`
  - `"sku_intro_max_months": 3` → `# 例如: 在售≤3个月视为导入试销期`
  - `"cv_low": 0.5` → `# 例如: CV<0.5为低波动，0.5-1.0为中波动`
- **归因**: C（体验缺失）

### P3-6-2: `COL_MAP` 缺少注释

- **文件**: `config/settings.py:64-85`
- **表现**: 部分列映射缺少注释说明
  - `"quantity": "数量"` — 单位是什么？是净数量还是毛数量？
  - `"cost": "成本"` — 总成本还是单位成本？
  - `"profit": "利润"` — 毛利润还是净利润？
- **归因**: C（文档缺失）

## 《第一次使用指南》草案

> **目标读者**: 小王，业务分析师，熟练使用Excel，从未用过命令行或Python
> **形式**: 假设放在项目根目录的 `第一次使用.html` 或打印版PDF

---

### 第0步：检查电脑有没有Python

1. 按 `Win + R`，输入 `cmd`，回车
2. 在黑色窗口中输入 `python --version` 回车
3. 如果看到 `Python 3.x.x` → 到第1步
4. 如果看到 `'python' is not recognized` → 需要安装Python：
   - 打开 https://www.python.org/downloads/
   - 下载最新版Python
   - **安装时务必勾选 "Add Python to PATH"**
   - 安装完成后重新打开cmd，输入 `python --version` 验证

### 第1步：安装需要的工具包

1. 在cmd窗口中（确保当前在项目目录）
2. 粘贴以下命令并回车（复制全部，粘贴到cmd窗口）：
```
pip install pandas numpy openpyxl statsmodels chinese_calendar rapidfuzz matplotlib scikit-learn
```
3. 安装过程会有滚动文字，等待出现 `Successfully installed ...` 即可
4. 如果遇到红色错误说 `pip` 不是命令，请用 `python -m pip install ...` 替代

### 第2步：准备数据文件

1. 从ERP导出交易明细Excel文件
2. **必需列**: 客户编号、产品名称、发货数量、金额（不含税）、发货日期
3. **可选列**: 利润、成本、单价、产品分类、是否新品、渠道类型、客户等级
4. 将文件放入项目目录下的 `data/` 文件夹（双击打开 `data/` 目录，把Excel文件拖进去）

### 第3步：双击运行（方式A）

1. 在项目目录中找到 `双击运行全部.bat`（如果没有，见下方"创建.bat文件"）
2. 双击它
3. 你会看到一个黑色窗口滚动显示运行进度
4. 当出现 `按任意键退出...` 时，表示运行完成
5. 结果在 `output/report/` 和 `output/gold/` 目录下

### 创建.bat文件（如果没有）

新建一个文本文件 `双击运行全部.txt`，打开粘贴以下内容，保存后把后缀从 `.txt` 改成 `.bat`：
```bat
@echo off
chcp 65001 >nul
echo ========================================
echo  半导体销售数据分析系统 - 一键运行
echo ========================================
echo.
echo 正在检测 Python 环境...
python --version >nul 2>&1
if errorlevel 1 (
    echo [错误] 未检测到 Python，请先安装 Python
    pause
    exit /b
)
echo 正在检查依赖包...
python -c "import pandas" >nul 2>&1
if errorlevel 1 (
    echo [错误] 缺少 pandas 等依赖包
    echo 请运行: pip install pandas numpy openpyxl statsmodels chinese_calendar rapidfuzz
    pause
    exit /b
)
echo 依赖检查通过，开始运行...
echo.
python run_all.py
echo.
echo 运行完成！
echo 报告已生成至: output/report/
echo 数据表已生成至: output/gold/
echo 按任意键退出...
pause >nul
```

### 第2.5步（可选）：调整参数

如果你需要修改分析参数：
1. 用 **记事本**（不要用Excel）打开 `config/settings.py`
2. 里面有很多 **用中文标注** 的配置项，修改数字即可
3. ⚠️ **不要删掉冒号、逗号、引号这些符号**，只改数字

## 改进优先级建议

### 立即执行（1小时内，零代码经验即可）
1. **创建 `run_all.bat`** → 样板代码已在上方《第一次使用指南》中提供
