## 三、关键发现

1. **核心盘可预测性好**：营收大头（通用电源管理 12.4 亿、有刷直流 2.9 亿、充电与控制 8476 万等）WAPE 6~15%——「预测准确率不高」在核心业务上不成立，此前观感大概率来自长尾线与早期方法未筛。
2. **方法无单一王者**：18 线冠军中 趋势族 7 胜 / 季节族 4 胜 / 业务规则 3 胜 / 基线 3 胜——**按线独立选择**（本框架做法）正确，强推单一模型会劣化。
3. **系统性偏差可见**：磁传感 -12%、车规电机 -16.2%、电源模组 -40.6%、dTOF -19.9%（预测偏低）；MLED +30.7%（偏高）——|偏差|>10% 的线可做系数校正或选用低偏差方法。
4. **C 档问题本质是数据**：新品（1 桶）/微线（24 万）/收缩线/脏分类——统计预测无意义，应走特殊通道。

## 四、待决策（选好后固化，再做看板）

1. **冠军方案**：是否接受 18 线自动选中结果？某线是否指定换方法（排行榜 CSV 可查每线全部 552 方法排名）。
2. **C 档 5 线处置**：按上表建议（数据治理/新品观察/人工/不预测）还是另定。
3. **偏差校正**：|偏差|>10% 的线是否启用系数校正。
4. **客户维度**：是否加跑 `run_customer_forecast.py`（KA/AA 客户级筛选回测）。
5. **固化与刷新**：选定后用 `--method-lock` 锁定方法表（后续月度刷新 1~2 分钟），是否作为月度 SOP 步骤。
