4. **代码依赖**：import 图、模块间依赖关系
5. **死代码**：未使用函数、未使用参数、不可达代码、重复定义

- **行为验证建议**：每项修复均给出可执行的验证方法

| 类别 | 数量 | 最关键问题 |

## 2. 架构分析

### 2.1 模块分层

```
L5 编排层
    run_chain.py          → subprocess 编排 processing + dashboard
    dashboard/generate_dashboard.py  → 独立入口，直接读 data/ 和 output/

L4 应用层
    run_all.py            → 主入口，stage_silver/product/customer/kpi/cross_ref
    core/pipeline.py      → DI 容器版（半成品，仅 --pipeline 可达）

L3 领域层
    product_lifecycle/    → 产品生命周期分析
    customer_analysis/    → 客户分析、画像、评分
    cross_reference/      → 交叉引用
    analysis/             → 定价、RFM-π、评分、b2b适配器
    b2b_v2/               → 客户旅程、行为、异常、动作

L2 基础设施层
    shared/               → 数据清洗、计算工具、风险评分、分类器、预测
    data_pipeline/        → DI 包装器（loader/cleaner/aggregator/validator）

    config/settings.py    → 主配置，通配符导入 settings_product/customer
    config/settings_product.py
    config/settings_customer.py

L0 外部入口
    chain_config.json     → 仅 run_chain.py 读取
```

### 2.2 关键发现：两套并行管道

存在两套实现但功能重叠的管道：

| 维度 | run_all.py | core/pipeline.py |
|------|-----------|------------------|
| 类型 | 过程式编排 | DI 容器式 |
| 生产使用 | 是，run_chain.py 调用 | 否，仅 --pipeline 标志 |
| Silver 构建 | 内联实现 | 不完整（缺 cust_info、CSV 写入） |
| 接口使用 | 直接函数调用 | Protocol（13 个，大多未实现） |
| 状态 | 成熟但混乱 | 半成品、死代码 |

**结论**：`core/pipeline.py` 是未完成的替代方案，实际生产路径是 `run_all.py`。

### 2.5 抽象质量评估

#### 职责分离问题

1. **Dashboard 是独立王国**：2000+ 行脚本，直接读 Excel、自己清洗聚合、绕过配置
2. **Silver 层三处构建**：逻辑分散，客户信息处理不一致
3. **analysis/b2b_adapters.py 是死适配器**：生产代码直接调 b2b_v2，绕过它

### 3.2 主要维度清单

| 维度类别 | 代表维度 | 定义位置 | 说明 |
|----------|----------|----------|------|
| **客户维度** | 客户编号、客户类别、渠道类型、客户等级、区域、业务员 | `portrait.py` | 来自客户信息表或 ERP 推导 |
| **时间维度** | _月、近12月、前12月、YoY、环比 | `portrait.py`, `trend_analysis.py` | 月度聚合 |
| **产品维度** | 产品品种、产品线、产品系列、品类 | `ERP_COL_MAP` | SKU/品类多级 |
| **收入维度** | 收入、数量、ASP、增长率 | `portrait.py` | 收入增长率有 clip 限制 |
| **毛利维度** | 毛利率、毛利跌幅、自比健康度、他比健康度 | `profiling.py`, `portrait.py` | 产品/客户口径不同 |
| **风险维度** | 风险评分、综合风险等级 | `risk_scoring.py`, `profiling.py` | 4因素加权 |
| **生命周期维度** | SKU 生命周期阶段、客户旅程阶段 | `profiling.py`, `journey/stage_classifier.py` | 9宫格 / 7阶段 |
| **价格维度** | 价格弹性、价格敏感度、ASP 分位带 | `analysis/pricing/*.py` | P25/P75 分位 |
| **集中度维度** | Top3/Top5 集中度、HHI、强依赖标记 | `dimensions.py` | 品类/客户依赖 |

### 3.3 关键指标计算差异

| 指标 | 客户 pipeline | 产品 pipeline | 风险 |
|------|--------------|--------------|------|
| 负数量处理 | 保留（自然抵消） | 过滤（>0） | ⚠ 同一数据源不同处理 |
| 毛利率钳制 | 禁用 | 启用（-50% ~ +75%） | ⚠ 指标口径不一致 |
| winsorization 参数 | 有参数但不生效 | 生效 | ⚠ 配置项误导 |
| 收入增长率 clip | [-1.0, 5.0] | 类似 | 需确认 |
| 近12月定义 | 滚动12个月 | 滚动12个月 | 一致 |
