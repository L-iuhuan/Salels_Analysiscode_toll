## 三、数据处理考量全录（按链路顺序）

### 3.1 数据清洗层（run.py:153-251）

| 考量点 | 实现 | 设计意图 |
|---|---|---|
| **负销量过滤** | 口径开关 `_口径_负销量过滤`，**默认关闭**（run.py:197） | 平台口径与生产链一致：保留退货/红冲行自然冲减收入；历史 v2.8 行为（剔除）待业务拍板（D-2）后按需启用 |
| **毛利率钳制** | 口径开关 `_口径_毛利率钳制`，**默认不钳制**（run.py:213） | 默认保留真实毛利率、`_利润_裁剪=原始利润`；v2.8 的 clip(-0.5, 0.75) 行为由开关控制（D-1 业务拍板后启用） |
| 日期范围 | `data_start_date = 2020-01-01` 起滤（run.py:204） | 与长历史起点一致 |
| **不完整月剔除** | 最新月最大日期 < 25 号（`incomplete_month_threshold_day`）→ 剔除该月，基准月回退至上月（run.py:242-247） | 防止月末未结数据拉低近 12 月指标；按"该月内最大日期"而非全局最大日期判断 |
| 类型清洗 | 名称 strip / 数值 coerce+fillna(0) / 日期 coerce | NaN 销量按 0 处理（不丢行） |
| Silver 复用 | 产品管道 `save_cleaned_rows=True`、`cat_col_propagation=False`（run.py:144-145） | 行级数据供后续复用；customer_x_product 不携带分类 |

### 3.2 新品判定（Phase 2）

| 参数 | 值 | 说明 |
|---|---|---|
| `new_product_mode` | "月数" | 判定模式 |
| `new_product_months` | 6 | 首次出货距今 ≤6 月 |
| `new_product_min_volume` | 100 | 且累计销量 ≥100 件 |
| 权威标记 | ERP "是否新品" | 标记优先于自动判定 |

考量：ERP 标记是业务口径（纯标记占比 12.7% 曾用于 A 面卡），自动判定是统计兜底。

### 3.3 参照组体系（profiling.py:32 `_compute_reference_groups`，配置 ref_*）

**优先级回退链**（run.py:56 `ref_priority`）：`产品一级分类 →（全公司均值）`

| 参数 | 值 | 考量 |
|---|---|---|
| `ref_percentile` | 0.95 | 常规参照组取组内 p95（头部基准，代表"优秀水平"） |
| `ref_short_age_months` | 12 | 参照组产品年龄 <12 月时 |
| `ref_short_percentile` | 0.50 | 短历史组用 p50（中位数，样本少时防极端值） |
| `ref_long_months` | 24 | 长历史组 |
| `ref_long_percentile` | 0.80 | 长历史组用 p80 |
| `ref_p95_min_months` | 20 | p95 需要 ≥20 月历史才可靠 |
| `ref_robust_min_points` | 6 | 稳健计算最少数据点 |

考量：分位数随样本量自适应（短历史降级到中位数），避免小样本参照组被单个极端产品拉偏。

### 3.4 九宫格分类（nine_grid.py:97-127）

**两个维度**：
- 销量动能（近 12 月 vs 前 12 月）：`growth_accelerate=+15%` 加速 / `growth_flat_lower=-10%` 萎缩 / 其间为持平或稳定扩张
- 盈利健康（近 12 月毛利率 vs 参照基准）：`health_healthy=70%` 绝对健康线 / `health_severe=50%` 严重侵蚀线 / `health_relative=-10pp` 相对参照组下滑 10pp

**12 组合 → 9 画像映射**（nine_grid.py:108-121）：

| 动能\健康 | 健康 | 轻度侵蚀 | 严重侵蚀 |
|---|---|---|---|
| 加速增长 | **成长期**（投入区） | **健康扩张**（投入区） | **预警增长**（观察区） |
| 稳定扩张 | **健康扩张**（投入区） | **现金牛**（维持区） | **预警增长**（观察区） |
| 持平 | **利润优化**（维持区） | **现金牛**（维持区） | **隐性衰退**（观察区） |
| 萎缩 | **主动收缩**（观察区） | **夕阳产品**（退出区） | **衰退期**（退出区） |

（组合外 → "未分类/待观察"）

考量：管理层摘要四区（投入/维持/观察/退出）与画像绑定，直接对应资源分配动作。

### 3.5 上下文感知策略（nine_grid.py:27-94）

同一画像按实时数据分支细化建议：
- **衰退期**：毛利率同比回升 **>10pp** → 确认回升可持续性（主动清退低毛利客户则转主动收缩）；回升 ≤10pp → 观察是否暂缓退市；销量=0 → 确认实质退市清库存；否则量利双跌安排退市
- **夕阳产品**：回升 **>5pp** → 控制库存暂缓换代；小幅回升 → 规划替代型号上市时间
- **隐性衰退**：表面稳定实则利润被侵蚀，需预警
- **预警增长**：减收增利 → 关注回升；否则"销量增长掩盖利润恶化，立即查成本结构"

考量：策略文本外置到配置（`nine_grid_base_strategies`/`nine_grid_contextual_strategies`），代码带硬编码兜底——业务可改文案不动代码。

### 3.6 风险评分五因子（profiling.py:102 `_score_all_products`，配置）

| 因子 | 关键阈值 | 默认分 |
|---|---|---|
| **销量斜率** | slope_pct 三档：0 / -0.3 / -0.8（月降幅）；最少 3 个数据点，不足得 50 分 | 80 |
| **销量波动 CV** | 四档：0.5 / 1.0 / 1.5；脉冲值 0.5 | 85 |
| **衰减深度** | decay_high_pp=-10pp / decay_mid_pp=0 / decay_yoy_high=-10%；爆发性封顶 cap=1.0、阈值 -100、S4 封顶 50 | 20（衰减默认低分） |
| **自比健康度**（毛利率 vs 自身历史） | health_low/mid/high_pct = 70/50/30 | 50 |
| **ASP 趋势** | asp_pct：0 / -0.5 / -1.0；rising>+0.5 / falling<-0.5 | 80 |

**风险等级**（risk_low_max=55 / risk_mid_max=65 / risk_high_max=68）：≤55 低风险，56-65 中风险，66-68 高风险，>68 极高风险。

考量：
- **不可靠因子自动重加权**：某因子数据不足时（如斜率点数<3），其权重摊给其余因子，不产生 NaN 评分
- **衰退期兜底**：衰退期产品风险评分有最低分兜底（防五因子都"正常"却已萎缩的漏报）
- 收入增速钳制 `rev_growth_lower=-1.0 / upper=5.0`：客户分析侧不钳制会出现 3085% 极端值，产品侧钳制在 [-100%, +500%]

### 3.7 PIT 防泄漏（历史画像追踪，Phase 7）

- 每个历史截点 t-k **只用截点前的数据**重跑画像（`prod_month ≤ latest_month`，profiling.py r28 修复）
- `hist_portrait_points` 支持 `"auto_12"`（1~12 月全偏移）/ `"3,6,12"` 逗号串 / 单值 / 列表；当前生产配置 **t-1~t-20 全截点**
- 多进程并行加速，按时间顺序合并为画像变迁轨迹（供桑基图展示流转）

考量：2026-06 曾发现"当前画像泄漏进历史回测"问题（用当前快照预测历史），r28 已根治——这是 D2 预测实验（生命周期因子建模被证伪）的前置修复。

### 3.8 ETS 预测与 SKU 生命周期（Phase 6 + 辅助参数）

- ETS 状态空间模型（MLE 参数优化），**节假日调整**（chinese_calendar）+ 80%/95% 置信区间，数据不足回退 WMA
- SKU 导入期/退市判定：`sku_intro_max_months=3`、`sku_intro_min_qty=1000`、`sku_exit_ratio=0.30`（销量降至峰值 30% 以下）、`sku_decline_ratio=0.70`
- Pareto 分类：`pareto_key_revenue=100 万`（关键产品）、`pareto_regular_revenue=10 万`（常规）
- 长尾判定：`长尾销量阈值=1000` 件/年
