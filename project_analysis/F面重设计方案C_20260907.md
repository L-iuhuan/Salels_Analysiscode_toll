## 一、核心设计：窗口对窗口，彻底消灭锚月错位

### 1.1 对比基准重构（现状 vs 新设计）

| 指标 | 现状（缺陷设计） | 新设计 |
|---|---|---|
| 同比 | H1 vs 去年 H1（已有，正确） | 保留 |
| 环比 | 用全局"上一月"锚（**错位根源**） | **H1 vs 去年 H2**（半年对半年，窗口对窗口） |
| 月度环比 | mom/asp_mom 锚全局上月 | **窗口末月 vs 窗口前一月**（永远在窗口内取） |
| 新增 | — | 环比差额与增幅双展示（万元+%） |

### 1.2 窗口语义动态推导（S2 合规，零硬编码）

```
最新数据期 _latest_period = YYYYMM（现由数据推导）
当前半年度窗口 W_cur = _latest_period 落在 1-6 月 → 当年 H1；7-12 月 → 当年 H2
对比窗口 W_prev_half = 上一个半年度（H1 的前窗=去年 H2；H2 的前窗=当年 H1）
对比窗口 W_prev_year = 去年同期半年度（同比）
```

- **任何数据月份都自洽**：2-6 月跑批做 H1 复盘 ✓；8-12 月跑批做 H2 复盘 ✓；7 月（H2 刚开始）做 H1 复盘——W_cur 取"已完结的最近半年度"（去年 H2+当年 H1 中取已完结者），口径条披露
- 首销月/新品 cutoff 等既有动态推导逻辑不动

## 二、内容框架（保留现有维度，只换时间基准）

F 面现有五维对比全部保留，时间列从"全局锚"改为"窗口对"：

| 维度（现有 8c-8h 段） | 展示内容 | 时间基准改造 |
|---|---|---|
| 产品线 | 收入/毛利/毛利率 W_cur vs W_prev_half vs W_prev_year | 三列对比+变化幅度 |
| 品类 | 同上 | 同上 |
| 部门 | 现有 F_DEPT_MARGINS 表（asp_mom 全 0 的那张） | asp_mom 改"窗口末月 vs 前月"；补 W_cur vs W_prev_half 的 ASP 变化 |
| 客户（KA/AA） | 现有 F_KAAA_MARGINS 表 | mom 同上改造；mg_yoy/rev_yoy 保留 |
| 新品 | 新品在窗口内的收入占比与渗透 | 窗口内计算 |

**新增一个小节**：窗口概览卡（W_cur 收入/毛利/毛利率/客户数 vs 两个对比窗的差额与增幅）——一眼看到"这半年比上半年/去年同半年好还是差"。
