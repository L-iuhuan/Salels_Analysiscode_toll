## 二、交互修复方案

### 2.1 抽动根治：恒高上下文条 + 滚动浮现内容（Oracle 修订版）

- 现行：展开时在 `#bList` 顶部**插入** crumb div → 列表整体下移 = 抽动。
- **否决方案（Oracle P0）**：crumb 移入 `#bList` 内部做 sticky——renderBList/renderAgentList 每次 `innerHTML` 整体重建会把它抹掉；且与现有 sticky 表头 `.brow.hd`（top:0）叠位；插入首子节点还会翻转斑马纹奇偶。
- **采用方案**：`#bCrumb` 保持在滚动容器**外部**现位，代理模式下**恒定 32px 高度**（占位永不增删 → 展开/收起零位移，抽动根治）。内容按用户意图做滚动浮现：条内平时显示语境（"经销 · 124 家代理商"）；当展开的代理商表头行**滚出视口后**，条内容切换为"‹ 收起 · 经销 / 代理商名"（轻量 scroll 监听只改内容不改布局）。若监听实现有坑，降级为"展开即常驻显示收起"，效果等价。

### 3.3 数据设计（体积证据驱动 + Oracle P0 修订：改全内联）

**核心决策：存"范围成员 × 产品"的近 12 月月度稀疏单元，区间统计客户端现算。**

每对存：静态属性（品类/产品线/首销月）+ 预计算标量（**最近月**环比 mom、同比 yoy，服务端用全 31 月历史算好；列名锁死"最近月环比/同比"，不随区间变化，faces.yaml 披露——Oracle P1-3）+ R12 月度单元 `[{m,r,p,q}]`（只存有销量的月）。
**新品口径（实证定稿）**：gold 产品画像表 61 列无新品/首发字段（实读验证）→ 直接在 silver 行级复刻 C 面同款口径：**是否新品 = 品种级曾有 ERP 新品标记（含"是"）∩ 首销月 ≥ cutoff_new（=最新月-12，13 个月含界；G:253 实证，勿用 start_12m=p-11）**；产品键统一**产品品种**（C 面/B面 t5 同款；勿用 _prod 一级分类）。

## 五、顺带发现的生产缺陷（独立小工单，不在本批）——决策轮5深挖完毕

**parquet 双写在真实数据上失败**：`silver_cleaned_rows.parquet` / `silver_customer_x_product.parquet` 报 `ArrowTypeError: 产品品类列 int/str 混型`，仅警告不阻断 → 真实生产环境的 parquet 加速通道实际从未生效（靠 mtime 守卫回退 CSV 兜底，功能正确但 193MB CSV 读写税每次都在付）。
**根因实证**（真实 silver 直查）：「产品品类」列 54 行为数值 `0`（ERP 导出该单元格为数字，calamine 按 int 读取）+ 119 行空值 → object 列混型，Arrow 拒绝。
**修复方案**：parquet 写入前对**输出副本**的 object 列做 `astype(str)` 归一（`df_parquet = df.copy()` 后处理）——CSV 一字节不动（golden-diff 零接触），parquet 得纯净字符串列；修复后读侧自动切回 parquet 快路径，须按 S8 用生产加载语义做读写等价对拍。合成数据全 str 所以历次环境测试均未暴露——**教训已确认：探针必须用真实数据**。
