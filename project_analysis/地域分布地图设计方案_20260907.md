## 二、形态设计（渐进两步）

### 第一步：地域区块（A 面，0.5 天）

```
A 面新增「地域分布」section
┌ KPI 速览条 ──────────────────────────────┐
│ 广东占比 72% · 海外+港澳台 1% · 覆盖 16 省  │
├ Top10 省份条形图（收入+毛利率双轴） │ 海外/港澳台列表卡 │
│  条形可点击 → drawer 弹层            │  韩国·仁川 2,286万 ▾ │
│                                     │  台湾·新北 682万 ▾   │
│                                     │  香港·新界 283万 ▾   │
│                                     │  （各带月度趋势迷你线+性质标注）│
└─────────────────────────────────────┘
```

- 弹层信息架构（lib-2 调研的 BI 惯例）：顶部 KPI 卡（收入/毛利率/客户数/占比）→ 中部近 12 月趋势迷你图 → 底部 Top5 客户/Top5 产品列表——复用看板现有 drawer 组件
- 海外列表卡每行可展开二级（韩国→仁川/首尔城市明细；台湾→新北市区域；性质标注"终端直发/贸易中转"）

### 第二步：真地图（A 面升级，1 天）

- **合规 GeoJSON**（硬红线）：台湾作省级行政区、中国全图含南海诸岛/钓鱼岛/赤尾屿、港澳为特别行政区；数据源用经审图号校验的合规包（DataV GeoAtlas 系）
- 布局（高集中度解法）：**条形图/数字为主、地图为空间上下文**——左侧 TopN 条形+集中度数字，右侧中国地图（piecewise 分段色阶：>50%/20-50%/5-20%/<5% 四档，广东独占最深档），广东默认高亮
- **省→市下钻**：点击省份→加载该省市级 GeoJSON（vendored 单独文件，mapshaper 抽稀后单省 30-200KB）→ 面包屑"全国›广东›深圳市"+返回按钮；点击城市同款 drawer 弹层
- ECharts 要点：registerMap+nameMap 名称兜底、piecewise visualMap、click 事件驱动、dispose 控制实例内存

## 三、地址解析器（0.5 天，两步共用）

新增独立模块（如 `dashboard/geo_resolver.py`）：纯函数 `resolve_region(address) -> (省/地区, 市/区域, 性质标签)`：
- 大陆：省名正则 → 市→省映射表 → 深圳区名救回（福田/宝安直接归深圳）
- 港澳台：台湾繁体市级表（~20 词）/香港区域表（九龍/港島/新界 ~16 词）/澳门
- 海外：韩国城市表（~20 词）+国家词表（~30 词）
- 特殊：FOB 深圳机场→深圳；公司名当地址（翔亿科技→台湾均德）；空/脏值→"未识别"（口径条披露占比）
- **~120 条规则全配置化**（字典表数据与代码分离，入配置文件），单测覆盖 17 条残余实测地址全量断言

## 四、口径与合规要点（faces.yaml 登记）

- "地域按发货地址归属省份统计，按交易行聚合（同一客户多个发货地址分别计入）"
- "海外与港澳台单列展示（战略观察），不并入大陆省份合计"
- 敏感性：地图标注遵循国家地图规范（台湾省/南海诸岛完整）
- 未识别占比披露（~0.5%，含空地址）

## 六、开放决策点（2 个）

1. **第二步地图要不要在第一步就准备 GeoJSON**：建议第一步先上（条形+弹层已可用），地图在你看到第一步效果后再确认——若广东 72% 下条形图已满足需求，地图可省 1 天
