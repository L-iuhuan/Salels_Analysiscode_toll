## 二、v2 策展引擎设计

### 2.1 风险信号源扩展（6 个新通道，全部现成数据）

| 通道 | 数据源 | 入选规则（建议） | 上下文字段 |
|---|---|---|---|
| 营收异动 | 客户月度趋势.csv（月环比%） | 环比≤-50% 或 ≥+50%（新导入）且月收入≥10万 | 本月/上月收入、连续下滑月数 |
| 采购中断预警 | 客户全景.采购中断预警 | 预警=是 | 触发原因、近12月收入 |
| 毛利率恶化 | 客户全景.毛利率跌幅% | 跌幅≥5pct 且收入≥50万 | 跌幅、当前毛利率 |
| 衰退风险 | 组合健康度（隐性衰退/衰退期金额占比） | 隐性衰退=是 | 衰退金额占比 |
| 高风险产品 | gold_product_portrait（综合风险等级） | 高风险 且 品种收入≥20万 | 风险主导因子、策略建议 |
| 定价异常 | 定价合理性分析（异常低价标记） | 标记=是 且偏离≥10% | 业务员、偏离度、归因 |

现有 2 通道保留（异常日志补上详情列+损失金额、负毛利保持）。**去重合并规则**：同一客户多通道命中时合并为一行（类型顿号拼接、等级取最高、上下文取最严重通道），避免同一客户刷屏。

### 2.2 月度关联机制（核心新增）

1. **关联键**：`客户编号 × 风险类型`（复合 ID 写入 md 表格隐藏列或行动清单 id 列）
2. **上月对拍**：生成初稿时读取上月 `risk_action_*.md`（解析表格），对每条本期风险：
   - 上月也上榜 → 标记「**连续第 N 月**」（N 从上月+1）+「较上月恶化/好转/持平」（损失额或环比对比）
   - 上月上榜本月消失 → 列入「**本月解除**」小节（闭环反馈，管理层看得见改善）
3. **行动清单结转修复**：
   - bug 修：`created_month` 不再被渲染回写刷成当月；补 `closed_month`
   - **种子自动生成**：初稿时把「高等级+连续≥2月」的风险自动转为行动项草稿（事项=风险摘要、负责人空待填、期望完成日=月末）——人工审定后在编辑器里删改即可，不用从零写
4. 首月冷启动：无上月 md 时跳过对拍（逻辑天然兼容）

### 2.3 建议动作模板库（类型×等级，数据填充）

| 类型 | 模板示例（`{}`为数据填充） |
|---|---|
| 采购中断 | 近12月收入{rev12m}万，已连续{months}月无出货，建议：客户健康检查+业务员本周拜访确认存续性 |
| 营收断崖 | 本月收入{cur}万（环比{mom}%），连续下滑{months}月，建议：核实订单节奏+评估备货调整 |
| 负毛利 | {n}/{total}品种({pct}%)负毛利，损失{loss}万，建议：{gold建议透传}（停售可增利{loss}万） |
| 毛利率恶化 | 毛利率跌{drop}pct至{mg}%，主因{factor}，建议：产品组合复查+提价评估 |
| 定价异常 | 业务员{sales}成交价偏离{dev}%，建议：价格纪律复核{attribution} |

模板入配置（faces.yaml 或独立 yaml），代码零文案——**可持续调整不需改代码**。

### 2.4 溢出治理

初稿头部统计保留+新增：「溢出明细」写入 DQ 文件同级附件 `风险溢出明细_YYYY-MM.md`（全量 2252 条按通道×等级排序）——需要深挖时人工查，不刷屏主文档。
