# 半导体分析系统 — 非技术人员使用手册

> 本文档帮助你理解系统报告中的各项指标，用完就知道"这个数字高了是好是坏、我该做什么"。
> 技术细节请参考 [开发人员维护手册.md](开发人员维护手册.md)。

---

## 1. 快速开始

系统生成两大类报告：
- **产品生命周期报告**: 每个产品的当前状态、风险评分、未来趋势
- **客户分析报告**: 每个客户的采购行为、价值评估、价格建议

### 产品报告长什么样

打开 `产品生命周期报告_*.xlsx`，主要看这几页：

| Sheet | 看什么 | 什么时候看 |
|-------|--------|-----------|
| 产品九宫格画像 | 所有产品的健康度一览 | 每周扫一眼 |
| 衰退风险预警 | 得分高的产品（>68分） | 重点检查 |
| 价格分析 | 哪些产品在降价、幅度多大 | 月末复盘 |
| 退出期清单 | 建议清仓/退市的产品 | 季度决策 |

## 2. 产品画像怎么看

### 2.1 九宫格画像

系统把每个产品放到 3×3 的格子里：

| | 盈利健康(自比≥70% 且 他比≥参照组) | 轻度侵蚀(自比≥50% 且 他比尚可) | 严重侵蚀(自比<50% 或 他比<-10pp) |
|--|------|---------|---------|
| **加速增长(>15%)** | 成长期 | 健康扩张 | 预警增长 |
| **稳定扩张(0~15%)** | 健康扩张 | 现金牛 | 预警增长 |
| **持平(-10~0%)** | 利润优化 | 现金牛 | 隐性衰退 |
| **萎缩(≤-10%)** | 主动收缩 | 夕阳产品 | 衰退期 |

**怎么用**：处于右上角（衰退期、夕阳产品）的产品要优先关注；处于左上角（成长期、健康扩张）的产品正常跟进。

### 2.2 管理层摘要（四区简化版）

如果九宫格太多，可以只看四个区：

| 摘要区 | 含义 | 建议 |
|--------|------|------|
| **投入区** | 成长期、健康扩张 | 加大投入，抢占市场 |
| **维持区** | 现金牛、利润优化 | 保利润，正常维护 |
| **观察区** | 预警增长、隐性衰退、主动收缩 | 警惕恶化信号 |
| **退出区** | 夕阳产品、衰退期、清仓/偶发 | 考虑退市或迭代 |

## 3. 衰退风险评分

### 3.1 四因子风险评分（0-100 分，越高越危险）

系统用四个维度衡量产品的衰退风险：

| 风险因子 | 看什么 | 分数高说明 |
|---------|-------|-----------|
| F1f 毛利率趋势斜率 | 毛利变化 | 毛利率持续快速下滑（占10%权重） |
| F4 增速衰减 | 增长速度 | 增长在放缓（占60%权重，核心因子） |
| F5 自比健康度 | 当前 vs 历史表现 | 比过去差得多（占20%权重） |
| c6 大客户订货量变化 | 大客户采购变动 | 大客户大幅减少采购（占10%权重） |

### 3.2 v4.0 新增：四因子模型

增速衰减因子现在还会考虑**下跌持续了多久**。同样是跌了 20%，跌了 1 个月和跌了 4 个月的产品风险不同——后者会额外加分。

- 连续下跌 2 个月以上：计入风险评分
- 连续下跌 4 个月以上：特情说明中标注⚠️，并触发行动建议

### 3.3 v4.0 新增：覆盖规则

当 F4 增速衰减 ≥ 80 且 F1f 毛利率趋势斜率 ≥ 70 时，系统会**自动将该产品判定为极高风险**（得分=100），无论其他因子得分如何。该规则用于捕捉"增长断崖 + 毛利崩塌"的双重恶化信号，确保极端产品不会因权重分配而漏判。

### 3.4 风险等级

| 得分 | 等级 | 含义 |
|------|------|------|
| ≤ 34 | 低风险 | 指标在健康范围内 |
| 35 ~ 52 | 中风险 | 有个别指标异常，月度巡检关注 |
| 53 ~ 58 | 高风险 | 多项指标恶化，本周内复查 |
| > 58 | 极高风险 | 需立即制定处置方案 |

### 3.5 特情说明

系统会自动为每个产品生成一段"特情说明"，类似于：

> "毛利率已跌破历史参照值一半；客户集中度过高，存在单点崩塌风险；月销量已连续下跌4个月，下跌持续性构成独立风险信号"

这个说明直接告诉你**这个产品出了什么问题、有多严重、建议怎么处理**。

> **覆盖规则提醒**：当 F4 增速衰减 ≥ 80 且 F1f 毛利率趋势斜率 ≥ 70 时，产品会被自动标记为极高风险（得分100），详见 [3.3 覆盖规则](#33-v40-新增覆盖规则)。

## 4. 客户分析报告

### 4.1 RFM-π 评分（客户价值评估）

系统用四个维度给客户打分：

| 维度 | 含义 | 分数说明 |
|------|------|---------|
| **R**（最近一次采购） | 上次采购距今多久 | 越近分数越高 |
| **F**（采购频率） | 多久采购一次 | 越频繁越高 |
| **M**（采购金额） | 总共买了多少钱 | 金额越大越高 |
| **π**（利润贡献） | 给公司赚了多少利润 | 利润越高越高 |

综合得分分四个等级：

| 等级 | 分数范围 | 含义 |
|------|---------|------|
| **S 级** | ≥ 4.0 分 | 核心优质客户 |
| **A 级** | ≥ 3.5 分 | 重要客户 |
| **B 级** | ≥ 2.5 分 | 普通客户 |
| **C 级** | < 2.5 分 | 需关注客户 |

### 4.2 客户生命周期阶段

| 阶段 | 怎么判断 | 建议做法 |
|------|---------|---------|
| **导入期** | 刚开始合作，交易次数少 | 加强技术支持，帮客户度过试用期 |
| **成长期** | 采购量快速增长 | 加深合作，扩大份额 |
| **成熟期** | 采购稳定，是最核心的客户 | 维护关系，防止竞争者切入 |
| **衰退期** | 采购量持续下滑 | 了解原因，看是否能挽回 |

## 5. 关键指标解释

| 指标 | 正常范围 | 异常信号 |
|------|---------|---------|
| 近12月增长率 | 0% ~ 50% | < -10% 大萎缩, > 100% 注意持续性 |
| 自比健康度 | ≥ 70% | < 50%：毛利率比过去差了一半 |
| 他比健康度 | ≥ 0pp | < -10pp：明显低于同类产品 |
| 订货波动性CV | ≤ 0.5 | > 1.0：需求极不稳定 |
| 毛利率趋势斜率 | ≥ 0%/月 | < -0.5%/月：毛利持续下滑 |
| 连续下降月数 | 0 | ≥ 2 月：需要关注, ≥ 4 月：严重警告 |

## 6. 常见问题

**Q: 为什么某个产品得分突然变高了？**
A: 可能的原因：近期销量连续下跌、毛利率恶化、大客户流失。查看该产品的"特情说明"和"因子归因解读"列。

**Q: 新品得分很高是不是系统误判？**
A: 系统会自动识别新品（ERP标记"是否新品"=是，或在售不足6个月），新品不参与风险评分。

**Q: 两个产品看起来差不多，为什么得分差很多？**
A: 关键因子可能是增速衰减（占60%权重），增长断崖式下跌的产品风险分极高。

**Q: 数据更新频率是多少？**
A: 取决于源数据更新频率。建议每次新数据到货后重新运行分析。

| 因子 | 默认权重 | 说明 |
|------|---------|------|
| F4 增速衰减 | 0.60 | 近3月 vs 近12月增速的变化，核心因子 |
