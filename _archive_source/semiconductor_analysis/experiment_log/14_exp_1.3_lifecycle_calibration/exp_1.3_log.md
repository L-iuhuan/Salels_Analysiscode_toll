## 1. 假设 (Hypothesis)

### 1.3A 解释层
- **H1**: 当前画像（衰退期/夕阳产品）占比高的产品线，WAPE和低置信度标签更差。
- **H2**: 当前综合风险等级与holdout WAPE恶化正相关。
- **H3**: 管理层摘要分布与人工复核优先级一致。

### 1.3B PIT建模层
- **H4**: PIT代理增长率与下一季度实际增长率正相关 → 可用于幅度修正。
- **H5**: PIT毛利率变化与营收-毛利质量相关 → 可辅助偏差校准。
- **H6**: PIT客户集中度上升预示单点风险 → 可辅助置信度下调。

### 3.4 1.3B 幅度修正参数空间

| 参数 | 搜索空间 | 含义 |
|---|---|---|
| α (growth) | [-0.5, -0.3, -0.1, 0.0, 0.1, 0.3, 0.5] | 增长率修正系数 |
| β (margin) | [-0.3, -0.1, 0.0, 0.1, 0.3] | 毛利率修正系数 |
| γ (concentration) | [-0.3, -0.1, 0.0, 0.1, 0.3] | 集中度修正系数 |
| δ (risk) | [-0.2, -0.1, 0.0, 0.1, 0.2] | 风险上调修正系数 |

修正公式: `修正预测 = 基线预测 × clip(1 + α×growth + β×margin + γ×concentration + δ×risk, 0.5, 1.5)`

### 9.2 幅度修正函数

```python
def lifecycle_amplitude_correction(base_forecast, growth, margin, concentration, risk, params):
    adj = 1 + params['alpha']*growth + params['beta']*margin + \
          params['gamma']*concentration + params['delta']*risk
    adj = np.clip(adj, 0.5, 1.5)
    return base_forecast * adj
```
