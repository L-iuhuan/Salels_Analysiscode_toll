## 实验目的

验证不同产品线是否适合不同预测层级和时间粒度，决定后续1.1-1.4应在哪个层级上做方法筛选。

## 字段口径

| 业务含义 | 字段口径 |
|---|---|
| 产品线 | `型号_产品线（新）` |
| 品类 | `型号_产品品类`，缺失归`未知品类` |
| SKU | `SKU预测键` = `存货编码` → `存货名称` |
| 客户 | 本实验严格版1.0不做客户×产品联合预测；客户字段修正已在0.2基线脚本完成 |
| 销售额 | `RMB 未税金额小计` |
| 销量 | `发货数量` |
| 成本 | `总成本`→标准字段`成本` |
| 订单号 | `ERP订单号` |

## 对比方案

| 方案ID | 方案 | 准入规则 |
|---|---|---|
| `pline_quarterly` | 产品线×季度 | 17条全运行 |
| `pline_monthly` | 产品线×月度→季度汇总 | 按`product_line_monthly_eligible`过滤 |
| `category_monthly` | 产品品类×月度→产品线汇总 | 按`category_monthly_eligible`过滤 |
| `sku_monthly` | SKU×月度→产品线汇总 | 按`sku_monthly_eligible`过滤 |

## 方法池说明

严格版1.0使用与基线同源的简单算法池调用`forecast_values`：最近值、均值、中位数、线性加权均值、指数加权均值、趋势、漂移、同比季节等共21种组合。目的不是最终方法最优，而是比较“层级/时间粒度”这个变量。

## 关键发现

1. 严格版1.0与旧版结论显著不同，旧版不可引用。
2. SKU×月度对部分A/B线有效：POE、通用电源、音频功放。
3. 产品线×月度对电脑&计算电源管理有效。
4. C类线仍然高WAPE，主要价值是低置信度识别，而非强行点预测。
5. 品类月度样本只覆盖9条线，整体均值看似较好，但覆盖范围受限，不能直接作为全局默认。
