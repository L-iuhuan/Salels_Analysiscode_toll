# 实验 0.0.7: 字段修正版层级准入

## 元信息
- 日期: 2026-06-12
- 数据源: `data/财务分析-5月（6.3）.xlsx` sheet `总表`
- 字段口径: `experiment_log/00_master/field_spec_locked_20260612.md`
- 前置实验: 0.0.6（旧字段口径，不再作为最终准入表）
- 脚本: `run_0.0.7_corrected_hierarchy_eligibility.py`
- 输出目录: `output/`

## 实验假设

在进入Phase 1后续实验前，必须用已锁定字段口径重新计算每条产品线的层级准入，尤其是SKU键、客户键、客户分层字段，避免后续实验建立在错误维度上。

## 与0.0.6的关键差异

1. 数据源直接从原始Excel读取，而非silver CSV。
2. 客户字段使用`预测客户名称`：`终端客户简称` → `代理商/直供名称` → `实际终端客户` → `未知终端客户`。
3. SKU字段使用`SKU预测键`：`存货编码` → `存货名称`。
4. 客户分层使用`终端客户名称_客户类别`，缺失归`Unknown`，只用于分类。
5. 产品×客户准入使用`SKU预测键 × 预测客户名称`组合。
6. 客户层级准入改为2024+ Unknown销售额占比<5%且非Unknown类别数≥1。

## 字段口径

| 字段 | 来源 | 缺失处理 |
|---|---|---|
| 发货日期 | `发货日期` | 无效日期剔除 |
| 产品线 | `型号_产品线（新）` | 缺失→`未分类` |
| 产品品类 | `型号_产品品类` | 缺失→`未知品类` |
| SKU预测键 | `存货编码`→`存货名称`→`未知SKU` | 按优先级fallback |
| 预测客户名称 | `终端客户简称`→`代理商/直供名称`→`实际终端客户`→`未知终端客户` | 按优先级fallback |
| 客户类别预测 | `终端客户名称_客户类别` | 缺失→`Unknown` |
| 发货数量 | `发货数量` | ≤0剔除 |
| 销售额 | `RMB 未税金额小计` | 无特殊处理 |

## 层级启用规则

| 层级 | 启用条件 |
|---|---|
| 产品线×季度 | 默认启用 |
| 产品线×月度 | 最近36个月有效月份≥18，零月份占比<60% |
| 品类×月度 | 产品线内品类数≥2，至少2个品类有≥6个有效月份，未知品类销售额占比<20% |
| SKU×月度 | 有效月数≥6或非零月数≥4的SKU数≥3，头部SKU覆盖销售额≥70% |
| 产品×客户 | 头部SKU×预测客户名称组合中≥3个组合有效月数≥6，或头部组合覆盖≥50%且≥1个组合有效月数≥6 |
| 客户层级 | 2024+客户类别Unknown销售额占比<5%，且2024+非Unknown客户类别数≥1 |

### 重要变化

- 产品×客户层级可用性提升为17/18，因为使用了`预测客户名称`fallback并采用小线友好准入规则。
- 客户层级可用性为17/18，PMIC因2024+无有效非Unknown客户类别而不可用。
- `未分类`仍只建议产品线季度、产品×客户、客户层级；但由于其本身是回填/兜底产物，后续仍需低置信处理。
