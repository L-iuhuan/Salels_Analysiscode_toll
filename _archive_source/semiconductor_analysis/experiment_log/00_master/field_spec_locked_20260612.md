# 字段口径锁定说明（2026-06-12）

## 目的

锁定后续所有预测实验、日志、输出中的字段取用规则，避免客户、SKU、成本、订单等字段混用导致结果不可比。

## 铁律

1. 所有测试文件、日志、数据、会话记录必须存放在 `experiment_log/` 下。
2. 每次会话决策必须写入 `experiment_log/00_master/` 或对应实验目录日志。
3. 每次测试完成后必须写入测试结果和会话记录。
4. 字段口径变更后，受影响结果必须作废或重新运行，不得继续引用旧结果。

## 锁定字段口径

| 业务含义 | 标准字段/派生字段 | 原始字段优先级 | 用途 |
|---|---|---|---|
| 日期 | `发货日期` | `发货日期` | 月度/季度分桶 |
| 产品线 | `型号_产品线（新）` | `型号_产品线（新）`，缺失按存货名称历史众数回填，仍缺失归`未分类` | 主预测维度 |
| SKU建模键 | `SKU预测键` | `存货编码` → `存货名称` | SKU级建模、SKU×客户建模 |
| SKU展示名 | `存货名称_展示` | `存货名称` | 输出展示 |
| 产品品类 | `型号_产品品类` | `型号_产品品类`，缺失归`未知品类` | 品类月度层级 |
| 客户名称 | `预测客户名称` | `终端客户简称` → `代理商/直供名称` → `实际终端客户` → `未知终端客户` | 客户级/产品×客户建模与输出 |
| 客户分层 | `终端客户名称_客户类别` | `终端客户名称_客户类别`，缺失可归`Unknown` | KA/AA/KM/MM分类，不作为客户名称 |
| 销量 | `发货数量` | `发货数量` | 销量预测 |
| 销售额 | `RMB 未税金额小计` | `RMB 未税金额小计` | 销售额预测主指标 |
| 成本 | `成本` | 原始`总成本`映射为标准`成本` | 成本/毛利预测 |
| 毛利额 | `利润` | `利润` | 毛利额预测 |
| 销售单价 | `未税单价` | `未税单价` | ASP诊断 |
| 单位成本 | `单位成本` | `单位成本` | 成本单价诊断 |
| 订单号 | `ERP订单号` | `ERP订单号` | 订单数辅助统计 |

## 客户字段说明

- `终端客户简称`是客户名称第一优先级。
- `代理商/直供名称`仅作为客户名称缺失时的fallback，不再作为主客户键。
- `实际终端客户`仅作为第三优先fallback。
- `终端客户名称_客户类别`只用于客户分层，不能作为客户名称。

## SKU字段说明

- `存货编码`完整且稳定性优于`存货名称`，作为SKU建模主键。
- `存货名称`存在一名多码/一码多名问题，因此只作为fallback和展示字段。

## 联合层级顺序说明

最终联合预测/下钻主表建议顺序：

```text
预测客户名称 → 型号_产品线（新） → SKU预测键 → 存货名称_展示
```

说明：
- 对同一最细颗粒度，groupby维度集合一致时，字段顺序不改变汇总数值。
- 顺序会影响下钻展示、稀疏合并策略和未来层级调和树结构。
- 本项目业务下钻目标优先使用“客户 → 产品线 → 产品/SKU”。

## 后续实验要求

1. 所有新实验必须读取本字段口径文档。
2. 若脚本中新建客户键、SKU键，必须命名为`预测客户名称`、`SKU预测键`，不得随意替换。
3. 输出字段中如果展示客户，必须展示`预测客户名称`；如果展示SKU，必须展示`SKU预测键`和`存货名称_展示`。
