## 1. 假设 (Hypothesis)

点预测无法充分表达低置信度预测的不确定性。通过提供预测区间（如50%/80%/95%分位数），可以：
1. 量化预测不确定性，为决策提供风险评估
2. 区间覆盖率可以验证预测质量，比单一WAPE更全面
3. 对低置信度产品线，区间预测比强行点预测更有业务价值

## 2. 范围 (Scope)

- **目标产品线**: 全部17条产品线（包括低置信C类线）
- **重点评估**: 低置信C类线（新显示MLED驱动、无刷直流电机驱动、未分类、电源模组）
- **数据源**: `data/财务分析-5月（6.3）.xlsx`, sheet `总表`
- **时间粒度**: 季度（3个月桶），12个历史桶 H01-H12
- **预测指标**: 销售额（RMB 未税金额小计）
- **字段口径**: 严格遵守 `experiment_log/00_master/field_spec_locked_20260612.md`

## 5. 评估指标 (Evaluation Metrics)

### 5.1 区间覆盖指标
| 指标 | 公式 | 理想值 |
|---|---|---|
| 覆盖率(Coverage) | `P(actual ∈ [lower, upper])` | 接近名义覆盖率 |
| 覆盖偏差(Coverage Bias) | `Coverage - 名义覆盖率` | 0 |

### 5.2 区间宽度指标
| 指标 | 公式 | 理想值 |
|---|---|---|
| 区间平均宽度 | `mean(upper - lower)` | 越小越好（在保证覆盖率前提下） |
| 区间宽度标准化 | `区间宽度 / mean(|actual|)` | 越小越好 |

### 5.3 分位数评分
| 指标 | 公式 | 理想值 |
|---|---|---|
| 分位数损失(Quantile Loss) | `∑ρτ(actual - qτ) / n` | 越小越好 |
| 连续分级概率评分(CRPS) | `∫F(y) - 1(y ≤ actual) dy` | 越小越好 |

## 6. 成功标准 (Success Criteria)

| 标准 | 阈值 | 说明 |
|---|---|---|
| 区间覆盖准确性 | 覆盖率偏差 < 5% | 80%置信区间实际覆盖率在75%-85%之间 |
| 低置信线改善 | 区间覆盖准确性优于基线点预测 | C类线区间预测质量优于盲目点预测 |
| 区间宽度合理性 | 平均宽度 < 实际值标准差的2倍 | 区间不过宽，有实用价值 |

### 8.3 整体评估

- 平均覆盖偏差: 33.92% (远超5%目标)
- 通过线数: 4/17 (23.5%)
- 低置信线通过线数: 1/4 (25%)
- 强证据: 否 (>=10条通过)

### 8.4 关键发现

1. **区间覆盖能力普遍较差**:
   - 13/17条线覆盖偏差超过-15%，远未达到±5%目标
   - 80%置信区间实际覆盖率普遍在16.67%-66.67%之间
   - Bootstrap残差重采样方法可能不适合季度粒度的间歇性数据

2. **低置信C类线表现不佳**:
   - 仅1/4低置信线通过（电源模组）
   - 新显示MLED驱动、无刷直流电机驱动覆盖率仅16.67%-33.33%
   - 未分类虽然覆盖率33.33%，但区间宽度过小（5,859），难以覆盖实际波动

3. **通过线特征**:
   - 电机驱动: Q_HistAvg, 83.33%覆盖，偏差3.33% ✓
   - 电源模组: Q_HistAvg, 83.33%覆盖，偏差3.33% ✓
   - 车规电机驱动: Q_HistAvg, 83.33%覆盖，偏差3.33% ✓
   - 通用电源管理: Q_ExpSmooth, 83.33%覆盖，偏差3.33% ✓
   - 共性：均为相对稳定的产品线，历史均值方法效果较好

4. **Bootstrap方法局限性**:
   - 季度粒度数据点少（12个历史桶），Bootstrap效果受限
   - 误差分布不稳定，重采样难以捕捉真实不确定性
   - 适合高频数据，对低频季度数据效果差

5. **区间宽度问题**:
   - 区间宽度标准化值普遍较高，部分超过均值
   - 对低置信线，区间宽度不够（未分类）或过大（电源模组标准化宽度1.766）

### 8.5 数据质量问题发现

电源模组的WAPE异常再次出现：
- 基线WAPE: 3898720000000.34 (异常高)
- vs基线WAPE_pp: -3898719999999.52 (异常值)
- 表明电源模组的数据质量问题仍未解决，影响评估

### 8.6 推荐行动

1. **区间预测不可行**:
   - 当前方法对低置信线未提供有意义的区间预测
   - Bootstrap方法不适合季度粒度的间歇性数据
   - 建议放弃区间预测，转向其他策略

2. **低置信线处理**:
   - 新显示MLED驱动、无刷直流电机驱动: 继续使用基线方法，接受低置信度
   - 未分类: 标记为"不可预测"，使用业务判断或固定值
   - 电源模组: 修复数据质量问题后重新评估

3. **方法改进方向**:
   - 如果必须提供区间预测，考虑使用更复杂的方法（如贝叶斯时间序列）
   - 或使用业务经验设定固定区间比例（如±20%、±50%）
   - 对低置信线，提供定性风险评估而非定量区间

### 8.7 实验结论

**Gate结果**: ❌ 未通过

**结论**: 区间预测对低置信产品线未提供显著改进。Bootstrap残差重采样方法不适合季度粒度的间歇性数据。建议放弃区间预测，转向其他低置信线处理策略。

## 9. 注意事项

- 此实验评估全部17条产品线，但重点关注低置信C类线
- 分位数预测假设误差分布相对稳定，对于极稀疏数据可能不适用
- 区间宽度与覆盖率的权衡：更宽的区间保证覆盖，但实用性降低
- 修正版0.2基线作为基础，使用其最佳方法进行分位数扩展

## 脚本实现说明

### 方法池
| 方法ID | 方法名称 | 实现方式 |
|---|---|---|
| Q_ExpSmooth | ExpSmooth分位数 | statsmodels SimpleExpSmoothing + Bootstrap残差 |
| Q_LinearTrend | LinearTrend分位数 | numpy polyfit 线性/二次趋势 + Bootstrap残差 |
| Q_HistAvg | HistoricAverage分位数 | 历史均值 + Bootstrap残差 |
| Q_SeasNaive | SeasonalNaive分位数 | 最近k=4季均值 + Bootstrap残差 |

### 分位数生成
- 所有方法使用Bootstrap残差重采样（n=500）生成10%/25%/75%/90%分位数
- 分位数对应区间：80%置信区间 [q10, q90]，50%置信区间 [q25, q75]

### 依赖
- pandas, numpy, scipy（核心计算）
- statsmodels（ExponentialSmoothing，可选；不可用时回退到线性趋势）
- 无需 statsforecast（已用 statsmodels + 手写替代实现）
