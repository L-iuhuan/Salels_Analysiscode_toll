# 产品线季度分析与预测实施方案

## 1. 目标

基于原始出货明细基础表，生成“产品线 × 3个月滚动季度桶”的历史与预测数据：

- 历史：最近 12 个 3个月桶。
- 预测：未来 4 个 3个月桶。
- 主输出粒度：产品线，即原始字段 `型号_产品线（新）`。
- 输出字段使用中文。
- 预测方法需要可追溯：记录每一种候选方法的回测结果、评价指标、筛选标准、最终选择原因。

当前数据最新月份为 2026-04 时，时间桶为：

## 3. 清洗与映射规则

### 3.1 行过滤

保留条件：

```text
发货日期 非空
发货数量 > 0
销售额、成本额、利润 可转为数值
存货名称 非空
```

### 3.2 产品线缺失回填

主产品线字段为：

```text
型号_产品线（新）
```

缺失时优先使用 `存货名称` 回填：

1. 在全量历史数据中，对每个 `存货名称` 统计非空 `型号_产品线（新）` 的出现频次。
2. 若该产品只对应一个主要产品线，则用出现次数最多的产品线回填。
3. 若同一产品对应多个产品线：
   - 记录冲突。
   - 默认使用出现次数最多的产品线。
   - 在诊断表中输出：产品、候选产品线、出现次数、是否冲突。
4. 若仍无法回填：
   - 标记为 `未分类`。
   - 主表可保留，但方法选择时单独处理。

### 3.3 单价与成本单价

正式计算不用简单平均 `未税单价` 或 `单位成本`。

产品级最近历史桶加权平均销售单价：

```text
产品最近桶加权销售单价 = 产品在最近历史桶销售额 / 产品在最近历史桶销售量
```

产品级最近历史桶加权成本单价：

```text
产品最近桶加权成本单价 = 产品在最近历史桶成本额 / 产品在最近历史桶销售量
```

若某产品最近历史桶没有销量，则依次回退：

1. 最近 2 个历史桶产品加权单价。
2. 最近 4 个历史桶产品加权单价。
3. 同产品线最近历史桶加权单价。
4. 同产品线最近 4 桶加权单价。
5. 全局最近历史桶加权单价。

每次回退都需要记录：

- 产品。
- 产品线。
- 单价来源。
- 使用窗口。
- 是否回退。

## 5. 预测目标与评价指标

### 5.1 主目标

模型选择以销售额预测表现为主。

原因：

- 产品线经营分析更关注销售额与毛利。
- 单纯销量准确可能因产品结构变化导致销售额偏差很大。
- 价格必须下沉到产品/SKU级计算，避免产品线整体ASP掩盖结构差异。

### 5.2 综合评分

建议综合评分：

```text
综合评分 = 0.50 × 销售额WAPE
         + 0.15 × 销售额MAPE_截尾
         + 0.10 × abs(销售额偏差率)
         + 0.10 × 销量WAPE
         + 0.10 × 毛利额WAPE
         + 0.05 × 毛利率MAE_归一化
```

说明：

- 销售额WAPE作为第一核心指标。
- 销售额MAPE需要对小基数产品线做截尾，避免被极小值放大。
- Bias用于避免长期系统性高估或低估。
- 销量、毛利额、毛利率作为辅助稳定性指标。

### 5.3 指标定义

```text
销售额WAPE = sum(abs(预测销售额 - 实际销售额)) / sum(abs(实际销售额))
销售额MAPE = mean(abs(预测销售额 - 实际销售额) / max(abs(实际销售额), eps))
销售额sMAPE = mean(2*abs(预测销售额 - 实际销售额) / (abs(预测销售额)+abs(实际销售额)+eps))
销售额Bias = sum(预测销售额 - 实际销售额) / sum(实际销售额)
销售额MAE = mean(abs(预测销售额 - 实际销售额))
销售额RMSE = sqrt(mean((预测销售额 - 实际销售额)^2))
毛利率MAE = mean(abs(预测毛利率 - 实际毛利率))
```

## 6. 回测设计

### 6.1 回测方式

使用滚动起点回测。由于历史只有12个3个月桶，回测折数不能太多，但可以结合月度内部数据增强。

季度桶层面建议：

| 折次 | 训练桶 | 验证桶 |
|---|---|---|
| 1 | H01~H06 | H07 |
| 2 | H01~H07 | H08 |
| 3 | H01~H08 | H09 |
| 4 | H01~H09 | H10 |
| 5 | H01~H10 | H11 |
| 6 | H01~H11 | H12 |

也可以做多步预测回测：

- 训练 H01~H08，预测 H09~H12。
- 训练 H01~H09，预测 H10~H12。
- 训练 H01~H10，预测 H11~H12。

### 6.2 月度增强回测

由于季度桶只有12个点，很多模型不稳。因此需要额外构建月度序列：

- 产品线 × 月。
- 产品 × 月。
- 产品×客户 × 月。

模型可先预测月度，再汇总到3个月桶，用于提高回测样本数。

月度回测窗口示例：

- 最近36个月作为主训练/回测窗口。
- 滚动预测未来1个月、3个月。
- 每3个月汇总成季度桶，计算销售额WAPE。

## 7. 候选预测方法池

方法池通过“方法族 × 层级 × 目标 × 窗口 × 异常处理 × 参数”组合生成，预计候选数超过300种。

### 7.1 层级维度

| 层级 | 说明 |
|---|---|
| 全局 | 所有产品线共享趋势或季节参数 |
| 产品线 | 每条产品线单独建模 |
| 产品 | 每个 `存货名称` 单独预测，再汇总到产品线 |
| 产品×客户 | 每个产品×客户组合预测，再汇总到产品线 |
| 分层集成 | 头部用产品级，中腰部用产品线级，尾部用保守基线 |

### 7.2 目标维度

| 目标 | 说明 |
|---|---|
| 销售额直接预测 | 直接预测销售额 |
| 销售量预测后乘产品级价格 | 预测产品销量，再用产品最近桶加权单价计算销售额 |
| 销售额与销量双目标 | 两者分别预测，按回测表现选择 |
| 毛利额辅助预测 | 毛利额直接预测或由销售额、成本额推导 |

## 8. 方法筛选规则

### 8.1 最终方法选择

每个产品线单独选择最优方法。

选择流程：

1. 过滤无效方法：
   - 预测值为空。
   - 预测销售额为负且无法合理修正。
   - 有效回测折数不足。
2. 计算每个方法的综合评分。
3. 按产品线内综合评分排序。
4. 如果第一名和第二名差距很小，则优先选择：
   - Bias更小的方法。
   - 回测稳定性更高的方法。
   - 业务解释性更强的方法。
5. 若产品线数据稀疏，则触发兜底策略。

### 8.2 稀疏产品线兜底

如果产品线满足任一条件：

- 历史有效桶数 < 6。
- 最近4桶中有超过2桶为0或缺失。
- 销售额规模极低。
- 回测误差极不稳定。

则优先使用：

- 最近4桶均值。
- 最近3桶指数加权。
- 产品级最近销量 × 产品级ASP。
- 产品线规模分层保守系数。

### 8.3 预测值约束

预测销售额、销售量、成本额不得小于0。

毛利率需要做诊断，不强制裁剪历史原始利润，但预测异常时标记：

- 毛利率 < -50%。
- 毛利率 > 80%。
- 预测毛利率相比最近历史桶变化超过30个百分点。

## 11. 性能注意事项

原始Excel约32万行、69列，读取较慢。实现时应：

1. 只读取必要字段。
2. 读取后在当前任务内缓存为临时 parquet 或 pickle。
3. 不重复读取Excel。
4. 回测方法尽量向量化。
5. 产品×客户层级可能组合很多，需要先过滤低频组合或使用稀疏兜底。

## 13. 最终验收标准

1. 主表包含所有产品线的历史12桶与未来4桶。
2. 主表字段为中文。
3. 历史销售额、销售量、毛利额、毛利率可从基础表复算一致。
4. 预测销售额以综合评分优先筛选方法。
5. 预测价格使用产品/SKU级最近桶加权单价，而不是产品线平均单价。
6. 每个产品线都能看到最终使用的方法。
7. 每种候选方法都有回测明细与评价指标。
8. 缺失产品线回填过程可追溯。
9. 产品级单价回退过程可追溯。
10. 输出可直接用于后续经营分析和人工复核。
