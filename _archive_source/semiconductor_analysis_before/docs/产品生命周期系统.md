## 1. 系统概述

产品生命周期系统从共享Silver层读取数据，输出产品快照表（九宫格画像 + 5因子风险评分 + ETS预测 + 历史追溯）。

### 运行流

```
Silver层(product_monthly) 或 行级数据
  ↓ run_profiling()
产品画像(40+指标/每产品)
  ├── 九宫格定位(横轴:盈利健康 × 纵轴:销量动能)
  ├── 5因子衰退风险评分
  ├── ETS时序预测(3月+置信区间)
  ├── 价格弹性/ASP趋势/订单频次
  ├── 历史参照毛利率(多级兜底)
  └── 数据质量标记
  ↓
RFM客户分群 + 产品关联分析
  ↓
Gold层CSV + Excel报告(9 Sheet)
```

### 入口

```bash
python run_product.py     # 单独运行
python run_all.py          # 全部运行
```

## 2. 新品判定

### 双轨制优先级

`profiling.py:line 161-173`

```python
if "新品标记" in df.columns:
    # ERP标记优先：近12月中任一行"是"即为新品
    _prod_new_flag = df_recent.groupby(name_col)["新品标记"].apply(
        lambda s: (s == "是").any()

else:

    prod_info['is_new'] = calendar_age < min_history_months  # 或 recent_qty < min_volume
```

| 来源 | 新品判定 | 打印日志 |
|------|---------|---------|
| ERP"是否新品"列 | 近12月任一行标记为"是" | `[新品判定] 使用ERP标记，新品数: N` |
| 自动计算 | 日历月龄 < new_product_months(默认6月) 或 近12月销量 < min_volume | `[新品判定] 无ERP标记，使用自动计算，新品数: N` |

> 新品观察产品不参与九宫格定位、风险评分和参照组计算。

## 3. 二维九宫格画像

### 3.1 坐标轴

**纵轴：销量动能** — 近12月 vs 前12月月均增长率

| 增长率范围 | 动能等级 | 简写 |
|-----------|---------|------|
| > 15% | 加速增长 | 量增 |
| 0% ~ 15% | 稳定扩张 | 量增 |
| -10% ~ 0% | 持平 | 量稳 |
| ≤ -10% | 萎缩 | 量跌 |

> 增长率自动缩窗：12月→6月→3月递进，窗口不足时=0。

**横轴：盈利健康** — 自比 + 他比双重判断

| 自比健康度 | 他比健康度 | 健康等级 |
|-----------|----------|---------|
| ≥ 70% | ≥ 参照组均值(≥0pp) | 健康 |
| ≥ 50% | 低于参照组但差<10pp | 轻度侵蚀 |
| < 50% 或 他比 < -10pp | — | 严重侵蚀 |

### 3.2 九宫格矩阵

| | 健康 | 轻度侵蚀 | 严重侵蚀 |
|--|------|---------|---------|
| **加速增长** | 成长期 | 健康扩张 | 预警增长 |
| **稳定扩张** | 健康扩张 | 现金牛 | 预警增长 |
| **持平** | 利润优化 | 现金牛 | 隐性衰退 |
| **萎缩** | 主动收缩 | 夕阳产品 | 衰退期 |

### 3.3 管理层摘要（四区简化）

| 摘要 | 包含画像 |
|------|---------|
| 投入区 | 成长期、健康扩张 |
| 维持区 | 现金牛、利润优化 |
| 观察区 | 预警增长、隐性衰退、主动收缩 |
| 退出区 | 夕阳产品、衰退期、清仓/偶发 |
| 待观察 | 新品观察 |

### 3.4 清仓/偶发过滤

日历月龄 ≥ 24月 且 近24月内发货月数 ≤ 2 → 标记"清仓/偶发"，不参与分析。

## 4. 衰退风险评分（5因子）

### 4.1 评分因子

| 因子 | 权重 | 函数 | 正向(高=风险) |
|------|------|------|--------------|
| F1 毛利率趋势斜率 | 20% | `risk_slope()` | 斜率越负→风险越高 |
| F3 订货波动性(CV) | 10% | `risk_cv()` | CV越高→风险越高 |
| F4 增速衰减 | 20% | `risk_decay()` | 衰减越大→风险越高 |
| F5 自比健康度 | 35% | `risk_self_health()` | 健康度越低→风险越高 |
| F6 ASP趋势 | 15% | `risk_asp()` | ASP跌越多→风险越高 |

> 旧版因子2(客户集中度)和因子5(历史对照)已在v2.9移除。

### 4.2 不可靠因子降权

因子不可靠时权重=0，其余因子权重按比例重分配：

| 标记 | 含义 | 影响因子 |
|------|------|---------|
| SL | 斜率数据不足(<3点) | F1降权 |
| CV | CV无效(近12月无发货) | F3降权 |
| NH | 无历史参照(无正毛利率月) | F5降权 |
| AS | ASP数据不足(<3有效点) | F6降权 |

### 4.3 分级标准

| 得分 | 等级 |
|------|------|
| ≤ 25 | 低风险 |
| 26 ~ 50 | 中风险 |
| 51 ~ 75 | 高风险 |
| > 75 | 极高风险 |

### 4.4 衰退期最低分保护

衰退期产品且毛利率≤0或销量≤0 → 非SH因子加权分若<50分则强制设为50分。

## 5. 历史参照毛利率

### 5.1 计算规则

`profiling.py:line 388-412`

| 产品月龄 | 数据点 | 参照分位数 |
|---------|--------|-----------|
| < 12月 且 数据点<6 | — | P30 |
| < 12月 且 数据点≥6 | — | P50 |
| ≥ 12月 且 数据点<20 | — | P90(自动降级) |
| ≥ 12月 且 数据点≥20 | — | P95 |

**长周期(月龄≥36月)**：取最近24月，按P80分位。

### 5.2 参照组加权均值

```
加权均值 = Σ(营收_i × 毛利率_i) / Σ营收_i
```

**兜底链路**（config驱动）：
```
型号_产品品类(≥3个产品) → 产品二级分类(≥3个) → 全公司均值
```

**排除产品**：新品观察、已退市、清仓/偶发。

## 7. 价格相关

### 7.1 ASP趋势斜率

近12月均价变化率（最小二乘斜率），最小3个有效数据点。

### 7.2 价格弹性系数

```python
弹性 = 中位数(ΔQ/Q / ΔP/P)  # 经IQR过滤
```

| |弹性绝对值|标签|
|--|---------|----|
| > 1.5 | 高敏感 |
| > 0.8 | 中敏感 |
| ≤ 0.8 | 低敏感 |

### 7.3 ASP-毛利率联合诊断

| 条件 | 诊断 |
|------|------|
| ASP跌+毛利率跌 | 价格战风险 |
| ASP稳+毛利率跌 | 成本问题 |
| ASP跌+毛利率稳 | 规模效应 |
| 其他 | 正常 |
