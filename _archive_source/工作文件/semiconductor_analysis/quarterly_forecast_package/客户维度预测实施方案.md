# 客户维度季度预测实施方案

## 概述

在原产品线季度预测基础上，新增客户维度（KA/AA客户），按终端客户简称分组，
沿用相同的12+4季度桶结构，保留全部552种原方法 + 新增HTML模板3种独有算法，
为每个客户独立回测选择最优预测方法。

## 数据源

- 文件：财务分析-5月（6.3）.xlsx「总表」331,402行
- 筛选：`终端客户名称_客户类别` 含 KA 或 AA（客户自身营收标签）
- 分组：`终端客户简称`
- 筛选后：118,299行，41个KA/AA客户

## 预测方法池

### 原552种方法（保留全部）
- 12种基础算法：最近值、均值、中位数、线性加权均值、指数加权均值、线性趋势、对数线性趋势、漂移、同比季节、衰减趋势、保守增长、保守衰减
- 6种层级：客户级销量×客户加权价格、客户×产品销量×SKU价格、客户销售额直接预测、客户×产品销售额直接预测
- 多种窗口参数组合

### 新增3种算法（HTML模板独有）
A. **月度季节指数** — 月度经典季节分解（4变体）
B. **Croston稀疏需求** — 间歇需求预测（3变体）
C. **组合中位数Ensemble** — 5方法投票取中位数（1变体）

合并后约570种候选方法。

## 单价模型

按HTML模板公式：
```
ASP = 近3月加权均价 × √(近3月均价 / 前3月均价)
```
截断 [0.8, 1.15]，成本单价同理。
