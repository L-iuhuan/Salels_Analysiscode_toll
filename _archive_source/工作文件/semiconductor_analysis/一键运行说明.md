## 桌面入口（推荐）


## 设计原则

1. **自动 cd 到项目目录** — 不管你从哪里双击都不会跑错位置
2. **检测 Python** — 没装直接弹窗提示，不会黑屏闪退
3. **跑完后 pause** — 不会一闪而过，能看完整日志
4. **失败时红字** — 错误码 + 错误位置一眼看见
5. **耗时统计** — 跑完显示开始/结束时间
6. **菜单调用快捷 bat 时不会卡住** — `from_menu` 参数控制是否 pause

## 故障排查

### Python 未找到
```
[✗] 未找到 Python，请先安装 Python 3.10+ 并加入 PATH
```
解决：装 Python 时勾选 "Add Python to PATH"。

### Gold 数据不存在（运行 2_只生成看板）
```
[!] 警告：output\gold\客户全景.csv 不存在
```
解决：先跑 1_全量重跑.bat。

### 看板文件不存在（运行 6_打开最新看板）
```
[✗] 看板文件不存在
```
解决：先跑 1 或 2。

### 找不到产品生命周期 Excel（运行 5）
```
[!] 未找到 output\report\产品生命周期报告_v4.0_*.xlsx
```
解决：先跑 4_只跑产品分析.bat。

## 跳过菜单直接跑

不想看菜单？直接双击对应数字编号的 bat 即可。每个独立 bat 都能单独运行（不需要先打开菜单）。
