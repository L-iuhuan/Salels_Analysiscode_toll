# 实验 0.0.5: 产品线覆盖与字段一致性诊断

## 元信息
- 日期: 2026-06-12
- 数据版本: 财务分析-5月（6.3）.xlsx / silver_cleaned_rows.csv / 产品线季度历史与预测.csv
- 前置实验: 0.0 平凡基线 ✅

## 实验假设
产品线数量在原始数据、历史主表、预测主表、方法排行榜中应完全一致。若不一致则存在口径漂移，需修复后方可进入Phase 1。

## 实验设计

检查6个数据源的"产品线"字段：
1. 原始Excel (`型号_产品线（新）`)
2. Silver明细 (`型号_产品线（新）`)
3. 历史主表 (产品线季度历史与预测.csv)
4. 预测主表 (同上)
5. 方法排行榜 (预测方法排行榜.csv)
6. 锁定版预测 (quarterly_forecast_locked)

## 执行过程

### 步骤1: 原始Excel
- 耗时: ~30s (读取67列)
- 产品线列: `型号_产品线（新）`
- 结果: 17条 (+ 1个"PMIC"在后续管道被排除)

### 步骤2: Silver明细
- 输入: silver_cleaned_rows.csv (290MB)
- 产品线列: `型号_产品线（新）`
- 结果: 17条

### 步骤3: 历史/预测主表
- 历史数据: 204行, 17条产品线 × 12个桶
- 预测数据: 68行, 17条产品线 × 4个桶

### 步骤4: 方法排行榜
- 结果: 552种方法 × 17条产品线

### 步骤5: 锁定版预测
- 结果: 16条产品线 (缺少"电机驱动")
