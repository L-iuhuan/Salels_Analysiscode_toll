## 一、`b2b_v2/actions/rules_engine.py` — 完全重写

### 旧版（v2.0）
- 扁平L1（异常告警）+ L2（10条规则）双轨制
- 所有客户平等对待，"关注"过于平均
- 业务负责人未标注
- 大量客户被标记关注/警示，意义不大

### 新版（v4.0）
**6策略体系**，按优先级匹配（先匹配先生效）：

| 优先级 | 策略 | 判定逻辑 | 匹配人数 |
|:--:|------|------|:--:|
| 1 | **策略5: 风控收缩** | 衰退/流失+体量>5万；真实利润率≤0；连续下滑≥3（重度）/≥2（中度）；中断预警（轻度） | 888 |
| 2 | **策略6: 激活试探** | 休眠/流失期 + 历史收入≥3万；分级：平稳走势→建议激活，断崖下跌→弱激活 | 123 |
| 3 | **策略1: 深度绑定** | S/A级 + 交易≥12月 + 毛利≥P80 + 加分条件≥2（增长/多产品线/品类健康/成熟期） | 126 |
| 4 | **策略2: 重点维护** | S/A级 + 毛利≥P50 + (增长乏力/平稳无变化/高度稳定<CV<0.3) | 94 |
| 5 | **策略3: 培育放量** | 连续增长≥3月/成长期/C级+高增长/新品占比>20%+收入<P50；排除Top5≥85%/衰退/交易<3月 | 55 |
| 6 | **策略4: 品类拓展** | 主导线占比>80% + 品类机会非空 + 收入≥2万 + (交易≥6月/A/B级) | 234 |
| — | 常规维护 | 不触发任何策略的活跃客户 | 463 |
| — | 休眠(跳过) | 非活跃客户 | 1,868 |

**每策略输出**：
- `策略名称`：匹配到的策略标识
- `策略建议`：完整的上下文感知建议，含客户名/毛利/产品线/业务负责人
- `策略原因`：触发条件说明

**L1告警**：仅对P1(战略级)+P2(高价值)+P3(中等)客户生成，P4/P5静默。标注`@业务负责人`。

**数据校准**（实施中修正）：
- 移除Top5集中度≥85%独立条件（终端客户中位=100%，79%+客户触发）
- 移除收入CV≥0.6条件（中位4.51，97%客户>0.6，不适用终端客户维度）
- 移除零采购月占比≥30%条件（97%客户触发）
- 连续下滑从≥2升级为≥3=重度，保持≥2=中度

## 二、`b2b_v2/actions/negative_margin.py` — 新建

### 功能
1. 从 `customer_x_product` Silver层数据聚合客户×产品级别毛利
2. 识别每个客户采购的负毛利产品
3. 计算损失总额 + 停售可挽回利润
4. 生成分级建议

### 核心函数
- `analyze_negative_margin(customer_x_product, customer_portrait)` → DataFrame
- `summarize_negative_margin_for_alert(neg_analysis)` → dict

### 输出字段
| 字段 | 说明 |
|------|------|
| 整体毛利率% | 客户总毛利/总收入 |
| 负毛利品种数 | 毛利率<0的产品数量 |
| 负毛利品种占比 | 负毛利品/在采品种 |
| 负毛利损失总额 | 负毛利产品的利润总和(负值) |
| 停售可增加利润 | abs(损失总额)，停售可挽回的利润 |
| 负毛利产品清单 | 品种:毛利率:损失额的明细列表 |
| 负毛利严重等级 | 严重/关注/轻微/无 |
| 建议动作 | 分级建议文案 |

### 严重等级判定
- **严重**：整体毛利率<0；或负毛利>30%品种/损失>10%采购额
- **关注**：负毛利>15%品种/损失>5%采购额
- **轻微**：有负毛利但影响小
- **无**：无负毛利产品

### 集成点
- `customer_analysis/gold.py`: `generate_gold_tables()` 中调用 → 输出 `负毛利分析.csv`
- `b2b_v2/actions/rules_engine.py`: 策略建议中嵌入负毛利分析结果（优先级1-2的客户）

## 七、`b2b_v2/actions/product_insights.py` — 新建（v4.1 策略模板增强）

### 功能
为6策略引擎提供客户-产品级别的深度分析数据，使每个策略建议包含具体产品信息而不仅仅是汇总指标。

### 核心函数

| 函数 | 输入 | 输出 | 用途 |
|------|------|------|------|
| `build_customer_product_profiles(cxp, portrait, silver)` | Silver层customer_x_product | dict[cid] | 每客户Top5产品/利润担当/利润拖累/整体毛利率 |
| `build_monthly_product_trend(cxp)` | customer_x_product | dict[cid] | 产品级近3月vs前3月变化，定位哪个产品下降导致衰退 |
| `build_historical_glory(cm, cxp)` | customer_monthly | dict[cid] | 历史12月滚动窗口峰值：峰值收入/利润/毛利率/期间 |
| `analyze_margin_structure(profile, db_profiles)` | 产品画像 | dict | 利润率vs同类对比、拖累/担当产品详情 |
| `format_product_list(products, top_n)` | 产品列表 | str | 格式化"产品名(¥X万,毛利率Y%)" |

### 数据结构

```python
profile[cid] = {
    "top5_by_revenue": [(产品, 收入, 毛利率), ...],   # Top5收入产品
    "margin_stars": [(产品, 利润, 毛利率), ...],      # Top5利润贡献
    "margin_drains": [(产品, 亏损额, 毛利率), ...],   # 负毛利拖累
    "top1_product": (产品, 收入, 占比),
    "overall_margin": float,                          # 整体毛利率%
    "total_revenue": float,
    "total_profit": float,
    "product_count": int,
}
```
