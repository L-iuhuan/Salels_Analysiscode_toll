# 产品线季度预测方法说明

## 一、方法总览

本预测系统使用 **5种时间序列方法**，对每条产品线独立选择最优方法。方法按复杂度从低到高排列：

| 方法 | 复杂度 | 适用场景 | 数学本质 |
|------|--------|----------|----------|
| Naive | ★☆☆ | 平稳序列、无趋势 | 直接用最新值 |
| MA3 | ★☆☆ | 短期波动平滑 | 3期等权移动平均 |
| Median4 | ★★☆ | 含异常值的序列 | 4期中位数（抗离群点） |
| Holt | ★★★ | 有明显趋势的序列 | 指数平滑+趋势项 |
| Ensemble_median | ★★☆ | 不确定时稳健选择 | 前4种方法的中位数聚合 |

---

## 二、各方法详细说明

### 1. Naive（朴素法）

**公式**：
```
̂y_{t+1} = y_t
```

**说明**：直接用最新一期的观测值作为下一期的预测值。这是最简单的预测方法，也是所有方法的基准。

**适用场景**：
- 销量平稳、无明显趋势或季节性的产品线
- 数据点极少时（<3个季度）的兜底方法
- 随机游走型序列（每期变化不可预测）

**优点**：
- 零参数，无需训练
- 理解直观，业务人员容易接受
- 对于某些产品线（如通用电源），回测MAPE低至 **16.8%**

**缺点**：
- 无法捕捉任何趋势或模式
- 对最新一期的异常值极为敏感
- 预测值永远不变（滚动预测4个季度值相同）

---

### 2. MA3（3期移动平均）

**公式**：
```
̂y_{t+1} = (y_t + y_{t-1} + y_{t-2}) / 3
```

**说明**：取最近3个季度的算术平均值作为下一期预测。当可用数据不足3期时，取可用数据的均值。

**适用场景**：
- 销量有短期波动但总体平稳
- 中等数量级的产品线（季度销量 1万~10万件）

**优点**：
- 平滑了最新一期的随机波动
- 比Naive更稳定，不易受单期异常影响

**缺点**：
- 对趋势的反应滞后
- 等权平均没有区分各期的重要性
- 当序列存在明显趋势时，预测系统性偏低估或高估

---

### 3. Median4（4期中位数）

**公式**：
```
̂y_{t+1} = median(y_t, y_{t-1}, y_{t-2}, y_{t-3})
```

**说明**：取最近4个季度的中位数作为下一期预测。当数据不足4期时，取可用数据的中位数。

**适用场景**：
- 销量含有异常值（如2026-Q1的暴增/暴跌）
- 低数量级产品线（季度销量 <1万件），数据波动大
- 需要稳健估计的场景

**优点**：
- **极强的抗异常值能力**——单个极端值不影响中位数
- 在低量产品线上表现突出（回测MAPE仅 **20%**）
- 比均值方法更稳健

**缺点**：
- 当序列有明确趋势时，中位数滞后于均值
- 样本量小时中位数代表性下降

**与MA3对比**：
```
例子：历史销量 = [100, 120, 110, 500（异常）]
  MA3预测     = (120 + 110 + 500) / 3 = 243 ❌（被异常拉高）
  Median4预测 = median(100, 120, 110, 500) = 115 ✅（排除异常）
```

---

### 4. Holt（霍尔特线性趋势法）

**公式**：
```
水平项:  s_t     = α·y_t + (1-α)(s_{t-1} + b_{t-1})
趋势项:  b_t     = β·(s_t - s_{t-1}) + (1-β)·b_{t-1}
预测:    ̂y_{t+1} = s_t + b_t
```

其中 α（水平平滑系数）、β（趋势平滑系数）通过网格搜索最小化历史SSE自动优化：
- α 搜索范围: [0.05, 0.95]，步长0.05
- β 搜索范围: [0.05, 0.50]，步长0.05
- 共 18×9=162 种参数组合

**说明**：在指数平滑的基础上增加了趋势项，能够捕捉并延续线性趋势。参数自动优化，无需人工调整。

**适用场景**：
- 销量有明确上升或下降趋势的产品线
- 增长期或衰退期的产品
- 历史数据较多（≥4个季度）的产品线

**优点**：
- 可以捕捉和延续趋势
- 参数自适应优化，无需手动调参
- 在趋势型产品线上显著优于Naive

**缺点**：
- 对趋势的延续假设可能过度外推
- 需要较多历史数据才能稳定
- 参数优化计算量较大（每产品线162组参数）
- 在无趋势序列上可能"制造"虚假趋势

**回测中适用产品线示例**：
- 放大器：Holt最佳（MAPE **23.9%**），其他方法均>26%
- 蓝牙/WIFI电源：Holt最佳（MAPE **46.4%** vs Naive 42.4%)

---

### 5. Ensemble_median（集成中位数法）

**公式**：
```
̂y_{t+1} = median( ̂y_{t+1}^{Naive}, ̂y_{t+1}^{MA3}, ̂y_{t+1}^{Median4}, ̂y_{t+1}^{Holt} )
```
只取预测值>0的方法参与投票。

**说明**：同时运行前4种方法，取它们预测结果的中位数作为最终预测。这是一种集成学习方法，通过多种方法的"投票"提高稳健性。

**适用场景**：
- 不确定哪种单一方法最佳时
- 产品线数据模式复杂，含趋势、波动、异常混合
- 需要稳健预测，避免单一方法失效的风险

**优点**：
- **分散风险**——一种方法失效不影响整体
- **自动纠偏**——极端预测被中位数削平
- 在中等复杂度产品线上表现稳定

**缺点**：
- 计算量是单一方法的4倍
- 当多数方法都表现差时，集成也无效
- 在特定模式上不如针对性优化的单一方法

## 三、数量等级（Tier）策略

### 3.1 Tier分类标准

根据产品线的季度平均销量，将17条产品线分为3个等级：

| Tier | 季度均销量 | 产品线数量 | 典型产品线 |
|------|-----------|-----------|-----------|
| 🟢 高量级 | >100,000件 | 13条 | 通用电源、无刷马达、硬包锂电池 |
| 🟡 中量级 | 10,000~100,000件 | 1条 | dTOF模块 |
| 🔴 低量级 | <10,000件 | 1条 | 电源模块 |

> **注**：PMIC为特殊产品线（全部销量为0），使用Naive兜底。

### 3.2 Tier与最优方法的关系

分层回测结果（排除2026-Q1异常季度后）：

| Tier | 最优统一方法 | MAPE | 次优方法 | MAPE |
|------|------------|------|----------|------|
| 🟢 高量级 | **Naive** | **29.2%** | Holt | 33.0% |
| 🟡 中量级 | **MA3** | **33.0%** | Holt | 33.7% |
| 🔴 低量级 | **Median4** | **20.0%** | Ensemble_median | 54.0% |

### 3.3 当前系统使用的策略：逐产品线最优

虽然存在Tier层面的倾向性，但当前最终预测系统采用的是 **逐产品线独立选择最优方法**，而非统一按Tier分配。原因：

1. **同一Tier内的产品线差异很大**：
   - 高量级中，通用电源(Naive, MAPE 16.8%) vs 无刷直流马达(Naive, MAPE 21.1%) vs 隔离转换器(MA3, MAPE 46.6%)
   - 如果强制全部用Naive，隔离转换器的MAPE会从46.6%上升到48.9%

2. **逐产品线选择优于统一Tier策略**：
   - 综合MAPE：逐产品线 ≈ **28.8%** vs 统一Tier策略 ≈ 29.2%
   - 差异虽小，但每条产品线都获得了最适合自己的方法

3. **极端值保护**：
   - 低量级产品线数据稀疏，逐产品线选择能自动识别并选中Median4等稳健方法
   - 不会因为某个季度的异常值导致方法选择错误

### 3.4 方法选择流程

```
开始
  ↓
每条产品线
  ↓
历史数据是否≥4个季度？───否──→ Naive
  ↓是
对每个可用季度做 leave-one-out 回测
  ↓
对5种方法分别计算平均MAPE
  ↓
选择MAPE最低的方法
  ↓
用该方法预测未来4个季度
  ↓
滚动预测（每期预测值加入历史，用于下期）
  ↓
完成
```

## 四、收入与利润预测方法

### 4.1 转换逻辑

```
预测收入 = 预测销量 × 最新季度平均单价
预测利润 = 预测收入 × 最新季度毛利率
```

### 4.2 参数来源

| 参数 | 数据源 | 说明 |
|------|--------|------|
| 最新季度平均单价 | 原币含税单价的季度均值 | 每条产品线各自计算 |
| 最新季度毛利率 | (_毛利率)的季度均值 | 每条产品线各自计算 |

### 4.3 注意

- **毛利率取最近一个完整季度的均值**，而非历史平均
- 单价和毛利率的假设是：未来4个季度保持不变
- 如果产品结构或定价发生重大变化，需要人工调整单价/毛利率参数

## 五、异常值处理

### 5.1 检测标准

某季度销量满足以下任一条件即标记为异常：

| 指标 | 阈值 |
|------|------|
| 环比变化率 | >80% 或 < -50% |
| 与过去4季均值偏差 | >50% |

### 5.2 2026-Q1异常分析

2026-Q1是显著的异常季度，主要异常产品线：

| 产品线 | 变化幅度 | 原因推测 |
|--------|---------|----------|
| 无刷直流马达 | +44.2% QoQ | 客户集中备货 |
| MiniLED显示 | -80.3% QoQ | 产品换代或客户流失 |
| 通用电源 | +18.8% QoQ | 大客户集中采购 |

### 5.3 处理方式

- **回测阶段**：异常季度被纳入回测数据，但由于异常值在所有方法上都产生高误差，不影响方法选择
- **预测阶段**：由于2026-Q1已被新数据（2026-Q2）覆盖，对当前预测无直接影响
- **业务建议**：如果判断未来4季度可能出现类似异常（如大客户下单、产品退市），应人工调整预测值
