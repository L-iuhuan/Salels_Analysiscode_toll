# 📐 产品生命周期分析工具 — 使用说明

> 版本：v2.5 | 日期：2026-05-03

## 文件结构

```
生命周期工具/
├── run.py                # 主程序（双击运行）
├── config.xlsx           # 配置文件（修改参数用）
│   ├── 列映射            # ERP列名 → 程序字段映射
│   ├── 阈值参数          # 所有分类边界值和判定阈值（50+项可调）
│   ├── 风险因子权重      # 5个风险因子的权重（合计须=1.0）
│   └── 参照组优先级      # 参照组兜底链路配置（可调顺序）
├── defunct_count.py      # 退市产品独立统计脚本（交叉验证用）
├── setup.bat             # 一键安装运行环境（首次使用双击）
└── README.txt            # 本文件
```

## 首次使用

1. 双击 `setup.bat`，安装所需的 Python 库（只需执行一次）
2. 打开 `config.xlsx`，按实际情况填写：
   - Sheet「列映射」：填入你的 ERP 数据对应的列名
   - Sheet「阈值参数」：可调整所有分类边界值和评分阈值
   - Sheet「风险因子权重」：可调整 5 个因子的权重（**必须合计=1.0**）
   - Sheet「参照组优先级」：配置多级兜底链路（产品小类→产品品类→全公司，可调顺序）

## 每月运行

1. 从 ERP 导出销售明细数据，存为 Excel 文件（.xlsx 或 .xls）
2. 双击 `run.py`
3. 在弹出的文件选择窗口中选择刚才导出的数据文件
4. 程序自动计算，生成 `output_YYYY-MM.xlsx`

## 输出文件说明

`output_YYYY-MM.xlsx` 包含 4~5 个 Sheet：

| Sheet | 内容 | 用途 |
|-------|------|------|
| 产品快照表 | 每个产品一行的完整诊断数据 | **主要分析结果**，可导入 Power BI |
| 预警清单 | 筛选风险等级≥高 或 画像为预警/衰退期的产品 | 快速定位问题产品 |
| 画像分布 | 各画像的产品数统计 | 整体组合健康度概览 |
| 数据不足产品清单 | 日历月龄 < 最低记录月数（默认3）的产品 | 确认无遗漏 |
| 使用说明 | 字段含义、名词定义（Winsorization/P95/百分点/月均法等） | 快速查阅参考 |

## 可配置的核心参数（config.xlsx → 阈值参数）

所有硬编码阈值均已搬入配置，无需改代码即可灵活调整：

### 新品判定
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 新品判定模式 | 月数 | 【月数】按日历月龄判定；【销量】按近12月总销量判定 |
| 新品观察月数 | 6 | 新品判定模式=月数时生效 |
| 新品观察最低销量 | 100 | 新品判定模式=销量时生效 |
| 最低记录月数 | 3 | 日历月龄低于此值的产品不进入快照表 |

### 增长判定
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 加速增长阈值 | 0.15 | 增长率>15%为加速增长 |
| 持平下限 | -0.10 | 增长率<-10%为萎缩 |

### 盈利健康判定
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 健康度健康线 | 0.70 | 自比健康度≥70%为健康 |
| 健康度严重线 | 0.50 | 自比健康度<50%为严重侵蚀 |
| 他比严重线(pp) | -10 | 低于参照组均值10pp为严重侵蚀 |

### 退市检测
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 退市判定月数 | 12 | 最后发货距今≥12月为退市 |
| 退市最少历史月数 | 6 | 总日历月龄≥6月才计入退市 |

### 风险评分阈值
各因子（斜率/客户/CV/衰减/历史）的分级阈值和默认分值均可独立调整。

### 其他
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 自比参照分位数 | 0.95 | 历史参照毛利率取P95（可改为0.90即P90） |
| 长尾销量阈值 | 1000 | 月均销量低于此值的产品CV改用稳健算法 |
| 参照组最低产品数 | 3 | 组内产品数≥此值才启用该组均值 |
| P95最少有效月数 | 20 | 月度数据点少于此值自动降为P90 |
| Winsor下限 | 0.0 | 毛利率钳制下限（退货/核算异常保护） |
| Winsor上限 | 0.75 | 毛利率钳制上限（样品单/成本未记账保护） |

## 配置注意事项

1. **风险因子权重**：5项合计必须=1.0，否则综合风险得分系统性偏差
2. **参照组优先级**：从上到下逐级尝试，可删除行跳过某级，可调整顺序
3. **列映射**：分类参照列的列名必须在数据文件中存在，否则程序使用全公司均值
4. **新品判定模式**：修改后程序自动切换判定逻辑，无需改代码
5. **修改参数后直接运行即可**，无需重启或重新安装

## 常见问题

Q: 运行报错"找不到模块"？
A: 双击 setup.bat 安装依赖即可。

Q: 如何更改分类参照组？
A: 在 config.xlsx → 参照组优先级 Sheet 中调整优先顺序即可。
   config.xlsx → 列映射 → 分类参照列 中的值是主参照列名。

Q: 各产品的历史数据不一致怎么办？
A: 程序自动按日历月龄（首末发货月的跨度）计算月龄。日历月龄不足"新品观察月数"（默认6）的产品标记为"新品观察"，日历月龄不足"最低记录月数"（默认3）的不进入快照表。

Q: 如何调整退市判定的严格程度？
A: 在 config.xlsx→阈值参数 中修改"退市判定月数"或"退市最少历史月数"。增大则退市条件更严格。

Q: 输出中"参照组加权均值%"列的来源是什么？
A: 按 config.xlsx → 参照组优先级 Sheet 配置的链路逐级选择，具体来源标注在"参照组均值来源"列中。

Q: 什么是"日历月龄"和"活跃月数"？
A: 日历月龄=首次到末次发货的日历月份跨度（含首尾月），用于判定新品和退市。活跃月数=实际有出货记录的月份个数。
