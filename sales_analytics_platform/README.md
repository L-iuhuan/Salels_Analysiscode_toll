## 一、这是什么？

一个**自动生成销售看板的工具**。

你可以把它想象成一条「**流水线**」：

```
你放进去原始销售明细(Excel)
        │
        ▼
   [流水线自动加工]
        │
        ▼
  出来一个网页看板(output/dashboard/销售数据分析看板_<yyyy年mm月>.html)
  用浏览器打开，就能看各种销售分析图表
```

**你只需要做一件事：把原始 Excel 放进 `data` 文件夹，然后运行一条命令。** 剩下的它全自动完成。

出来的看板长这样（在浏览器里打开后有 6 个标签页，叫 A/B/C/D/E/F 六个「面」）：
- **A面**：公司总览（收入、利润、趋势图）
- **B面**：客户明细（每个客户的情况）
- **C面**：产品分析（每个产品的生命周期、桑基图）
- **D面**：销售员能力（每个销售的业绩、能力画像）
- **E面**：月度作战雷达（按月看变化）
- **F面**：半年总结（部门、新品、问题清单）

## 二、开始之前，你需要准备什么？

| 需要的东西 | 说明 | 怎么检查 |
|---|---|---|
| 一台 Windows 电脑 | 平时办公的就行 | — |
| 装好 Python | 一个免费的运行环境，只需装一次 | 按 `Win+R`，输入 `cmd` 回车，在黑窗口里输入 `python --version` 回车，能显示版本号（如 `Python 3.13.x`）就是装好了 |
| 你的原始销售明细 Excel | 就是 ERP 导出的那个大表（文件名类似 `财务分析-6月（7.6）.xlsx`） | — |
| 人员对应表 | `部门-人员-职务对应.md`（看板 F 面要用到部门/人员信息） | 没有也能跑，只是 F 面部门信息会空 |

> 💡 如果输入 `python --version` 提示「不是内部或外部命令」，说明没装 Python。去 https://www.python.org 下载安装（**安装时务必勾选 "Add Python to PATH"** 那一项），或者找 IT/懂行的同事帮忙装一次。

## 三、第一次使用（手把手，共 4 步）

### 第 1 步：拿到这个文件夹
把整个 `看板流水线` 文件夹放到你电脑上（放哪都行，桌面、D盘都可以）。

### 第 2 步：安装依赖（只需这一次）
1. 打开 `看板流水线` 文件夹，在**地址栏**点一下，输入 `cmd` 然后回车（会弹出一个黑窗口，而且已经在这个文件夹里了）。
2. 在黑窗口里输入下面这条命令，回车：
   ```
   pip install -r requirements.txt
   ```
3. 等它自动下载安装（会看到一堆下载进度，**第一次可能要几分钟**，取决于网速）。装完会回到等待输入的状态。

> 💡 这一步是告诉电脑「运行这个工具需要哪些零件」。只装一次，以后不用再装。

### 第 3 步：放入你的数据
把这两个文件**复制**到 `看板流水线` 文件夹里的 **`data`** 文件夹中：
- 你的原始销售明细 Excel（`财务分析-XX（X.X）.xlsx`）
- `部门-人员-职务对应.md`

> ⚠️ 放进去之后，**请先关闭 Excel**（不要打开着这个文件），否则程序读不到。

### 第 4 步：运行
1. 同样在黑窗口里（如果关了，就再按第 2 步的方法打开一个），输入：
   ```
   python run_chain.py
   ```
2. 回车，然后**等着就行**。它会自己一步步跑，屏幕上会滚动显示进度。
   - **第一次跑大约需要 8~10 分钟**（因为要处理很大的表），中途不要关窗口。
   - 你会看到它先「数据处理」，再「生成看板」。
3. 看到「**完成**」两个字，就说明成功了。它会告诉你看板文件在哪。

### 打开看板
跑完后，打开 `看板流水线` → `dashboard` 文件夹，里面有个 **`dashboard_a.html`**，**双击它**就会用浏览器打开，就能看看板了。

## 四、以后每次用（看情况选一条）

| 你的情况 | 怎么做 | 大概要多久 |
|---|---|---|
| **换了新的Excel数据**（最常见） | 把新 Excel 放进 `data`（旧的可删掉），跑 `python run_chain.py` | 约 8~10 分钟 |
| **数据没变，只是想重新出一下看板** | 跑 `python run_chain.py --skip-processing` | 约 3~4 分钟（跳过了数据处理，快很多） |
| **换了别处的Excel，不想挪动文件** | 跑 `python run_chain.py --data "完整路径\你的文件.xlsx"` | 约 8~10 分钟 |

> 💡 小提示：`--skip-processing` 是「数据没动、只重出看板」的快捷键。只要你没换 `data` 里的 Excel，都可以用它，能省一半时间。

## 五、这个文件夹里都有什么？（哪些能动、哪些别动）

```
看板流水线\
│
├─ run_chain.py        ⭐ 一键启动按钮（你唯一要运行的东西）
├─ chain_config.json   ⚙️ 设置文件（一般不用动）
├─ requirements.txt    📦 零件清单（装依赖时用的，不用动）
├─ README.md           📖 就是这份说明书
├─ docs\               📚 技术存档（效率评估/优化核对报告，不看也能正常使用）
│
├─ data\               📥 【输入】你唯一要放东西的地方：放原始Excel + 人员表
│
├─ output\             📤 【输出】加工好的中间数据都在这里（下面细说）
│
├─ processing\         🔧 【别动】数据处理的程序代码
└─ dashboard\          🔧 【别动】生成看板的程序代码
    └─ dashboard_a.html  ⭐ 最终成品：你的看板（双击用浏览器打开）
```

### 重点说两个文件夹：

**📥 `data`（输入）**
- 这是**唯一需要你手动放文件的地方**。
- 放：原始销售明细 Excel + `部门-人员-职务对应.md`。
- 想换数据，就换这里的 Excel。

**📤 `output`（输出）**
- 这是流水线**加工出来的中间数据**，分三个小文件夹：
  - `silver`：清洗、整理后的明细数据
  - `gold`：汇总好的各种指标表（客户、产品、销售等维度的现成结果）
  - `report`：产品生命周期分析报告（Excel，可直接看）
- **看板就是从 `output` 这里取数画出来的。**
- 💡 **`output` 里的 `gold` 文件夹是个宝**：里面是很多现成的汇总表（CSV格式，用Excel就能打开），你如果想做**其它分析**（比如自己拉个透视表、喂给别的工具），直接用这些表就行，不用重新算。
- 这个文件夹是程序自动生成的，**你不用手动改它**；删了也没关系，下次运行会重新生成。

> ⚠️ `processing` 和 `dashboard` 这两个文件夹是**程序本身**，请**不要**改里面的东西，也别往里放文件。

## 六、搬到另一台电脑

整个文件夹是**自包含**的（里面没有任何指向固定位置的路径），想搬走很简单：

1. 把整个 `看板流水线` 文件夹**完整拷贝**到新电脑（U盘、网盘、共享都行）。
2. 新电脑装好 Python。
3. 在新电脑上做一次「第 2 步：安装依赖」。
4. 把数据放进 `data`，跑 `python run_chain.py`。

> 💡 拷贝时如果嫌文件夹太大：刚跑完时约 900MB（大头是中间数据和看板成品），把 `output` 整个删掉、`dashboard\dashboard_a.html` 删掉就只剩约 250MB——它们都能重新生成。**只有 `data` 里的原始数据和程序文件是必须带的。**

## 七、常见问题（遇到情况先来这查）

**Q1：运行后提示「未找到原始Excel」？**
- 检查 `data` 文件夹里是不是真的有 `.xlsx` 文件。
- 看看是不是有个 `~$开头的.xlsx`（那是 Excel 打开时的临时文件）。把真正的 Excel 关掉再跑。

**Q2：提示「不是内部或外部命令 'python'」？**
- Python 没装好，或安装时没勾选 "Add Python to PATH"。重新安装并勾选那一项。

**Q3：跑到一半卡住/不动了？**
- 第一次处理大表本来就要几分钟，**屏幕不动不代表卡死**，耐心等。只要没报错就让它跑完。
- 如果超过 20 分钟还没好，可以关掉窗口重跑一次。

**Q4：报错了，一大串红字/英文？**
- 把报错内容**整段复制**下来，发给懂技术的同事看。绝大多数情况是数据文件的格式/列名变了（比如 ERP 导出的表换了列名）。

**Q5：看板 F 面（半年总结）里部门、人员是空的？**
- 检查 `data` 里有没有 `部门-人员-职务对应.md`，文件名别改。

**Q6：想看别的月份的看板？**
- 把对应月份的 Excel 放进 `data`（一次放一份最新的就行，程序会自动认最新的那份），再跑一遍。

**Q7：output 里的表能直接用吗？**
- 能。`output\gold` 里的 CSV 文件用 Excel 双击就能打开（如果中文乱码，用 Excel 的「数据→从文本/CSV导入」并选 UTF-8 编码）。

## 八、名词解释（不懂的词来这里查）

| 词 | 大白话解释 |
|---|---|
| **看板 / dashboard** | 一个网页，里面全是销售分析的图表，用浏览器打开看。 |
| **面（A面/B面/…/F面）** | 看板里的 6 个标签页，每个页签看一个角度（总览、客户、产品、销售员、月度、半年）。 |
| **流水线 / pipeline** | 把「原始数据 → 加工 → 出看板」这一连串步骤打包成一条自动流程。 |
| **Python** | 一个免费的运行环境，这个工具靠它跑起来。装一次就行。 |
| **依赖 / 零件（requirements）** | 这个工具运行需要的一些现成组件，第一次用 `pip install` 装好即可。 |
| **silver（银层）** | 把原始乱七八糟的明细，清洗、整理成干净规范的数据。 |
| **gold（金层）** | 在干净数据上，进一步汇总好的各种现成指标表（可直接拿去做别的分析）。 |
| **CSV** | 一种通用的表格文件，Excel 能打开。 |
| **run_chain.py** | 「一键运行」的启动文件，你唯一需要运行的东西。 |
| **ERP** | 你们公司用来记账/管进销存的系统，原始销售明细就是从它导出的。 |
