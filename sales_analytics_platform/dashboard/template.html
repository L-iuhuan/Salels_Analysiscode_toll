看板说明中心

一份数据，七种管理节奏

这是全平台七面看板的统一说明书。数据只有一条链路——每月的 ERP 出货明细；但它要回答的问题分布在七种节奏上：总览看“今年到现在”，作战看“这个月”，专项看“这半年”，风险与行动看“现在该处理什么”。每一章讲清一面：它回答什么经营问题、指标怎么读、怎么算出来、去哪个图表接着看。

一整体设计与数据架构

数据链：从一张 Excel 到七面看板

所有数字都来自同一条加工链。理解这条链，就理解了为什么不同面的同一个指标有时“对不上”——不是算错，而是窗口与口径不同。

每月一次全链路重跑；指纹缓存（preagg.json）保护未变化的重算——模板、配置或源数据任一变化才触发全量。银层 = 清洗后的明细宽表，金层 = 画像与评分结果，交付层 = 单 HTML 看板与审定文档。

加工链上的三个约定

一、展示层做减法，数据层不做减法。主文档只放“一次会议能过完”的重点（如风险榜单前 12 条），全量信号写进附件——漏榜不代表无害，深挖时人工可查。

二、口径与失效条件写在数字旁边。每一处窗口差异（YTD 与近 12 个月、终端客户与代理商）都在页面上显式标注，不靠口头约定，也不靠读者自己去猜。

三、机器初稿与人工审定分离。风险与行动面由每月一份人工审定的文档驱动；审定之前，页面上只是机器初稿——对外引用前先确认审定状态。

二A 面 · 总览决策

今年到现在，经营得怎么样

总览面是全平台的开场白：九张卡 + 地域地图 + 毛利率摘要表，把 YTD 的经营结果一次性摊开——先看大势，再决定去哪个面下钻。

这面回答的经营问题

  • 公司今年整体经营得怎么样？九卡给出今年累计收入 / 毛利 / 毛利率 / 售价 / 新品渗透 / 核心客户贡献，每卡带同比——一屏看完大盘。
  • 收入分布在哪些地域？地域地图（近 12 个月窗口）：点省份看头部客户与产品，广东可下钻到市；识别不出的地址单列“未识别”并披露占比。
  • 哪些产品线与品类在赚钱？毛利率摘要表把产品线 / 品类拆到 YTD 收入与毛利率，KA / AA 层级可切换。

核心指标怎么读

指标怎么读失效条件（什么时候不能信）
九卡主值今年 1 月至今的累计口径，九卡同一分母，可直接相加对照售价卡的“环比”是最新两个月之比，与卡的累计主值不同窗——卡内跨窗是既有设计
广东占比YTD 口径、与九卡同分母它不跟地图的近 12 个月窗口走：两处数字对不上属预期，拿不准时默认以 YTD 为准
地域地图与省份榜近 12 个月窗口，色阶按收入占比分四档依赖发货地址填写质量：空地址 / 乱地址计入“未识别”——未识别不等于没有收入
毛利率明细表产品线 / 品类维度的 YTD 收入与毛利率，并标出 KA、AA 分层摘要不下沉：小基数品类会被单笔大单拉动，看到异常值先回到明细页

口径提示：总览页同时存在两套窗口——KPI 九卡与“广东占比”是 YTD，地图与省份榜是近 12 个月，点开省份看明细又回到 YTD。

计算方式

YoY_R = ( R_ytd − R_pytd ) / R_pytd × 100% ；Δm = m_ytd − m_pytd（pp）
同比口径：本年 1/1 至最新月末 vs 上年 1/1 至上年同月末（同月数对齐）；毛利率差用百分点（pp）表示。ASP = 收入 ÷ 发货数量。
share_r = R_r / R_all
地域占比：分母包含海外与未识别——保证所有份额加总 100%、不做隐性归一；解析不出的部分单列“未识别”桶，让解析质量的退化直接显形在页面上。

三R 面 · 风险与行动

这个月该处理什么

风险与行动面不做分析，做交接：八类信号合并去重、人工审定后形成一张 12 条的榜单，再配套一张跨月结转的行动清单。

这面回答的经营问题

  • 本月有哪些风险信号？八类信号（异常日志 / 营收异动 / 采购中断 / 毛利率恶化 / 衰退风险 / 高风险产品 / 定价异常 / 负毛利）同客户合并为一行，按等级与损失额取前 12 条。
  • 上个月的问题这个月好了吗？“持续”列给出连续第几个月上榜与较上月判定（恶化 / 好转 / 持平）；上月上榜本月消失的进“本月解除”备注——解除不是“没问题了”，是“信号消失，请人来确认”。
  • 每件事谁在跟、进展如何？行动清单三态：待处理 / 跟进中 / 已关闭；仅未关闭事项跨月保留，已关闭永久归档。

核心指标怎么读

指标怎么读失效条件（什么时候不能信）
风险摘要机器初稿 + 人工审定后的结论，以审定为准榜单只有 12 条，其余信号在《风险溢出明细》附件；阈值是经验值、未经回测
风险页整体每月一份审定文档驱动，改完文档重跑即生效文档缺失时系统自动重建初稿；仍失败整页降级为红色警示条——看到红条先找数据管理员，不要引用该页任何结论
较上月判定损失额对比带死区（±10% 且 ≥1 万）——先看损失、再看等级等级是离散粗粒度（高 / 中 / 低，跳档即翻转结论），单看等级容易被四舍五入噪声带走
行动清单未关闭事项跨月自动保留，关闭后归档不再显示审定者改过“等级 / 状态”列名时，着色与统计会显式降级（页面口径条提示、统计卡变“—”），不影响其余列

计算方式

ΔL > +10% 且 |ΔL| ≥ 1 万
较上月的死区判定：两个条件同时满足才判「恶化」（相对幅度 AND 绝对金额 ≥1 万，防“小基数大百分比”误报）；反向 −10% 判「好转」，死区内维持「持平」。
rank = ( 等级 ↓ , 损失 ↓ ) ⇒ Top 12
上榜排序：先按等级（高→低）、再按损失额降序取前 12；溢出信号全量写入附件——这是“有界榜单 + 无损附件”的一般模式。

四B 面 · 客户 360

一个客户，四层回答

客户面把每个客户拆成“值多少钱、还在涨吗、靠得住吗、下一步做什么”四层来回答——收入排行只是最表面的一层。

这面回答的经营问题

  • 这个客户现在值多少钱？综合价值层级（S / A / B / C）+ 双轴分类（明星 / 潜力 / 金牛 / 瘦狗）：五个维度加权评分后划档——明星 = 高价值还在涨，金牛 = 高价值已稳，瘦狗 = 双低控成本。
  • 他还在涨吗、靠得住吗？增长动能（收入增长率、同比、连续增长 / 下滑月数）与风险评级（节律断档、波动剧烈、毛利率被侵蚀）分开看。
  • 客户什么时候会再买？有流失迹象吗？采购节律：按历史平均采购间隔推算“预计下次采购”，已超期的客户亮出超期天数——超期越久流失嫌疑越大。
  • 对这个客户下一步做什么？详情页的策略建议与触发原因（系统按规则生成），配套异常提醒汇总——建议可解释、可追溯。

核心指标怎么读

指标怎么读失效条件（什么时候不能信）
综合价值层级S 约为当前全部客户的前 5%，A 前四分之一，B 到前七成近 12 个月没交易的客户不参与评级、直接标“休眠”——休眠客户的分数没有读法
风险评级极高 / 高 / 中 / 低，度量的是关系脆弱信号它不是财务信用、也不预测违约——回款问题另走财务口径
双轴四象限以活跃客户的中间线分界，每象限约四分之一相对位置：全员都在涨的年份，“金牛”也可能是正增长客户——先看大盘再解读象限
增长率 / 同比看方向和连续性——连续三个月比单点可信增长率已封顶（极端增长最多 +500%）；同比未封顶，出现几千个百分点属超低基数客户——看方向别抠幅度
代理商视图收入毛利均为当年累计口径，可展开看到终端客户销售模式填了公司名或留空的交易不进本视图（两组合计小于总盘）；同一客户经多家代理商拿货会分别列示，各代理商客户数相加大于实际客户数

口径提示：评分族（层级 / 风险 / 双轴 / 五维分）是终端客户 × 近 12 个月画像口径；列表收入毛利与代理商视图是当年累计现算口径——同一客户两处“收入”对不上是口径不同、不是算错。

计算方式

S = 0.35 D₁ + 0.25 D₂ + 0.20 D₃ + 0.15 D₄ + 0.05 D₅
五维综合分：D₁–D₅ 依次为价值 / 增长 / 稳定 / 潜力 / 效率；层级阈值 S ≥ 34、A ≥ 28、B ≥ 22，其余 C，非活跃客户统一覆写为「休眠」。权重是设计时的经验判断，从未做过校准对拍（见终章账目）。
S_risk = 0.70 (100 − D_stable) + 0.30 (100 − D_eff)
风险评级：取「稳定」与「效率」两维的反向加权（≥85 / 78 / 60 分为极高 / 高 / 中 / 低）——度量的是关系脆弱度，不是财务信用。

五C 面 · 产品生命周期

每个产品：在什么阶段、赚不赚钱、衰退了没有

产品面不做“一打了分的排行榜”，而是把每个产品放进“销量动能 × 盈利健康”的交叉格子——风险评分刻意往“宁可多预警”校准：误杀一个还在赚钱的产品，代价远大于多复核几条预警。

这面回答的经营问题

  • 钱该往哪些产品投？投入区清单（成长期 / 健康扩张）：争产能、备货、销售资源；重点产品（近 12 月营收百万以上）看“降本 1% 能提多少毛利率”。
  • 哪些产品该准备退场？退出区清单（夕阳 / 衰退）：控库存、规划替代型号、安排退市节奏；毛利率明显回升的衰退品，先复核“是否主动瘦身”再决定退不退。
  • 哪些表面平静其实在失血？自比健康度（现在赚的是自己巅峰的几成）× 他比健康度（比同类差几个点）——量稳利跌的产品总量报表看不见，靠两个健康度交叉才能发现。
  • 衰退要来了吗？风险评分四档 + 主导因子：动能衰减主导 → 查下游需求和大客户；毛利趋势主导 → 查成本和定价。主导因子比总分更重要。

核心指标怎么读

指标怎么读失效条件（什么时候不能信）
自比健康度0.6 = 现在的盈利只有自己巅峰的六成；0.7 以上健康，跌破 0.5 严重侵蚀上市不满 1 年的标杆降档、读数偏乐观；历史上没有赚钱月份 = 无法评估
他比健康度低于同类平均的百分点数；低 10 个点以上严重侵蚀，不低于同类算达标同类产品不足 3 个、回退到大类或全公司平均时，仅供参考
风险评分55 / 65 / 68 三条线分低-中-高-极高四档；含义是“值得优先看一眼”的排序误报率未统计（见终章账目）；且要先看主导因子再看总分
未来 3 月预测点值供排产草案；80% / 95% 两档区间刻画不确定性数据太短的产品只有平滑外推、不给区间——只能当方向参考，不能做库存承诺；区间未回测

口径提示：退货 / 红冲默认保留、自然冲减收入与销量（净额口径）；每月以 25 号为界，残月整月剔除、基准回退上月，防残月混进“近 12 月”窗口。

计算方式

S_risk = Σ Sᵢ wᵢ ；(w₁, w₄, w₅, w₆) = (0.10, 0.60, 0.20, 0.10)
综合风险：四因子加权——动能 60%、自比健康 20%、毛利趋势 10%、大客户订货 10%（生产上大客户因子未生效，权重自动让渡给其余因子）。权重来自历史版本的经验校准，样本已无法复现。
H_self = m₁₂ / m_peak
自比健康度：近 12 个月毛利额 ÷ 历史峰值毛利额；0.6 表示现在只有自己巅峰的六成。历史上没有赚钱月份的产品判“无法评估”，不参与该维度比较。

六D 面 · 销售能力

不做收入排行榜

把每位销售员拆成九种能力分别打分，再放进“同体量、同客户结构”的小组里定 A / B / C / D——因为管 332 个客户和管 12 个客户的销售员放在一张榜上，怎么排都不公平。

这面回答的经营问题

  • 每个销售员靠什么赚钱？九维雷达：绝对贡献、客户维系、品类拓展、客户升级、新客开拓、产品结构、组合抗风险、定价博弈、客户激活——个人形状 vs 团队均值，一眼看出强项短板。
  • 他在同类人里排第几？先按体量分组（重量 / 中量 / 轻量级），再按客户结构分组（大客户 / 均衡 / 批量型），小组内排百分位——A = 同类组前 30%。
  • 收入差不多的两个人，谁的结构更健康？气泡图（横轴收入、纵轴毛利率、气泡 = 客户数、颜色 = 客户结构类型）+ 组合抗风险分：一个大客户撑八成的销售员，气泡大但抗风险分低。
  • 客户利润藏在谁手上？客户利润热力图：前 33 大客户 × 销售员的利润矩阵——颜色最深的格子就是“利润最集中的那个人那家客户”。

核心指标怎么读

指标怎么读失效条件（什么时候不能信）
九维各维分数50 分是中性起点，不是团队均值；看形状和相对差距，别抠绝对值“客户激活”维度：名下没被分配激活策略的销售员恒为 50——没被考过，不是考得好
综合能力分九维加权（绝对贡献占 35%，其余 8 维分摊 65%）跨组不可比：批量型组的 72 分和大客户型组的 72 分不是一个意思
能力等级 A/B/C/D同类组内定位：前 30% 为 A、之后 30% 为 B、末 25% 为 D、其余 C小组人少时定级不稳：3-5 人的组里一人变动会牵动全组；组内只有 1 人时直接给 B（保底，不是评价）
硬保护近 12 月画像口径总营收超 8000 万强制 A 级、总营收归零强制 D 级——不看排名这两类的等级是营收事实，不是能力结论
客户 / 品类热力图客户图看利润、品类图看收入；行列只取头部（前 33 客户 / 前 15 品类 / 前 15 销售员）现算口径：当次从出货明细聚合，与能力等级的近 12 月窗口不同；头部之外的格子不在图上

口径提示：能力分数与等级 = 近 12 个月画像口径；排名表业绩列与两张热力图 = 当年 YTD 现算口径。两套并存是历史形成、尚未合并——同一人两处“营收”可能不相等。

计算方式

S = clip( 50 + Σ Δᵢ , 0 , 100 )
50 分基线 + 偏移累加：每个维度都从 50 分出发、按子项加减、截断到 [0, 100]。缺数据的子项自然跳过、分数退回中性 50——注意 50 是中性点，不是任何统计量。
HHI = Σ_c ( R_c / ΣR )² ；S_risk = clip( (1 − HHI) × 100 , 0 , 100 )
组合抗风险（v4.14 新增）：客户营收份额平方和 HHI——单客户垄断 HHI = 1 → 0 分，完全分散 → 趋近 100 分。它是九维中唯一不是“50 基线结构”的维度。该维度的证据文案有取数缺陷，见终章账目。

七E 面 · 月度作战雷达

这个月的钱，从哪来、为什么变

作战面是月度执行视图：谁在异动、收入波动是量还是价、谁第一次大批量拿货——粒度到月，动作到人。

这面回答的经营问题

  • 本月哪些客户在异动？势能矩阵：横轴增长率、纵轴毛利率，定位高增 / 下滑 / 高利润 / 低利润客户，同比 / 环比可切。
  • 收入波动是量的原因还是价的原因？量价拆解：销量变化带来的部分 vs 售价变化带来的部分，四个维度可切（产品线 / KA 客户 / AA 客户 / Top10 品类）。
  • 谁第一次大批量拿货？首次导入：单笔 ≥6000 颗且历史上没出现过的客户 × 品种组合，按销售员聚合——新品与老客户双视角都能用。

核心指标怎么读

指标怎么读失效条件（什么时候不能信）
量价拆解看方向（量驱动还是价驱动）与相对大小——“量驱动型 / 价驱动型”按两项绝对值较大者判定拆分之和不严格等于收入变化（量价交叉项不摊分）；上期没有销量的新项不参与拆分、标 NEW
首次导入“首次”以系统数据覆盖的全部历史为界，门槛为单笔 ≥6000 颗数据起点之前的历史无法识别——个别“首进”可能只是老品种回归
势能矩阵横轴增长率、纵轴毛利率，四象限直接对应资源态度矩阵覆盖当月有交易的客户，新导入客户会改变象限基数
月度 KPI所选月份区间的收入 / 毛利 / ASP / 发货量 / 活跃客户 / 首次导入数区间可跨月选择，与总览的 YTD 不同窗——两处数字不可直接比

计算方式

ΔR = ΔQ·ASP_prev (v_Q) + ΔASP·Q_prev (v_P) + ΔQ·ΔASP (residual)
量价分解：收入变化 = 量贡献 v_Q + 价贡献 v_P + 交叉项残差。交叉项不摊分是设计选择——量价分解是会计口径、不是物理定律，线性归因会系统性偏袒一侧；误差量级留给使用者判断（见终章账目）。
Q_prev = 0 ⇒ v_Q = v_P = 0 ⇒ NEW
新项处理：上期没有销量的组合不去强行拆分——变化列直接标 NEW，表示本期收入全部为增量；毛利变化 ΔP 单独成列核算，不混入收入拆解。

八F 面 · 半年度专项

这半年，和上半个半年、去年同期比

专项面半年一开（复盘期人工开启，平时页签隐藏）：把当前半年窗、上一半年窗、去年同期窗放进同一行里逐行对比——窗口由数据月份自动推导。

这面回答的经营问题

  • 这个半年和上半个半年、去年同期比怎么样？三窗对比：产品线 / 品类 / 部门 / 核心客户逐行对比，当前窗值 + 两对比窗值 + hoh / yoy 增幅与毛利率 pp 差。
  • 半年毛利率下滑是谁拖累的？关键问题与归因：下滑对象逐品种列影响额，客户级问题区分“价格原因”还是“结构原因”——结论可直接进复盘会。
  • 哪些部门 / 产品线的毛利在改善？部门雷达图 + 产品线 / 品类毛利率表（产品线 / 品类可切），点击行可展开成员或下钻到明细。

核心指标怎么读

指标怎么读失效条件（什么时候不能信）
三窗对比当前半年窗 / 上一半年窗 / 去年同期窗；四组聚合（产品线 / 品类 / 部门 / KA·AA 客户）共用同一行构造KA / AA 客户的对比窗取该客户在对比窗内的子集——层级跨窗漂移（去年 KM 今年 KA）时，按当时层级取数才可比
窗口定义窗口由数据月份自动推导；7 月数据展示的是刚完结的上半年半年窗中途打开、数据不满窗；窗口最后一月的环比在窗口首月必然显示“—”（禁止填 0 伪造）
开放节奏复盘期人工开启，当前页签处于关闭状态平时连计算都跳过，也没有“复盘期临近”提醒——开启当月才暴露问题（登记在案）

计算方式

hoh = (R_cur − R_half) / R_half ；yoy = (R_cur − R_year) / R_year ；Δm = m_cur − m_base
三窗对比：hoh 对上一半年窗、yoy 对去年同期窗、毛利率用 pp 差；窗口内月度环比锚在末月，前一月越出窗口起点即无值（显示“—”）。
impactᵢ = Rᵢ × Δmᵢ / 100
归因影响量：按影响最负排序取前 8，定位“谁把毛利率拖下来的”；客户级归因再判价格原因 / 结构原因 / 综合原因，结论写入关键问题表供复盘会引用。

这页怎么读

  1. 先看标注，再信数值。标注为空 = 该数字在本期全部可靠；带失效条件标注的，先读标注再读数。
  2. 先看方向，再看单点。单月波动正常，连续三个月的方向比单点可信；量价拆解看方向，不抠小数。
  3. 口径不同的数字不可互比。YTD 与近 12 个月、终端与代理商、画像与现算——每处差异都标注在页面旁边，跨口径比较前先确认窗口。
  4. 三套评分体系各答各的对象。客户五维评客户、销售九维评销售员、产品九宫格评产品，刻度互不相通：“客户 S 级 + 对接销售员 D 级 + 主力产品在衰退区”可以并存、不矛盾。
  5. 对账以财务口径为准。看板数字用于结构与趋势判断，不用于对账。
