# 批次⑦ Excel 报告开关 + 提价机会有效行过滤 — 修改说明与验证报告

> 日期：2026-08-25 · 决策人：用户拍板（"excel 加开关默认不要输出；提价机会只输出有效行"）
> 状态：**本地已完成并验证，未推送**。改动 5 个文件，带 `[批次⑦]` 注释。
> 验证数据：真实生产数据（财务分析-7月，199,681 行 / 3,196 客户 / 824 产品）。

---

## 一、改动内容（5 个文件）

### 1. Excel 报告开关（默认关闭）
- `config/settings.py`：新增 `EXCEL_REPORT = {"customer_enabled": False, "product_enabled": False}`。
  两份 Excel 报告（客户分析报告 / 产品生命周期报告）不被看板与管道消费，纯人工查阅交付物；
  需要时改 True 即可恢复，无需改代码。
- `reports/gold_exporter.py`：`save()` 在开关关闭时跳过客户 Excel 报告（仍写全部 gold CSV），返回 None。
- `product_lifecycle/report.py`：`write_excel_report()` 在开关关闭时跳过，返回 None。
- `product_lifecycle/run.py`：开关跳过时以画像产物（gold_product_portrait.csv）为成功判据，
  打印"已完成（Excel 报告已按配置跳过）"，不产生误报告警。

### 2. 提价机会只输出有效行
- `customer_analysis/gold.py`：`markup = markup[markup["可提价标记"]]` 后再 `_inject_tier`。
  背景：category 模式下 categorical groupby 默认 observed=False 展开客户×产品叉积，
  真实数据下 2,633,504 行 / 178.6MB，其中 `可提价标记=True` 仅 505 行，未标记行无下游消费。

## 四、恢复 Excel 报告的方法

`processing/config/settings.py` 中：
```python
EXCEL_REPORT = {
    "customer_enabled": True,   # 恢复客户分析报告
    "product_enabled": True,    # 恢复产品生命周期报告
}
```
恢复后客户 Excel 报告将只含 505 行有效提价机会（同步瘦身，生成时间也会比历史版本快）。
