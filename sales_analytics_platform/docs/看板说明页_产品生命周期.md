# 产品生命周期看板 · 说明页

> 这页说明随看板发布，用人话讲三件事：**看板回答哪些经营问题、每个数字怎么读、什么时候不能信**。
> 数据基础：全公司出货明细（2020 年 1 月起），每月产出一张产品快照表，覆盖在售 900 多个产品。
> 设计者的一句话：这套看板不做"一打了分的排行榜"，而是把每个产品放进"销量动能 × 盈利健康"的交叉格子——因为加权总分会把"量增利跌"和"量跌利稳"两种完全不同的病搅在一起。风险评分刻意往"宁可多预警"校准：误杀一个还在赚钱的产品，代价远大于多复核几条预警。

## 一、这页看板回答什么问题

| 你要问的 | 看板怎么看 |
|---|---|
| 钱该往哪些产品投？ | 投入区清单（成长期 / 健康扩张）——争产能、备货、销售资源；重点产品（近 12 月营收百万以上）看"降本 1% 能提多少毛利率"，增长翻倍的常规品看加投机会 |
| 哪些产品该准备退场？ | 退出区清单（夕阳 / 衰退）——控库存、规划替代型号、安排退市节奏；毛利率明显回升的衰退品先复核"是否主动瘦身"再决定退不退 |
| 哪些表面平静其实在失血？ | 自比健康度（现在赚的是自己巅峰的几成）× 他比健康度（比同类差几个点）——量稳利跌的产品总量报表看不见，靠两个健康度交叉才能发现 |
| 衰退要来了吗？ | 风险评分（四档）+ **主导因子**：动能衰减主导 → 查下游需求和大客户；毛利趋势主导 → 查成本和定价。主导因子比总分更重要 |
| 新品起来了吗？ | 新品观察池（不打分，是设计决策不是遗漏）+ 首次单月 6000 件用时（爬坡速度标尺） |
| 成本压力藏在哪里？ | 毛利趋势的品类分布 + 价格联合诊断：降价且利缩 = 价格战；没降价利却缩 = 成本问题 |
| 未来 3 个月怎么备货？ | 预测值 + 80%/95% 两档区间：区间越宽说明越难预测、备货越保守 |
| 产品组合整体健康吗？ | 四区占比逐月变化 + 流转图：退出区占比持续扩大 = 组合老化预警（比任何单品评分都可信） |

## 二、指标速览：怎么读、什么时候不可信

| 指标 | 怎么读 | 什么时候不可信（看板有标注） |
|---|---|---|
| 九宫格画像 | 销量增长四档 × 盈利健康三档 → 9 种画像，每种绑定一个资源态度（加 / 守 / 查 / 退） | 增长率基于 6 或 3 个月缩窗时可能不稳定 |
| 自比健康度 | 0.6 = 现在的盈利只有自己巅峰的六成；跌破 0.5 严重侵蚀；0.7 以上健康 | 上市不满 1 年的标杆降档、读数偏乐观；历史上没有赚钱月份 = 无法评估 |
| 他比健康度 | 低于同类平均的百分点数；低 10 个点以上严重侵蚀；不低于同类算达标 | 同类产品不足 3 个、回退到大类或全公司平均时仅供参考 |
| 毛利趋势 | 最近半年毛利额每月的升降速度，降得越急侵蚀越快 | 数据不足 3 个月时不可靠；单月大单会扭曲——只看方向，别抠幅度 |
| 销量增长率 | 高于 +15% 算加速；−10% 及以下算萎缩；极端基数封顶在 +500% / −100% | 被封顶的产品实际涨跌更深 / 更高（有标注） |
| 增速衰减 | 最近 3 个月比全年水平慢了几个百分点——最早出现的拐点信号 | 高爆发产品从峰值自然回落已自动豁免；但同比已实际转负的不豁免 |
| 连续下降月数 | 逐月连跌的月数，≥4 个月构成独立风险信号 | — |
| 风险评分 | 55 / 65 / 68 三条线分低-中-高-极高四档；含义是"值得优先看一眼"的排序，不是衰退判定 | 误报率未统计（见"四条账"）；先看主导因子再看总分 |
| 大客户订货量因子 | 设计中占 10% 权重、从客户端交叉验证需求 | 生产上从未生效、权重自动让渡给其余因子（见待拍板③） |
| 客户集中度 | 第一大客户营收占比超过 50% = 单点崩塌风险 | 客户不足 3 个时，前三客户占比按 100% 记 |
| 未来 3 月预测 | 点值供排产草案；区间刻画不确定性 | 数据太短的产品只有平滑外推、不给区间——只能当方向参考，不能做库存承诺；区间未回测 |

**读数优先级**：先主导因子、再总分；先看标注、再信数值（标注为空 = 数据全部可靠）。

**三条全局口径**，读任何数字前应知道：

- 退货 / 红冲默认保留、自然冲减收入和销量（净额口径，反映经营真实；另一口径的差异见待拍板①）
- 每月以 25 号为界：最新月份最后一笔发货早于 25 号，该月整月剔除、基准回退上月——防残月混进"近 12 月"窗口
- 历史从 2020 年 1 月起算：黄金期在 2020 年之前的产品"巅峰"看不见，自比健康度会偏高；早期历史流转数据曾有一处口径瑕疵（误用未来数据）已修复，修复前的流转对比严谨性打折

## 三、四条我们还的账（诚实清单）

设计者自述的已知欠账，登记在案、不藏进技术细节：

1. **风险评分的权重是历史经验值**。现在的配比（动能 60%、自比健康 20%、毛利趋势 10%、大客户 10%）来自历史版本的经验校准，当时的校准样本已无法复现——我们能证明"曾被数据校准过"，证明不了"最优"。**建议补法**：用已修复口径的历史画像重建"当时指标 → 后来实际衰退"的样本，重新推导一遍与现行值对拍，差异大才调。
2. **每月预警名单的误报率从未统计**。我们有意选择"宁可多预警、绝不放走真衰退"，但没统计过预警里多少是误报——若误报占比过高，复核会疲劳、预警会失去信任。**建议补法**：立项回溯统计高 / 极高风险产品的实际衰退命中率，用数据校准预警松紧。
3. **预测的 80%/95% 区间从未回测**。区间实际能罩住多少比例的结果未知，目前只能当"不确定性大小"的相对刻度。**建议补法**：用历史截点逐月回测区间覆盖率，达标后再作为备货决策依据。
4. **各阈值调整的影响面未测算**。任何一道分档线挪一点、会有多少产品跨档，现在答不上来。**建议补法**：对关键阈值做一次性敏感度扫描，形成"参数-影响"对照表附在配置旁。

## 四、需要管理层拍板的三件事

| 事项 | 现状 | 需要拍板 |
|---|---|---|
| ① 退货从销量里扣不扣 | 保留退货冲减（净额口径） | 经营分析以净额还是发货额为准。两口径差异量级**待测算**——可立项一次性跑对比，看多少产品因此换画像 / 换风险档，再拍板 |
| ② 毛利率极端值怎么处理 | 数据层保留真实值、仅展示层截断（此前验证：反向操作会高估收入约 0.5%） | 已拍板方向，确认维持现状即可；这是回退阀门，默认不动 |
| ③ 大客户订货量因子要不要恢复 | 设计中有（10% 权重），生产上从未生效、权重自动让渡 | 恢复需打通大客户订单数据通道，成本与收益**待评估**；不恢复则把现行三因子安排正式固定。我们倾向恢复——客户端的独立佐证价值高 |

## 五、使用边界

风险分是"值得人工优先看一眼"的**排序工具**，不是衰退的事实判定——把评分直接当退市依据，超出了它的设计能力。单品评分有噪声，四区分布的逐月趋势更稳。
