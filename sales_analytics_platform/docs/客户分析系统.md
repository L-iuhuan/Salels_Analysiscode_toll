## 1. 系统概述（平台版）

客户分析系统从**共享 Silver 层**读取数据，输出客户全景画像（60+ 指标/客户）、评分评级、定价建议、趋势分析，形成 **30 张 Gold 表（CSV）** 与 Excel 报告，供看板 **B 面（客户360）/ D 面（销售能力）/ A 面（KA/AA）** 消费。

### 数据管道

```
ERP Excel（DSE 加密，COM/快照双通道读取）
    ↓ 共享清洗（shared/data_cleaning：负数量保留/毛利率不钳制/双通道月度聚合）
  Silver层（4 表）
    ├─→ 产品生命周期分析（product_lifecycle/，独立管道）
    └─→ 客户分析（customer_analysis/run_pipeline.py）
          ├─ 客户全景画像 portrait.py（60+ 指标）
          ├─ RFM-π 评分（渠道隔离）
          ├─ 5维度评分卡 + 综合评级/机会评级/风险评级
          ├─ 行动建议（规则引擎）
          ├─ B2B v2：旅程7阶段/波动性/真实利润/异常检测/交叉销售
          ├─ 价格深度分析（价格带/跨客户差异/渠道对比/定价建议）
          └─ ETS 客户预测（未来3月）
    ↓ generate_gold_tables()（含 B2B v2 LEFT JOIN）
  30张Gold表 + Excel报告 → 看板 B/D/A 面
```

### 评分金字塔体系（不变，权重确认）

五维评分卡：**价值贡献 35% / 增长动能 25% / 稳定关系 20% / 战略潜力 15% / 效率运营 5%**（`SCORE_DIMENSION_WEIGHTS`）→ 综合价值分 S/A/B/C + 机会评级 + 风险评级 + 双轴行动矩阵（明星/金牛/培育/瘦狗）。

### 入口

```bash
python run_chain.py                    # 平台全链（customer 阶段）
python -m customer_analysis.run_pipeline   # 模块单独运行（processing/ 下）
```

## 2. 数据管道要点（平台版校正）

- **客户 ID 三级降级**（取数）：终端客户简称 → 代理商/直供名称 → 客户列兜底（`CHANNEL_DERIVE` 驱动）
- **渠道类型三级降级**：销售模式直取 → `_derive_channel`（原始列名匹配， buyer/end-customer 规则）→ 默认未知
- Silver 缓存：`SKIP_SILVER_IF_EXISTS=True` 静默跳过——改清洗逻辑/ERP_COL_MAP 后须 `--force-silver` 才生效
- CSV 输出统一 UTF-8-BOM（Excel 中文兼容）
- `sheet_name=0` bug 已修（现用 `DATA_SHEET_NAME` 配置）

## 3. 模块清单（processing/customer_analysis/）

| 模块 | 职责 |
|---|---|
| `portrait.py` | 客户全景画像（60+ 指标；渠道推导在此） |
| `scoring.py` | RFM-π + 5 维评分卡 + 评级 |
| `dimensions.py` / `group_aggregation.py`（禁用） | 维度定义 / 分组聚合 |
| `trend_analysis.py` | 月度营收趋势 / 品类迁移 |
| `price_deep_dive.py` | 价格深度分析 4 表 |
| `gold.py` | Gold 表编排（**B2B v2 集成点**：generate_gold_tables LEFT JOIN） |
| `run_pipeline.py` | 管道入口 |
| `b2b_v2/`（经 analysis 适配器接入） | journey（7 阶段）/ behavior（波动）/ profitability（真实利润）/ anomaly（IsolationForest+规则）/ actions（交叉销售+规则引擎） |

> B2B v2 配置：`settings_customer.py` 的 `CUSTOMER_JOURNEY_THRESHOLDS` / `VOLATILITY_METRICS` / `ESTIMATED_COST`。

## 4. 看板消费

| 面 | 内容 |
|---|---|
| **B 面 客户360** | 双模式（终端客户/代理商）+ 层级/风险/行动筛选 + 客户详情（bSubWrap 下钻） |
| **D 面 销售能力** | 销售员排名 / 九维雷达（权重与基准见 GUIDE_DETAIL D_radar）/ 气泡图 / 瀑布 / 客户×销售员利润热力图（色阶 95 分位截断） |
| **A 面** | KA/AA YTD 卡 + KA 客户列表 + 散点（过滤规则见 GUIDE_DETAIL A_scatter） |
| R 面（风险） | 客户风险信号经风险面行动项联动 |

## 5. 与产品生命周期系统的边界

- RFM-π 客户分群、产品关联分析：**归属客户管道**（产品管道 run.py 已移除对应调用）
- 新品口径差异：客户侧纯 ERP 标记；产品侧 ERP 标记优先 + 月数/销量双轨兜底
- 共享模块（shared/）：calc_utils / classifiers / data_cleaning / forecasting / risk_scoring 为两管道共用，勿在单侧复制逻辑
