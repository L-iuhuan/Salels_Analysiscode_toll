# 客户360看板 · 说明页

> 这页说明随看板发布，用人话讲三件事：**看板回答哪些管理问题、每个数字怎么读、什么时候不能信**。
> 数据基础：全部终端客户的出货明细（近 12 个月画像 + 当年累计），每月刷新一次。
> 设计者的一句话：这页看板把每个客户拆成"值多少钱、还在涨吗、靠得住吗、下一步做什么"四层来回答——收入排行只是最表面的一层。

## 一、这页看板回答什么问题

| 你要问的 | 看板怎么看 |
|---|---|
| 这个客户现在值多少钱？ | 综合价值层级（S/A/B/C）+ 双轴分类（明星/潜力/金牛/瘦狗）：五个维度加权评分后划档，明星=高价值还在涨，金牛=高价值已稳，瘦狗=双低控成本 |
| 他还在涨吗、靠得住吗？ | 增长动能与风险评级：收入增长率、同比、连续增长/下滑月数看势头；风险评级看关系脆弱度（节律断档、波动剧烈、毛利率被侵蚀） |
| 客户是什么层级？ | 左侧按 KA/AA/KM/MM 筛选——层级是**客户公司自身的年营收规模**（超1亿/超5000万/超1000万/以下），不是在我们这的采购额 |
| 客户什么时候会再买？有流失迹象吗？ | 采购节律：按历史平均采购间隔推算"预计下次采购"，已超期的客户亮出超期天数——超期越久流失嫌疑越大 |
| 他买了什么、新品接不接受？ | 客户详情下钻：品类构成环、在采品种数、Top 产品卡（可切近3月到当年累计四档窗口）、新品采购明细 |
| 价格上谁吃亏、谁占便宜？ | 详情页的售价对比市场（偏离百分比）与低/中/高价采购占比——异常低价客户另有专表供审查 |
| 经销和直销的盘子怎么分布？ | 列表顶部切"按销售模式"：经销按代理商聚合（可展开看到终端客户）、直销直接列终端客户 |
| 对这个客户下一步做什么？ | 详情页的策略建议与触发原因（系统按规则生成）、异常提醒汇总 |

## 二、指标速览：怎么读、什么时候不可信

| 指标 | 怎么读 | 什么时候不可信（看板有/应有标注） |
|---|---|---|
| 综合价值层级 | S 约为当前全部客户的前 5%，A 前四分之一，B 到前七成 | **近 12 个月没交易的客户不参与评级，直接标"休眠"**——休眠客户的分数没有读法 |
| 风险评级 | 极高/高/中/低，度量的是关系脆弱信号 | 它不是财务信用，也不预测违约——回款问题另走财务口径 |
| 双轴四象限 | 以活跃客户的中间线分界，每象限约四分之一 | **相对位置**：全员都在涨的年份，"金牛"也可能是正增长客户——先看大盘再解读象限 |
| 增长率/同比 | 看方向和连续性（连续三个月比单点可信） | 增长率已封顶（极端增长最多显示+500%）；**同比未封顶**，出现几千个百分点属超低基数客户，看方向别抠幅度 |
| 活跃状态 | 三档：活跃/微量活跃/非活跃 | 微量活跃线=有交易客户中收入最低的四分之一——它随整体客户池浮动，不是固定金额线 |
| 预计下次采购 | 上次采购日+历史平均周期推算 | 采购不规律的客户（间隔忽长忽短）参考价值低，配合采购周期天数一起看 |
| 品种数 | 详情页为近 12 个月在采品种；代理商卡片为当年累计 | **两个窗口不同，数字对不上属预期**，不是数据错误 |
| 代理商视图 | 收入毛利均为当年累计口径 | ①销售模式填了公司名或留空的交易不进本视图，**两组合计小于总盘**；②同一客户经多家代理商拿货会分别列示，**各代理商客户数相加大于实际客户总数**（顶部客户数已去重） |

**一条全局口径**，读任何数字前应知道：

- 评分族（层级/风险/双轴/五维分）= 终端客户 × 近 12 个月画像口径；列表收入毛利与代理商视图 = 当年累计现算口径——同一客户两处"收入"对不上是**口径不同、不是算错**；默认以终端近 12 月口径为准。

## 三、我们还在的账（诚实清单）

设计者自述的已知欠账，登记在案、不藏进技术细节：

1. **评分权重是经验值，从未校准对拍**。五个维度 35%/25%/20%/15%/5% 的配比是设计时的经验判断，没有留下校准脚本，也没做过敏感性验证——我们能证明"何时定的"，证明不了"为什么是这个数"。**建议补法**：把评级线校准写成可重跑脚本（输出分位数、建议阈值、各层级名单变动数）；对权重做一次敏感性对拍（35% 对比 30%/40%，看 S/A 名单变多少家）再决定是否调整。
2. **客户口径在 2026 年 6 月换过一次**：从 310 个代理商实体换成 3850+ 终端客户，评分线按新客户池重新校准过；代理商视角保留为另一套当年累计口径——**两套数字对不上是口径不同，不是算错**。**建议补法**：正式确认双口径定位，并附一页"同月总收入两口径对照"说明。
3. **客户所在区域没有数据来源**，区域类分析当前整体不可用。**建议补法**：出货明细补部门列、或恢复客户信息表供数、或重启客户主数据匹配——三选一，前两者改动小。
4. **增长类指标的截断标准不统一**：增长率有封顶、同比没有。**建议补法**：统一截断规则并公示，避免同表数字互相矛盾。
5. **渠道识别完全依赖"销售模式"填写质量**：填错或留空的客户归入"未知"群体，他们在未知群体内部互比，管理含义弱。**建议补法**：源数据做下拉枚举校验，月度追踪未知占比。
6. **集团视角（同一集团多家子公司合并看）已停用**：集团名单覆盖率低、按名称前缀自动识别在 3850+ 客户下误报风险高。**建议补法**：业务方补充集团归属清单后再启用。
7. **"真实利润"名实有偏差**：目前只扣了订单处理费（按每单 50 元估算），不含物流、售后、资金占用。**建议补法**：接入真实成本数据；当下读它请当"毛利参考值"。
8. **效率评分用的是替代指标**（低价采购占比等），不是真实服务成本。**建议补法**：同上——真实成本到位后重设计该项。
9. **部分评分证据已断链**：驱动评分的一些中间分类（旅程阶段、稳定性等级、RFM 层级等）在数据表精简时被删除——分数仍由它们参与算出，但看板上看不到这部分依据。**建议补法**：下钻页补"评分证据"面板，或由开发者按需导出中间列。

## 四、需要管理层确认的四件事

| 事项 | 现状 | 需要拍板 |
|---|---|---|
| ① 双口径定位 | 终端客户为主视图（近12月）、代理商视图为补充（当年累计） | 是否确认此定位？确认后出对照说明页，消除对账困惑 |
| ② 区域字段补法 | 恒显示"未知" | 三方案选一：出货明细加部门列（零代码）/客户信息表供数/主数据匹配重启——建议先做补齐率与成本对比再定 |
| ③ 同比要不要封顶 | 同比未封顶，极端值可达数千百分点 | 统计超低基数客户占比与封顶对排名的影响后决定 |
| ④ 集团视角去留 | 已停用 | 若业务确需集团合并视图，先补集团清单并试算覆盖率；否则正式下线相关配置 |

## 五、使用边界

评分与层级是**当前客户池里的相对位置**，不跨期、不跨渠道直接比绝对分数；先看活跃状态再看分数（休眠客户的分数不读）、先看象限与评级再看综合分、先看三个月趋势再看单月。对某个客户的数字有疑问时，点进详情页看构成（品类、价格、节律）而不是只看总分——但部分评分依据（旅程阶段、稳定性等级等中间分类）已随数据表精简删除，页面上追不到的部分需开发者导出核对。另注意三套评分体系各答各的对象：客户五维评客户、销售九维评销售员、产品九宫格评产品——刻度互不相通、数值不可互比，"客户 S 级 + 对接销售员 D 级 + 主力产品在衰退区"可以并存、不矛盾。业绩对账请以财务口径为准，看板数字用于结构与趋势判断。
