# 总览·作战·专项·风险行动看板 · 说明页

> 这页说明覆盖四个页面：**总览决策、月度作战雷达、半年度专项、风险与行动**（重点讲后者）。用人话讲三件事：看板回答哪些问题、数字怎么读、什么时候不能信。
> 数据基础：ERP 出货明细（前三面当次计算）+ 风险信号库（风险与行动面），每月刷新一次。
> 设计者的一句话：总览看"今年到现在"，作战看"这个月"，专项看"这半年"，风险与行动看"现在该处理什么"——四面是同一份数据在不同管理节奏上的切片。

## 一、这页组回答什么问题

| 你要问的 | 看板怎么看 |
|---|---|
| 公司今年整体经营得怎么样？ | 总览九卡：今年累计收入/毛利/毛利率/售价/新品渗透/核心客户贡献，每卡带同比；产品线与品类的赚钱能力看毛利率摘要表 |
| 收入分布在哪些地域？ | 总览地域地图（近 12 个月窗口）：点省份看头部客户与产品，广东可下钻到市 |
| 本月哪些客户在异动？ | 作战雷达势能矩阵：横轴增长率、纵轴毛利率，定位高增/下滑/高利润/低利润客户 |
| 收入波动是量的原因还是价的原因？ | 作战雷达量价拆解：销量变化带来的部分 vs 售价变化带来的部分，四维度可切（产品线/KA/AA/品类） |
| 谁第一次大批量拿货？ | 作战雷达首次导入：单笔 ≥6000 颗且历史上没出现过的客户×品种组合，按销售员聚合 |
| 这个半年和上半个半年、去年同期比怎么样？ | 半年度专项三窗对比：产品线/品类/部门/核心客户逐行对比（复盘期才开启） |
| 半年毛利率下滑是谁拖累的？ | 半年度专项关键问题与归因：下滑对象逐品种列影响额，客户级问题区分价格原因还是结构原因 |
| 本月有哪些风险信号？ | 风险与行动风险摘要：八类信号（异常客户/营收断崖/采购中断/毛利率恶化/衰退风险/高风险产品/定价异常/负毛利）合并去重后取最重要的 12 条 |
| 上个月的问题这个月好了吗？ | 风险摘要"持续"列：连续第几个月上榜、较上月恶化还是好转；上月上榜本月消失的进"本月解除"备注 |
| 每件事谁在跟、进展如何？ | 行动清单：待处理/跟进中/已关闭三态，跨月自动结转，未关闭事项每月带入 |

## 二、速览与失效条件

| 内容 | 怎么读 | 什么时候不能信（看板有/应有标注） |
|---|---|---|
| 总览九卡 | 今年 1 月至今的累计口径 | 售价卡的"环比"是最新两个月之比，和卡的累计主值不同窗 |
| 总览地域 | 地图与省份榜=近 12 个月；点开明细=今年至今——同页两套窗口，图旁已注明 | 依赖发货地址填写质量：地址空或乱的计入"未识别"并披露占比，但未识别≠没有收入 |
| 量价拆解 | 看方向（量驱动还是价驱动）与相对大小 | 拆分之和不严格等于收入变化（交叉项不摊分）；上期没有销量的新项不参与拆分、标 NEW |
| 首次导入 | "首次"以系统数据覆盖的全部历史为界 | 数据起点之前的历史无法识别，个别"首进"可能只是老品种回归 |
| 半年度专项 | 复盘期才开启（平时页签隐藏）；7 月数据展示的是刚完结的上半年 | 半年窗中途打开数据不满窗；窗口最后一个月的环比在窗口首月必然显示"—" |
| 风险摘要 | 机器初稿 + 人工审定后的结论，以审定为准 | 榜单只有 12 条，其余信号在《风险溢出明细》附件；阈值是经验值未经回测 |
| 风险页整体 | 每月一份审定文档驱动，改完文档重跑即生效 | 文档缺失时系统自动重建初稿；仍失败整页降级为红色警示条——看到红条先找数据管理员，不要引用该页任何结论 |
| 行动清单 | 未关闭事项跨月自动保留，关闭后归档不再显示 | 审定者改过表格核心列（等级/状态）名称时，着色与统计会显式提示降级（页面口径条自动提示，风险统计卡变"—"），不影响其余列 |

**一条全局口径**，读总览页任何数字前应知道：

- 总览页有两套窗口：KPI 九卡与"广东占比"卡都是**今年至今（YTD）**口径、与九卡同一分母；地图色阶与省份榜是**近 12 个月**；点开省份看的明细又回到今年至今。**"广东占比"是 YTD、跟九卡同分母，不跟地图的近 12 月走**——两处数字对不上属预期，拿不准时默认以 YTD 为准。

**风险页审定速查（每月一分钟）**：改等级→"等级"格填 高/中/低（可加 🔴🟠🟢⚪ 调行色）；改进度→"状态"格填 待处理/跟进中/已关闭；删一条=删整行；加会议决议=行动清单加一行填齐五列。"等级""状态"两列列名不能改，其余列随意增改。

## 三、诚实账（已知欠账，每条带建议补法）

1. **地址解析准确率没验证过**：识别率只在生成日志里打印，没落成指标，"未识别"桶没人工抽验过。**补法**：每月落盘识别率 + 抽 20 条未识别按金额归类，量化解析质量。
2. **量价拆分的误差量级没标定**：残差（量价交叉项）不摊分也不显示，大异动项"量+价"与收入变化可能差一截。**补法**：拆解表加残差列，误差超过两成时对大项改用对称摊分并标注。
3. **半年度页半年一开，开启当月才暴露问题**：平时连计算都跳过，没有复盘期临近提醒。**补法**：年初/7 月跑批打印提醒，开启前用上月数据预演一次。
4. **风险对拍依赖上月文档的表格格式**：上月改过列名，本月"持续第几月"会全部误判为"新增"且无警告。**补法**：解析受阻时在初稿顶部显式警告。
5. **八类风险阈值没有回测**：全部凭经验设定，命中率和误报率没统计过，调阈值没有基线。**补法**：用过去 12 个月数据回放各通道触发量，形成"通道×月份"矩阵再校准。
6. **"自动关闭"承诺未兑现**：设计稿写过"连续三个月没触发就自动关闭"，实际没实现——长期挂起的事项要靠人工关闭，清单可能越来越长。**补法**：要么实现（先做成三个月提醒），要么正式撤销这条设计。
7. **没人审定时，风险页只是机器初稿**：风险页每月需要一次人工介入，跳过审定页面上就是机器初稿口径——把它当结论引用属越界使用。**补法**：把月初审定排进月度例会固定议程；未审定的月份对外引用须注明"初稿口径"。

## 四、需要拍板的事

| 事项 | 现状 | 需要拍板 |
|---|---|---|
| ① 八通道阈值校准 | 环比 ±50%、跌幅 5 个点、占比 30% 等均为经验值 | 是否安排一次历史回测，再定校准节奏 |
| ② 地址解析抽验 | 未识别占比自动披露，但解析对错无人核 | 是否每月做一次小额抽验（20 条） |
| ③ 半年页开启节奏 | 复盘期人工开启，无提醒 | 是否加"临近复盘期"提示 |
| ④ 长期不触发事项的处置 | 无自动关闭，只能人工改状态 | 自动提醒还是自动关闭，还是维持现状 |

## 五、使用边界

总览用于判断大势，不用于对账（对账以财务口径为准）；量价拆解看方向不抠小数；半年度页只在复盘语境下解读；风险摘要展示的是"审定后的重点"不是全部信号，追责以行动清单署名人为准。单月数字波动正常，连续三个月的方向比单点可信。
