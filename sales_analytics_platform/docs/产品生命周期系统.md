## 1. 系统概述

产品生命周期系统从**共享 Silver 层**读取数据，输出产品快照表（九宫格画像 + 4 因子风险评分 + ETS 预测 + 历史追溯）。

### 运行流

```
Silver层(product_monthly / 行级 cleaned_rows)
    ↓ run_profiling()（profiling.py，7 个内部阶段）
  产品画像(40+指标/每产品)
    ├── 新品判定（Phase 2：ERP 标记优先，月数/销量自动兜底）
    ├── 历史参考计算（Phase 3：参照组加权均值，多级兜底）
    ├── 九宫格定位（Phase 4：横轴 盈利健康 × 纵轴 销量动能 → 12 组合 9 画像）
    ├── 4因子衰退风险评分（Phase 5：v4.0，不可靠因子降权 + 联合覆盖 + 衰退兜底）
    ├── ETS时序预测（Phase 6：3月+80%/95%置信区间，WMA 兜底，节假日调整）
    ├── 价格弹性/ASP趋势/订单频次
    ├── 历史参照毛利率（多级兜底）
    └── 数据质量标记
    ↓（客户分析已独立：RFM-π 分群/产品关联 → customer_analysis 管道）
  Gold层CSV + Excel报告
    ↓
  看板 C 面（产品生命周期）消费
```

### 入口

```bash
python run_chain.py                      # 平台全链（STAGES 注册制）
python -m product_lifecycle.run          # 模块单独运行（processing/ 下）
```

## 3. 二维九宫格画像

### 3.1 坐标轴

**纵轴：销量动能** — 近12月 vs 前12月月均增长率

| 增长率范围 | 动能等级 |
|-----------|---------|
| > 15%（growth_accelerate） | 加速增长 |
| 0% ~ 15% | 稳定扩张 |
| -10% ~ 0%（growth_flat_lower） | 持平 |
| ≤ -10% | 萎缩 |

> 增长率自动缩窗：12月→6月→3月递进，窗口不足时=0。

**横轴：盈利健康** — 自比 + 他比双重判断

| 自比健康度 | 他比健康度 | 健康等级 |
|-----------|----------|---------|
| ≥ 70%（health_healthy） | ≥ 参照组均值 | 健康 |
| ≥ 50%（health_severe） | 低于参照组但差 < 10pp（health_relative） | 轻度侵蚀 |
| < 50% 或 他比 < -10pp | — | 严重侵蚀 |

### 3.2 九宫格矩阵（nine_grid.py `classify_9grid_full`）

| | 健康 | 轻度侵蚀 | 严重侵蚀 |
|--|------|---------|---------|
| **加速增长** | 成长期 | 健康扩张 | 预警增长 |
| **稳定扩张** | 健康扩张 | 现金牛 | 预警增长 |
| **持平** | 利润优化 | 现金牛 | 隐性衰退 |
| **萎缩** | 主动收缩 | 夕阳产品 | 衰退期 |

（组合外 → 未分类/待观察）

### 3.3 管理层摘要（四区简化）

| 摘要 | 包含画像 |
|------|---------|
| 投入区 | 成长期、健康扩张 |
| 维持区 | 现金牛、利润优化 |
| 观察区 | 预警增长、隐性衰退、主动收缩 |
| 退出区 | 夕阳产品、衰退期、清仓/偶发 |
| 待观察 | 新品观察 |

### 3.4 清仓/偶发过滤

日历月龄 ≥ 24月 且 近24月内发货月数 ≤ 2 → 标记"清仓/偶发"，不参与分析。

### 3.5 上下文感知策略（nine_grid.py `generate_contextual_strategy`）

同一画像按实时数据动态细化建议（策略文本外置配置 `nine_grid_base_strategies`/`nine_grid_contextual_strategies`，代码带兜底）：

- **衰退期**：毛利率同比回升 >10pp → 确认回升可持续性（主动清退则转主动收缩）；回升 ≤10pp → 观察暂缓退市；销量=0 → 确认实质退市；否则量利双跌安排退市
- **夕阳产品**：回升 >5pp → 控制库存暂缓换代；小幅回升 → 规划替代型号
- **隐性衰退**：表面稳定实则利润被侵蚀，预警
- **预警增长**：减收增利 → 关注回升；否则立即查成本结构

## 4. 衰退风险评分（4因子 v4.0）

### 4.1 评分因子与权重（settings_product.py `risk_weights`，当前生效值）

| 因子 | 权重 | 说明 |
|------|---------|------|
| F1f 毛利率趋势斜率 | 0.100 | 斜率下降越快→风险越高 |
| F4 增速衰减 | 0.600 | 增长放缓幅度越大→风险越高（主信号） |
| F5 自比健康度 | 0.200 | 健康度越低→风险越高 |
| c6 大客户订货量变化 | 0.100 | 近6月 vs 前6月 TOP5 大客户合计订货量变化率 |

> 因子阈值：斜率三档（0 / -0.3 / -0.8 月降幅，最少 3 点）；衰减（-10pp / 0 / 同比 -10%，爆发性封顶 cap=1.0）；自比健康（70/50/30）。CV 与 ASP 阈值用于质量标记与价格诊断（§7/§8），**不是独立评分因子**。

### 4.2 F4+F1f 联合覆盖规则

F4 与 F1f 同时触发高风险信号时取加权最大值，防"量价齐跌"被稀释（触发：F4 超阈值且毛利率斜率为负）。

### 4.3 不可靠因子降权

因子不可靠时权重=0，其余按比例重分配：

| 标记 | 含义 | 影响因子 |
|------|------|------|
| SL | 斜率数据不足(<3点) | F1 降权 |
| CV | CV无效(近12月无发货) | — |
| NH | 无历史参照 | F5 降权 |
| AS | ASP数据不足(<3点) | — |

### 4.4 分级标准

| 得分 | 等级 |
|------|------|
| ≤ 55 | 低风险 |
| 56 ~ 65 | 中风险 |
| 66 ~ 68 | 高风险 |
| > 68 | 极高风险 |

### 4.5 衰退期最低分保护

衰退期产品且毛利率≤0 或销量≤0 → 非SH因子加权分 <50 则强制 50 分。

## 5. 历史参照毛利率

### 5.1 计算规则（profiling.py `_compute_reference_groups`）

| 产品月龄 | 数据点 | 参照分位数 |
|---------|--------|-----------|
| < 12月 且 <6 点 | — | P30 |
| < 12月 且 ≥6 点 | — | P50（ref_short_percentile） |
| ≥ 12月 且 <20 点（ref_p95_min_months） | — | P90（自动降级） |
| ≥ 12月 且 ≥20 点 | — | P95（ref_percentile） |

**长周期(≥36月)**：取最近24月（ref_long_months），P80（ref_long_percentile）。

### 5.2 参照组加权均值

```
加权均值 = Σ(营收_i × 毛利率_i) / Σ营收_i
```

**兜底链路**（ref_priority 配置）：`型号_产品品类(≥3个产品) → 全公司均值`

**排除产品**：新品观察、已退市、清仓/偶发。

## 7. 价格相关

- **ASP趋势斜率**：近12月均价变化率（最小二乘），最少 3 个有效点；档位 0 / -0.5% / -1.0%
- **价格弹性**：中位数(ΔQ/Q ÷ ΔP/P) 经 IQR 过滤；>1.5 高敏感 / >0.8 中敏感 / ≤0.8 低敏感
- **ASP-毛利率联合诊断**（joint_asp_pct=-0.5 / joint_margin_pct=-0.3）：ASP跌+毛利跌→价格战；ASP稳+毛利跌→成本问题；ASP跌+毛利稳→规模效应；其他→正常

## 9. 数据清洗口径开关（平台版新增，run.py `_prepare_data`）

| 开关 | 默认 | 行为 | 状态 |
|------|------|------|------|
| `_口径_负销量过滤`（D-2） | **关** | 保留退货/红冲行自然冲减；开启则剔除负销量行 | 待业务拍板 |

| `incomplete_month_threshold_day` | 25 | 最新月最大日期 <25 号 → 剔除该月，基准月回退 | 生效 |

> 设计意图：平台口径与生产链（shared.data_cleaning）保持一致，历史 v2.8 行为由开关保留，业务拍板后可一键启用。
